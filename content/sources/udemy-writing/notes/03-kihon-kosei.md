# 03. ウェブライター育成コンテンツの基本構成設計

分類: 抽出A（構成・見出し系 → structure-craft.md 行き）

## 主張（このテーマの核心 1-3 行）

記事本文は「主張・理由・証拠・具体例」の4要素で骨組みを作る。主張と理由は必須、証拠と具体例は任意（あれば強い）。構成は事前のリサーチ結果（検索ユーザーの願望・本当に求めている情報・デモグラフィック）を反映して作らないと、リサーチが無駄になる。

## 技術・ルール

- 本文構成を作るときは「主張・理由・証拠・具体例」の4要素を軸に整理する
- **必須/任意の区別**: 主張と理由は必ず入れる。証拠と具体例は「あればよい」任意要素（主張＋理由だけの文章も成立する）
- **配置順序**: 4要素はこの順番通りに並べる義務はない。順序固定ではなく「要素が揃っているか」のチェックリストとして使う
- 構成を作るときは、事前リサーチの成果物（検索ユーザーの願望・本当に求めている情報・デモグラフィック分析）を必ず見返し、構成へ反映する。リサーチと構成を切断しない
- 主張は、対象キーワードの顕在ニーズ（例:「勉強方法を知りたい」）に正面から応える形で立てる。その上で、リサーチで判明した「現実的なステップ提示が重要」等の示唆を主張の切り口に織り込む
- 顕在ニーズの入口（勉強方法）から入り、読者が本当に到達したいゴール（売れるライターになる）までを具体的に提示する流れで構成を設計する
- 主張を書いたら、それを支える理由を複数（例では3つ）箇条書きで列挙する。理由は「〜だから」で主張に直結する形にする
- 証拠は「主張に対する証拠」として書く。書き手自身の立場・実務経験（当事者性）が信ぴょう性の源になる場合は、それを明示する
- 具体例は「証拠に対する具体例」として書く。業界・ジャンルの多様性を列挙→「しかし基本は共通」と収束させる等、主張へ戻る構造にする。実体験として語れる経験談を入れる
- 構成段階では完璧を目指さない。まず仮でよいので箇条書きで全要素を埋めることを優先する

## 具体例・Before/After

講座内の例: キーワード「ウェブライター 勉強」の記事。

- 主張 =「ライターになる勉強はステップが大事。自分のレベルに応じて選び、長期的に売れるライターを目指す」
- 理由 = ①いきなりなれるわけではなく勉強・経験・実績の積み上げが要る ②そのために段階的ステップが要る ③ジャンルにより求められることが変わるため、最低限の共通ライティングスキルが先に必要
- 証拠 = 講師自身が外注ライターを雇いブログを外注運営している当事者であり、クライアントも外注ライター組織で収益を安定させている →「いいライターは常に人材不足」という主張に当事者としての信ぴょう性を持たせる
- 具体例 = ブログのジャンルは芸能・医療・福祉・ファッション・恋愛など多様だが、基本のライティングを身につければどのジャンルでも成果が出せる → だから基本を学ぼう、と主張へ回帰

すべて箇条書きの仮置きで作り、後工程で本文化する流れ。

## TENZU 適用メモ

- 「主張・理由・証拠・具体例」4要素フレーム → **そのまま使える**。TENZU の結論先出し方針とも整合（主張を冒頭に置けばよい）
- 主張＋理由は必須、証拠・具体例は任意 → **そのまま使える**。ただし TENZU の旗艦記事（C4-1 効果 等）は信頼性が商品なので、実運用では証拠（references-map.md 登録済みの学術文献・教育系メディア）も実質必須に格上げして運用するのが妥当
- リサーチ内容を構成へ反映する手順 → **そのまま使える**。TENZU では personas.md / clusters.md / keyword-research.md が「リサーチ成果物」に相当。構成作成時にこれらを見返すステップとして移植
- 顕在ニーズの入口から本当のゴールへ導く構成 → **概ね使える。ただし衝突注意**: 「売れる」「引く手あまた」型の到達ゴール提示は煽りに寄りやすい。TENZU では voice-tone.md の誇張語 NG・焦り煽り回避に従い、ゴールは「家庭で無理なく続く」等の等身大表現に置換する
- 「自分が当事者である」ことを証拠にする → **TENZU ルールと衝突（部分）**: オーナーは顔出しなし・自分の家庭での実体験投稿は出さない方針（acquisition 確定事項）。当事者性は「店主が自作・選定している専門店」という三人称プロダクト主語の範囲でのみ使い、子どもの実体験談は使わない。学術的証拠は references-map.md 登録文献に限定
- 「引く手あまた・いくらでも仕事がある」型の成果保証トーク → **不適用**（煽り系。効果保証・誇張は TENZU 全面 NG）
- キーワードからニーズを特定して主張を立てる手順 → TENZU は記事テーマ確定済み（16 ページ体制）のため新規テーマ発掘には**不適用**だが、確定記事ごとの「検索意図→主張」の橋渡しチェックとしては使える
- 構成は仮置き箇条書きでまず埋める → **そのまま使える**（執筆ワークフローの初手として採用）
