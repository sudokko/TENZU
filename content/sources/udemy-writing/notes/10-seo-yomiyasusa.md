# 10. SEO対策と読みやすさの両立：記事ライティング戦略

分類: 抽出A（構成・見出し系 → structure-craft.md 行き）／副B（読みやすさ施策は writing-craft.md 行き。該当技術には行頭に【B】タグ）

※ 原典はセクション末尾のまとめ回。個別技術の手順詳細は他レクチャー側にあり、ここでは「SEO 施策と読者向け施策を二本立てで等価に扱う」という設計思想の言語化が中心。

## 主張（このテーマの核心 1-3 行）

- SEO 施策（Google に評価されるための施策）と読みやすさ施策（読者に好かれるための施策）は同じ重みで両立させる。どちらか片方では成立しない。
- Google は離脱率・読了率（最後まで読まれた割合）・回遊率を見ているため、「読者が読み切れる記事」であること自体が SEO になる。読まれる→評価が上がる→さらに読まれる、の循環を作るのがゴール。

## 技術・ルール

**キーワード配置（SEO 側）**
- 記事を書くときは meta description を設定する
- タイトルを付けるときは、重要なキーワードを先頭側（前方）に寄せる
- 見出し（H2/H3）を書くときは、対策キーワードを見出し文言に入れる
- 画像を入れるときは alt 属性（代替テキスト）を設定する（※原典は誤変換「ソロングタ」。文脈から alt タグと補正。ロングテールキーワードの可能性も残るが、施策列挙の並びから alt と判断）

**読みやすさ施策（読者側）**
- 【B】強調したい箇所は文字色の変更で目立たせる
- 【B】重要ブロックは背景色（マーカー・ボックス）で区別する
- 【B】文章が続くときは画像を挟んで視覚的な休憩を作る
- 【B】補足説明には YouTube 動画の埋め込みも使う

**両立の判断ルール**
- SEO 施策だけに偏った記事は途中離脱され、結果的に SEO 評価も下がる。施策を入れるときは常に「読者が最後まで読めるか」を同時に確認する
- 読了率・回遊率を上げる施策は間接的な SEO 施策として扱ってよい（検索エンジン向けと読者向けを対立させない）

## 具体例・Before/After

- 具体的な Before/After 提示はなし（まとめ回のため）。挙げられた構図は「SEO だけ完璧でも読みにくい記事 → 途中離脱 → Google 評価低下」vs「最後まで読まれる記事 → 満足度が高いと判断 → 検索順位上昇 → さらに読者が増える好循環」の対比のみ。

## TENZU 適用メモ

- **meta description 設定**: そのまま使える。Next.js の metadata API で実装（urls.md の記事ページに適用）。
- **キーワードをタイトル前方に寄せる**: そのまま使える。ただし voice-tone.md の SEO 例外運用（NG 語彙は冒頭のクエリ引用のみ許容）と組み合わせて運用。「高校受験」をタイトル前面化しない制約が優先。
- **見出しにキーワードを入れる**: そのまま使える。詰め込みにならない範囲で（TENZU はキーワード詰め込み NG）。「高校受験」は H1/H2 前面化 NG の既存ルールが優先。
- **画像 alt 設定**: そのまま使える。MDX の img/Image に alt 必須運用でよい。
- **【B】文字色変更・背景色の多用**: **衝突**（design rev.5 ミニマル原則・accent #2C6E7F は「到達・正解」のみ、shadow/装飾ほぼ無し）。色での強調は不採用。強調は構成（結論先出し・短段落・D1-D4 divider・左マーカーのメモブロック）で代替する。
- **【B】画像で休憩を挟む**: 趣旨はそのまま使える。TENZU では装飾画像ではなく点描写の図版・SVG ダイアグラム（記事ページの diagram 実装済パターン）で担う。
- **【B】YouTube 埋め込み**: 不適用。TENZU はノースクリーン志向の親が中核ターゲットで、動画素材も紙・プリント・メーカー画面録画限定の方針。記事内動画埋め込みは導入しない。
- **読了率・回遊率を評価軸にする考え方**: そのまま使える。launch/measurement.md の GA4 イベント設計（scroll 深度・記事→ガイド/商品への回遊）に対応付け可能。
