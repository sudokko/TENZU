# 11. SEO最適化のためのタイトル・見出し・メタディスクリプション設定方法

分類: 抽出A（構成・見出し系 → structure-craft.md 行き）

## 主張（このテーマの核心 1-3 行）

公開前の SEO 最終チェックは「タイトル・見出し・メタディスクリプションの3箇所にターゲットキーワードが入っているか」の確認に集約される。タイトルは重要キーワードほど左に寄せ、本文の SEO 装飾は strong タグのみが検索エンジンに効く（色・背景色は読者専用）。

## 技術・ルール

- **キーワード3箇所確認**: 公開前に①タイトル ②見出し（H2/H3）③メタディスクリプション の3箇所すべてにターゲットキーワード（例: 2語の複合キーワード）が入っているか必ず確認する
- **見出しのキーワード明示**: 見出しを短く削るときも、代名詞・省略でキーワードを消さない。「基本を学びましょう」ではなく「○○（キーワード）の基本を学びましょう」と明示的に残す
- **見出しの整合チェック**: テンプレート流用で見出しを作ると文として成立していない・連番（ステップ数等）が本文とズレることがある。公開前チェックで見出し単体を読み直し、不要語を削る
- **メタディスクリプションは必ず書く**: 検索者に読まれる頻度は低くても、検索エンジンはここのキーワードを重視するため、重要キーワードを必ず含める
- **メタディスクリプションの作り方**: ゼロから書かず、記事の書き出し（リード文）を要約・短縮して流用すると時間がかからない。「この記事は○○を提示する／読み終えると△△が分かる」という記事全体の要約形にする
- **タイトルはキーワード左寄せ**: 重要キーワードほどタイトルの先頭（左側）に配置する。検索者は自分の検索語を最初に見つけると「自分の探している記事だ」と認識しクリック率が上がり、検索エンジン評価上も有利。文意の都合で先頭に置けない場合も「できるだけ左へ」の意識を持つ
- **タイトル語順の優先則**: 訴求フレーズ（潜在ニーズ向けコピー）と検索キーワードが並ぶ場合、キーワードを先・訴求フレーズを後にする。検索者はまだ潜在ニーズに気づいておらず、検索語の方に反応するため
- **strong タグ = SEO 装飾の唯一手段**: 検索エンジンが「重要箇所」と認識するのは strong（太字タグ）のみ。本当に伝えたい重要箇所に限定して使う
- **色・背景色は読者専用**: 赤字・文字色変更・マーカー（背景色）は SEO に一切影響しない。役割は「どこを重点的に読めばよいか」を示す可読性向上のみ。全文黒一色だと読者が論文的な圧迫感を受けるため、読者体験のために使う
- **スラッグ（URL）はキーワードベースで事前設定**: パーマリンクに設定した文字列をそのまま使い、後からいじらない

## 具体例・Before/After

- タイトル語順: 「売れっ子ライターになるには、Webライティング勉強法はこの3ステップ」（訴求が先）→「Webライティングの勉強法はこの3ステップ。売れっ子ライターになるには」（キーワードが先）。後者の方が検索者の反応・SEO とも有利
- メタディスクリプション: 記事のリード文（長い）をそのまま使わず、「この記事は Webライティングの勉強方法と良書、上達ステップを提示します。読み終えると、まず何を勉強すればいいかが分かります」程度の要約形に圧縮
- 見出し修正: テンプレ流用で「3ステップ」と書いた見出しが実際のステップ数とズレていたのを公開前チェックで発見・修正

## TENZU 適用メモ

- キーワード3箇所確認（タイトル・見出し・メタ） → **そのまま使える**。Next.js metadata API の title / description と MDX 見出しでチェックリスト化可能
- 見出しでキーワードを省略しない → **そのまま使える**。ただし詰め込みは NG（誠実トーン）なので「自然な文として成立する範囲で明示」に限定
- メタディスクリプション=リード文の要約流用 → **そのまま使える**。時短かつ記事内容と乖離しない
- タイトル左寄せ → **概ねそのまま使える**。ただし TENZU は「高校受験」等をタイトル前面化しない方針・焦り煽り回避があるため、「キーワード左寄せ」と「煽りフレーズ排除」を両立させる（衝突先: foundation/voice-tone.md・MEMORY 表現置換ルール）。NG 語彙（診断系等）はそもそもキーワードにしない
- 「検索者の潜在ニーズより検索語を先に出す」 → **そのまま使える**。SEO 例外運用（クエリとしての引用は冒頭のみ許容）とも整合（voice-tone.md §1）
- strong タグ運用 → **そのまま使える**。MDX の `**太字**` が strong として出力される。重要箇所限定の節度ある使用は誠実トーンとも整合
- 赤字・マーカー（背景色）装飾 → **不適用寄り・要デザイン判断**。rev.5 ミニマルデザイン（accent teal は「到達・正解」専用・装飾最小）と衝突（衝突先: design/visual-identity.md・rev.5 トークン）。可読性目的の強調は strong ＋ rev.5 の divider/左マーカーで代替
- WordPress プラグイン（Yoast 系）設定画面の操作手順 → **不適用**（ツール依存。原則のみ抽出済み）
- 煽り系: 「売れっ子ライターになるには」型の射幸フレーズ例が出るが、技術としては展開なし → **不適用**（TENZU は誇張語 NG）
