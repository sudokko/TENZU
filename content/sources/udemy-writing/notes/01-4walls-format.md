# 01. ウェブコンテンツの基本フォーマットと4つの壁を越える記事執筆法

分類: 抽出A（構成・見出し系 → structure-craft.md 行き）

## 主張（このテーマの核心 1-3 行）

読まれる Web 記事は「タイトル → 書き出し → 見出し＋本文（必要数だけ反復）→ まとめ」という定型フォーマットでほぼ共通している。各パーツには読者が離脱する固有の「壁」（開かない／読まない／信じない／行動しない）が対応しており、パーツごとに越えるべき壁を意識して書き分けるのが執筆の基本戦略。

## 技術・ルール

- **基本フォーマットは4パーツ構成**: ①記事タイトル ②書き出し（リード文）③見出し＋本文のセット（記事の分量に応じて2個〜10個程度を反復）④まとめ見出し＋まとめ文。長い記事でもこの骨格は変えず、③の反復数で吸収する
- **パーツと「4つの壁」を1対1で対応させて書く**:
  - タイトル → 「開かない（Not Open）」の壁。クリックして開いてもらうことだけを目的に練る
  - 書き出し → 「読まない（Not Read）」の壁。開いた読者は本文を読まない前提で、続きを読みたくなる興味喚起をここで作る
  - 本文 → 「信じない（Not Believe）」の壁。読まれても信じてもらえない前提で、根拠・データ・専門的見解を入れて説得力を担保する
  - まとめ → 「行動しない（Not Act）」の壁。本文の要点を整理し直して納得させ、行動につなげる。最後まで気を抜かずに書く
- **本文は「主張 → 理由 → 具体例」のセットで組む**: 各見出しブロックの中身は、主張を立て、理由・根拠で支え、具体例で補強する型を織り交ぜて構成する
- **まとめは要約の場であって新情報の場ではない**: 本文の内容をきちんと回収して締めることで、読後の納得と次の行動を作る

## 具体例・Before/After

- 講座内の具体例は「見出しが2個の最小構成」と「分量が多い場合は見出し10個程度まで反復する」というフォーマット例示のみ。Google 検索で上位に出てくる記事はほぼ「タイトル → 魅力的な書き出し → 説得力ある本文 → まとめ」の型に収まっている、という観察が提示された。Before/After 形式の事例はこのレクチャーには無し

## TENZU 適用メモ

- **基本フォーマット（タイトル/書き出し/見出し＋本文反復/まとめ）**: そのまま使える。TENZU の記事テンプレ（content/templates.md）の骨格と整合。確定記事8本の構成チェックリストに転用可
- **タイトル＝開かない壁**: 部分適用。クリック誘導自体は必要だが、TENZU はキーワード確定済みかつ煽り NG なので「壁を越えるためにフックを盛る」方向ではなく「検索意図への正直な答えを明示する」方向で運用する
- **書き出し＝読まない壁（興味を引く書き出し）**: TENZU ルールと衝突に注意。「続きを読ませるための引き」を焦らし構成で作るのは結論先出し原則（foundation/voice-tone.md）と衝突。TENZU では「冒頭で結論と読むメリットを先に出す」ことで読まない壁を越える、と読み替えて適用
- **本文＝信じない壁（根拠・専門的見解で説得力）**: そのまま使える。学術土台記事（C3-4）や難易度メタデータ公開という TENZU の差別化方針と相性が良い。最重要の持ち帰り
- **本文で「感情を揺さぶる」**: 不適用。不安喚起・焦り喚起に転びやすく、傷つきにくさ原則・煽り NG と衝突。感情面は「共感（あるある）」の範囲にとどめる
- **まとめ＝行動しない壁（納得→行動）**: そのまま使える。ただし CTA は誇張せず、レベル選びガイド・サンプル PDF・メーカーへの自然な導線として置く
- **主張→理由→具体例の型**: そのまま使える。誠実トーンと矛盾しない汎用ライティング型
