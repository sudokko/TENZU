# sources/udemy-writing/ — ライター講座 文字起こし素材

## サマリ

- Udemy ライター講座（私的学習利用）の Notta 文字起こしを置く**素材置き場**（SSOT ではない）
- `raw/` … Notta から手動エクスポートした TXT 原文（約30テーマ・ファイル名自由）
- `notes/` … テーマ別の構造化抽出ノート（`NN-<slug>.md`・サブエージェントが生成）
- 抽出対象は 3 系統: **構成・見出し系**（章立て・目次設計・タイトル・リード設計・SEO 構成）→ [structure-craft.md](../../structure-craft.md)／**文章術系**（文・段落・リズム・具体化）→ [writing-craft.md](../../writing-craft.md)／**推敲系**（書いた後の点検・直し方）→ [revision-craft.md](../../revision-craft.md)
- **WordPress・プラグイン等ツール操作系は不採用**（TENZU は Next.js 自前実装）。本ディレクトリは出典遡り用の証跡（SSOT ではない）
- 成果物側（writing-craft.md）には講座名・講師名・逐語引用を書かない。ノートも自分の言葉で再構成する

```markdown
## 具体例・Before/After（自分の言葉で要約・逐語転記しない）
## TENZU 適用メモ（そのまま使える / voice-tone.md・templates.md §7 と衝突 / 不適用）
```
