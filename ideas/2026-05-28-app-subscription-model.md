# 印刷メンバーシップ（App サブスク）モデル

## 着想

[ideas/2026-05-28-app-decoration-for-buyers.md](2026-05-28-app-decoration-for-buyers.md) を検討する中で、より大きな戦略転換アイデアが浮上。

**従来発想**: App は無料フック（集客装置）。収益は PDF プリント単発販売のみ。

**転換発想**: App 自体を**独立した有料商品**として展開。**「PDF プリント本店 ＋ 親のためのプリント工房（月額メンバーシップ）」の商品ライン拡張**。

オーナーの戦略的判断軸:
- MISSION（点描写を家庭の当たり前に）は紙でもデジタルでも達成可能
- 本来の目的＝**点描写の普及**。プリント販売は手段
- 単発購入では取りこぼす「アプリが気に入っただけ層」「無料で済ませたい派の中の継続派」を月額で拾える
- LTV を桁レベルで改善し、1 人副業運営の収益安定化（MRR）

## 重要な名称転換（ChatGPT DR 提言）

| 避ける表現 | 推奨表現 |
|---|---|
| App サブスク・知育アプリ | **印刷メンバーシップ** |
| 子どもが遊べる | 親が作り、子どもは紙で解く |
| 進捗管理 | 続けやすい記録 |

**理由**: ユーザーは言葉で分類する。「App サブスク」と言った瞬間に Think!Think! / WonderBox 側の競合認識に寄り、TENZU の独自ポジションが壊れる。**「親のためのプリント工房」**として位置づければ、紙連携サブスクという独自カテゴリを確立できる。

## 商品ライン再定義

| 商品 | 役割 | ブランド上の意味 |
|---|---|---|
| **PDF 単品・バンドル** | 体系・順序・レベル設計 | TENZU の本店（P1 体系・P2 解像度） |
| **印刷メンバーシップ** | 親による調整・創作・反復 | 継続支援ツール（P5 継続） |
| **無料メーカー** | 発見・体験 | P3 発見の入口 |

「2 枚看板」ではなく「**本店＋工房**」の関係。

## 機能設計

### 無料層
- 5×5 のみ・#1 模写のみ
- 月 N 枚まで・透かしあり
- 保存なし
- 1 PDF = 最大 6 問

### 個人プラン（メンバーシップ）
- 7×7 まで
- #1-#5, #7, #8 の 7 タスク対応（#6 分解・#9 立体は永久に商品 PDF 専用）
- 装飾モード（子の名前・日付・フレーム・色・メッセージ）
- 透かしなし
- 無制限印刷
- 作品ライブラリ保存
- **きょうだい設定（個人プランに子 2 名まで含む）**

### 「守る線」の規約レベル明文化（必須）

| 項目 | ルール |
|---|---|
| 子ども向け画面 | 作らない |
| 画面上で解く UI | 作らない |
| バッジ・スコア | 子ども向けには作らない |
| 進捗管理 | 親の記録に留める |
| 表現 | 診断・治療・弱点・処方箋は禁止（voice-tone.md §1 と整合） |
| 子ども個人情報 | 最小化 |
| 解約導線 | 申込導線と同等に分かりやすく（特商法 2022 改正対応） |

**理由**: チャーン改善の圧力は必ずバッジ・連続ログイン・ゲーム性などを誘発する。これが TENZU の Anti-Brand（タブレット教材化）を侵食する最大の構造的リスク。**サブスク開始前に固定**しないと、後から戻せない。

## 価格設計

| プラン | 価格 | 備考 |
|---|---|---|
| 無料 | ¥0 | 制限あり |
| **個人** | **¥480/月 または年額 ¥3,980** | きょうだい 2 名まで含む |
| 教室 | 月額ではなく年額 ¥18,000-36,000 | **Phase 3 まで出さない** |

**¥200/月は安すぎ却下**（Stripe 手数料・サポート・返金で採算合わず）。Think!Think! 標準 ¥450 と整合するレンジに。

家族プランは Phase 0 段階では不要。個人プランに子 2 名まで含めて吸収。

## LTV 試算（現実値）

| 月次チャーン | 理論 LTV | 24 ヶ月内期待売上 |
|---|---|---|
| 4% | ¥7,500 | ¥4,700 |
| **6.5%（DTC/Education 平均）** | **¥4,615** | **¥3,700** |
| 10% | ¥3,000 | ¥2,700 |

→ 単発 PDF モデル（LTV ¥1,000-2,000）比で **1.5-4 倍改善**。投資判断は ¥3,700-4,700 の現実レンジで。

## 段階的 Phase 投入（ChatGPT 推奨）

| Phase | PDF | 印刷メンバーシップ |
|---|---|---|
| **Phase 0**（launch） | 即DL販売（既定） | **無料メーカー公開 ＋ 有料β予告 ＋ 価格アンケート** |
| **Phase 0.5** | 同上 | **先着 30-50 名のみ有料β**（クローズド） |
| **Phase 1**（モニター期） | 同上 | 継続率・印刷枚数・問い合わせ負荷を見て一般開放 |
| **Phase 2**（春LP） | バンドル SKU 追加 | 春LP連動・年額・バンドル導入 |
| **Phase 3** | GA | 教室プラン検証 |

### Phase 1 一般開放の判定基準

- 無料メーカーの 30 日内再訪率 ≥ 20%
- 1 人あたり月間印刷枚数 ≥ 3-6 枚
- 有料待機リスト登録率 ≥ 5%
- 問い合わせ負荷 1 ユーザーあたり月 < 10 分
- PDF 購入 CVR の悪化 < 30%

## 技術設計

### 認証・課金

- **Magic Link 認証**（Supabase Auth）・パスワードレス
- **Stripe Subscriptions ＋ Customer Portal**（解約・カード変更・領収書は丸投げ）
- **DB**: Supabase（ユーザー ID と Stripe Customer ID の紐付け）
- **Webhook**: Stripe → Amplify Function or Vercel API Route → DB 更新

### 最小アカウントページ（自前必要）

「マイページ自前不要」は言い過ぎ。Stripe Portal で**請求管理は外部化できるが、学習体験・アカウント状態・問い合わせ対応は外部化できない**。

| 必要機能 | 理由 |
|---|---|
| 契約状態表示 | 今どのプラン使えるか |
| Portal への導線 | 解約・カード変更の入口 |
| 権限同期 | Stripe 状態と App 機能制限の同期 |
| 退会・データ削除導線 | 個人情報保護 |
| 法定表示へのリンク | 特商法・規約・プライバシー |

## 法務リスク

| 法令 | 対応必須事項 |
|---|---|
| **特商法 2022 改正** | 申込最終確認画面で価格・期間・支払時期・解約方法・解約条件・無料→有料移行時期を明示 |
| **個人情報保護委員会 FAQ** | 12-15 歳以下の子どもデータは法定代理人同意が必要な場合あり |
| **電気通信事業法 外部送信規律** | 解析タグ・SDK 利用時の利用者情報外部送信通知・公表 |
| **クレジットカード・セキュリティガイドライン 6.0** | EMV 3-D セキュア・不正検知設定 |
| **Apple/Google 税回避** | Web 完結（PWA可）で 30% 手数料は回避可能。ただし将来ネイティブアプリ化する場合は別 |

## 効くポイント

1. **MISSION 整合度が高い**: 「点描写を家庭の当たり前に」が達成できる手段が広がる
2. **LTV 桁改善**: 単発 ¥1,000-2,000 → 月額 ¥3,700-4,700
3. **MRR の確立**: 1 人副業運営の収益安定化
4. **離脱層を取りこぼさない**: 「App だけ気に入った層」を月額で拾える
5. **デジタル完結**: 印刷・配送・在庫ゼロ
6. **PDF とのカニバリ問題が構造的に解消**: 本店（体系）vs 工房（創作）で役割分担
7. **独自ポジション**: 「画面で学ぶアプリ」ではなく「紙で学ぶために親が使う生成ツール」

## 課題・落とし穴

### 構造的リスク

1. **「Appサブスク」名乗りはブランドを壊す**: Think!Think! 側に分類される → **「印刷メンバーシップ」命名で死守**
2. **低 ARPU なのにサポートだけ SaaS 化リスク**: 月¥480 顧客が 1 回問い合わせるだけで利益消える → **設計でサポート負荷潰す**
3. **PDF とのカニバリ再発**: App で自由に作れるなら PDF を買う動機が弱まる → **PDF の価値を「順序・体系・レベル設計・失敗しにくさ」に置き直す**
4. **継続率改善の圧力が Anti-Brand を侵食**: バッジ・スコア・ゲーム性導入の誘惑 → **「やらないこと」規約レベル固定で防衛**
5. **子どもデータ・外部送信・広告タグの法務負債**: 複数子設定・進捗管理導入時に重くなる
6. **「創作派は高 LTV とは限らない」**: 継続課金しやすいのは「迷わず続けたい親」。サブスクの中核機能は**装飾より「今週の3枚」「次の一手」「戻り道プリント」**

### 開発・運用リスク

7. **コンテンツ供給の継続コスト**: 毎月新作を出すと破綻 → 生成ロジックと既存体系で回す
8. **プラン増殖リスク**: 無料・個人・家族・教室を Phase 0 同時投入は過剰 → **無料 ＋ 個人だけ**で始める
9. **「画面で解かせろ」という同調圧力**: ユーザー要望に押されて哲学が崩れる → 規約レベル固定で防衛

## 判断保留の理由

1. **PDF 単発モデルで事業が成立するか未検証**: Phase 0 無料 App → 有料 PDF の CV 率が実データで取れていない
2. **支払い意思の検証が必要**: 「App が気に入った層」の何 % が ¥480/月払うか未知
3. **開発工数（副業 2-4 ヶ月）と機会費用**: 本店（PDF 販売）の機能改善・コンテンツ拡充に充てる選択肢もある

## 次の判定タイミング

1. **Phase 0 無料 App 公開後の CV 率実データ取得時**:
   - PDF 購入 CVR が想定範囲なら、ピボット急がず PDF 単発モデルで進む
   - CVR が想定の 50% 以下なら、ピボット必要性が高い
2. **モニターから「サブスク化なら払う」声の蓄積**: 有料待機リスト登録率 ≥ 5% が目安
3. **春LPバンドル SKU 設計時**（[pack-commerce.md §24](../product/pack-commerce.md)）: バンドル価格設計の延長で「メンバーシップ」を組み込むか判断

## DR 結果サマリ（2026-05-28 実施）

### Gemini DR
- 総合判定: 条件付き推奨（Phase 0 同時 launch は非推奨）
- 採用ポイント: 特商法令和4年改正対応・チャーン現実値（5-10%/月）
- 過剰反応: CS 爆発論・カニバリ極大化論（既存設計を読み飛ばし）

### ChatGPT DR
- 総合判定: 条件付き推奨（「印刷メンバーシップ」として設計する場合に限る）
- 出典付き・数字付き・TENZU の具体設計を踏まえた厳密な指摘
- **核心提言**:
  1. 「App サブスク」→「印刷メンバーシップ」命名転換
  2. 「やらないこと」の規約レベル固定
  3. LTV 試算の現実化（¥3,700-4,700）
  4. 価格 ¥480/月 or 年額 ¥3,980
  5. Phase 0 → Phase 0.5 有料β段取り

### 2 AI 合議結果
- ChatGPT の構造的指摘が圧倒的に質高い
- Gemini の Phase 0 否定論は根拠弱いが、ChatGPT の「Phase 0.5 有料β」案と着地点は近い
- **「最初からやる」のオーナー意向は維持可能**: ただし"最初" = Phase 0.5 有料β（先着 30-50 名）
