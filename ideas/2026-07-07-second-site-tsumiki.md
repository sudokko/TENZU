# 点描写スキーム転用の第2サイト題材：6候補比較（本命＝積み木）

## 着想

TENZU で構築した「専門店スキーム」を、点描写の次の知育題材へ横展開できないかというオーナー発案（2026-07-07）。スキームの本質は次の4条件の掛け算：

1. **機械生成** — ジェネレータで全問ユニーク量産・解答も自動導出
2. **難易度の客観スコア化** — D スコア相当が定義でき「設計図ごと、全部公開する」（[foundation/brand.md](../foundation/brand.md) §0.5）の旗が立つ
3. **メーカー（工房）** — 親が自作できる UI が成立し per-maker 買い切りクロスセルが乗る
4. **紙とペンで完結** — PDF 印刷のみで成立。イラスト資産・音声不要

候補4つ（点つなぎ／系列・推理／お話の記憶／積み木）を、上記4条件＋市場・ブランドの2条件で比較した。同日、小受ペーパー7分野（言語・図形・数量・推理・記憶・常識・話の記憶）の棚卸しと市場調査から**迷路・展開図**を追補し、計6候補とした（数量＝公文と無料の海で最悪／なぞり運筆＝「考えないかき」で Anti-Brand／言語・常識＝イラスト必須、で脱落）。

### 追補：迷路・展開図の調査メモ

- **迷路（15/18・対抗）**: 需要は巨大で、くもん・学研とも幼児ドリルの主要カテゴリ（学研はトミカ/プラレール迷路）＝**支払い意欲は市販ドリルで実証済み**。無料はちびむす・ぷりんときっず等で無尽蔵だが、すべて「運筆練習」文脈でレベル体系・難易度メタデータを持つものは見当たらない→体系×スコア公開の差別化がそのまま効く。生成は定番アルゴリズムで全問ユニーク・正解経路も自動。年齢帯（年少〜年長）が TENZU 主戦場の**前段**にあたり、「迷路→点描写→積み木」の兄弟店送客階段が描ける。弱点＝空間認知 MISSION とは別軸（運筆・実行機能・計画性）
- **展開図（14/18・次点）**: 天才脳ドリル「空間把握」で点描写・回転図と**同居するファミリー**＝同志文脈が既にある。小受サイコロ問題として頻出・のびラボ等に PDF ダウンロード販売の前例あり。立方体11種ネット×面模様×回転で無限生成・正誤肢も自動。「切って組み立てて検証」まで紙で完結するのがスキームと好相性。弱点＝ボリュームゾーンが小4〜中受で主戦場から上振れ、TENZU の折り重ねタスクと近接

## 効くポイント（積み木の勝ち筋）

- **技術資産の直撃流用**: 立体模写で実装済みの押し出しジェネレータ・法線による隠線自動判定・斜投影レンダラ・`hiddenLines` メトリクス（[decisions.md](../decisions.md) §3.57）がそのまま核になる。「見えない積み木を含めて何個？」も四方観察（前後左右上の正射影）の正解／ひっかけ肢も、ボクセル配置から全自動生成。イラスト不要・全部幾何
- **D スコアの再演**: 総ブロック数・隠れブロック数・段数・凹凸で客観ラダーが組め、クリティカルコア「設計図ごと、全部公開する」を二度目の旗として立てられる
- **メーカー競合ゼロ**: ボクセルを積む→四方図・個数問題が自動生成される工房は前例なし。実物の積み木と連動できる点も「書く学習は紙とペン」哲学と好相性
- **市場構造が点描写と同型**: 天才ドリル（立体王）・ピグマリオンは「同志（引用先）」と定義済み（[market/competitive.md](../market/competitive.md)）、無料プリントは体系なし。客層は年長〜小1の空間認知＝MISSION 直系で、TENZU との相互送客が成立
- 決済・所有 cookie モデル・atelier 検品・ladder スキーマ・SVG/PDF パイプライン・Next.js 基盤もほぼ全部流用可能

## 課題・落とし穴

- **別サイト（兄弟店）か TENZU 第10タスクかの決め**が必要。行為が「描く」から「数える・選ぶ」へずれるため、「点図形（点描写）プリント専門店」の看板を薄めない兄弟店が筋。ただし「四方から見た図を**描く**」タスクを軸に据えれば「見て、考えて、書く」と地続きにできる
- 却下2候補のメモ: 点つなぎは無料プリント無尽蔵＋Anti-Brand と自己矛盾（※TENZU **内**の商品ライン化は別議論 → [2026-06-11-dot-to-dot-product-line.md](2026-06-11-dot-to-dot-product-line.md)）。お話の記憶はイラスト必須・スコア恣意的・メーカー不成立でスキーム適合最下位
- 系列・推理（追補比較で候補へ降格）は生成適合◎だが、メーカーの旗が弱く、「系列」というカテゴリの検索認知が小受外でほぼない
- 追補2候補の位置づけ: 迷路は主戦場の**前段**を担う兄弟店として送客階段（迷路→点描写→積み木）が描ける唯一の候補。展開図は単独サイトより TENZU 第10タスク（折り重ねの隣）編入のほうが自然かもしれない

## 判断保留の理由

TENZU 本体がローンチ前（模写図形の作りきり・クロスセル MVP・オーナー本番化残務が先）。第2サイトはリソース的に時期尚早。
