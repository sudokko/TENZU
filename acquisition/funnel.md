# CV 導線設計

## サマリ

- 点図形（点描写）プリント専門店 TENZU の **CV 導線設計書**
- **F2 主導線（3 段構造・確定）**: メイン「サンプルを見る」／サブ①「おためし点描写メーカーで作ってみる」／サブ②「レベル選びガイドで自分の子のはじめ方を見る」
- **メイン CTA = サンプル直接プレビュー**（クリック 1 発・"中身が見える"差別化の最短体現）
- **おためし点描写メーカー（Web ジェネレータ）は開店（2026-08-30）時から常設**（[brand.md §11.3.1](../foundation/brand.md)）
- **F5 「PDF と Web ジェネレータの違い」**: Web ジェネレータ = オリジナルの 1 枚を作れる入口／PDF = レベル順に続ける本練習
- 「自己診断ツール」「スタート診断」は Anti-Brand 化済（[voice-tone.md §1](../foundation/voice-tone.md)）
- メアド取得は **Stripe 決済に一本化**。Web ジェネレータ・サンプル・ガイドではメアド取得しない（静かな開店期以降「任意の追加価値」として案内のみ）
- クーポンは本格化（12 月第 1 週〜）のみ（[channels.md §4.3](channels.md)）
- **季節・年齢ワード第 4 分類（2026-05-23 実測追加）**: 春 LP（入学準備 ドリル 320／春 880）＋ C1-5 年齢別入口（年長 プリント 320／小1 プリント 320） — 通年 SEO ではなく季節限定 LP・年齢別 Cluster で受ける
- **広告ファネル計測 10 イベント（2026-05-27 新設）**: `lp_view` / `tool_start` / `tool_config` / `generated_pdf` / `download_pdf` / `product_recommend_click` / `view_item` / `add_to_cart` / `purchase` / `repeat_purchase`（§11）
- **6 リターゲティングオーディエンス（2026-05-27 新設）**: LP 訪問のみ／`tool_start` 済み未出力／`generated_pdf` 済み未購入／商品ページ閲覧未購入／初回購入者／複数購入者（§12）
- **広告 LP 7 セクション構成**＋**サンクスページ設計**（§13・§14）: Web ジェネレータ体験 → 商品ページ遷移の最重要勝負所
- **SEO 取引意図の受け皿は専用ファセットLP（メーカー非経由・2026-06-08）**: 「無料／プリント／難しい／簡単／立体／年齢」等の取引クエリは TOP でなく専用ファセットLPに着地＝**有償一本**（無料LP のみ絵柄サンプル印刷可）。**おためしメーカーは取引LPの流し先にしない**＝役割は広告/SNS 入口＋体験ツールに限定（無料完結回避・[../decisions.md §5.6](../decisions.md)・[../product/pack-commerce.md §25.6](../product/pack-commerce.md)）
- **広告は独立軸 SSOT**: [ads.md](ads.md) を参照
- **オンサイトメッセージ（自前 Web 接客・CV 導線の補助）**: [onsite-messaging.md](onsite-messaging.md) を参照

## 詳細

### §1. F2 初回 CTA 3 段構造（確定）

| 段 | CTA | 主たる対象セグメント | クリック先 |
|---|---|---|---|
| **メイン** | 「サンプルを見る」 | 全セグメント共通（特に S-b 紙とペン重視・S-c 図形・書字に不安） | PDF 1 枚プレビュー（即時表示） |
| サブ① | 「おためし点描写メーカーで作ってみる」 | S-b（紙とペン）・S-a（先取り知育）の入口体験層 | おためし点描写メーカーのページ |
| サブ② | 「レベル選びガイドで自分の子のはじめ方を見る」 | S-a 先取り知育・S-c 図形・書字に不安 | レベル選びガイド（5-7 問） |

#### Why メイン = サンプル直接プレビュー

- ① TENZU の差別化「中身が見える」を最短で体現（[brand.md §11.3](../foundation/brand.md)）
- ② コミット最低（クリック 1 発・フォーム入力なし）
- ③ 3 セグメント全層に効く（全員「中身を見たい」は共通）
- ④ LLM 引用しやすい構造的事実
- ⑤ S-b 紙とペン層に「画面で完結商品」と誤解されない

**Gemini 推奨「レベル選びガイド主導線」は却下**（カテゴリ未知層には重い・[decisions.md §3.32](../decisions.md)）。

### §2. おためし点描写メーカー（開店時から常設）

#### 2.1 仕様（[brand.md §11.3.1](../foundation/brand.md) SSOT）

- **完全に親向けツール**（子供 UI 排除）
- **模写のみ**（9 タスク中の 1 つ）
- **最大 5×5 まで**（6×6 以上は商品 PDF に誘導）
- **画面で解かせる UI を持たず・生成 → PDF ダウンロード一直線**
- ファーストビュー明示文: **「作るのは画面、練習は紙。」**

#### 2.2 F5 「PDF と Web ジェネレータの違い」一文化

```
おためし点描写メーカーは、オリジナルの 1 枚を作れる入口。
商品 PDF は、レベル順に続ける本練習。

（補足：作るのは画面、練習は紙。）
```

#### 2.3 自己カニバリ回避設計

- Web ジェネレータ出力 PDF のフッターに「**6×6 以上は商品 PDF で**」透かし CTA を入れる（Gemini 推奨採用方向・[brand.md §11.3.1](../foundation/brand.md)）
- Web ジェネレータページ → 商品ページへの内部リンクを末尾に必ず配置
- Web ジェネレータは MailerLite 連携も Stripe 連携もしない（純粋な入口体験ツール）

### §3. レベル選びガイド（4 問・2 軸出力）

- **位置付け**: F2 サブ②・C1-3 の本体機能
- **実装＝ Next.js 自前ページ `/level-guide`**（MailerLite 不採用。メアド非取得ゆえ外部ツールの利点ゼロ・catalog SSOT/SVG/帯グラフ/デザイントークン再利用が効く）。`"use client"` 単一コンポーネント・状態のみ・バックエンドなし
- **メアド取得しない**（誠実さ優先）。外部送信なし・完結はクライアント内
- **NG 表現**: 「弱点診断」「自己診断」「スタート診断」「健康診断」（[voice-tone.md §1](../foundation/voice-tone.md)）。**提案トーン厳守**（「〜なお子さんには、ここから」。「あなたの子は〇〇」型の断定 NG）

#### 3.1 中核＝2 軸モデル

| 軸 | 出すもの | 駆動する設問 |
|---|---|---|
| **軸A はじめる位置（Lv 1-5）** | 帯グラフ上で推奨レベルを強調 | 年齢（めやす補助）＋手ごたえ 2 問（斜め／細かさ・交差） |
| **軸B どの種類から** | ★最初の一冊（具体 SKU）＋関連 2-3 | 目的・きっかけ 1 問 |

- データは [pack-tasks §12.7](../product/pack-tasks.md)・catalog（`GROUPS`/`LEVELS`/`LEVEL_GRAPH`/`LevelGraph`）を**再利用**。ガイド独自のレベル/タスク定義は作らない（SSOT 維持）

#### 3.2 設問（4 問）

1. 年齢（4才以下／5才／6才／7才／8才以上）— **めやすのみ**。手ごたえ質問が上書きする。素の年齢で聞く（年中/年長などの呼称は使わない）
2. 斜め線：ななめは引けるか（すいすい／ときどき／まだむずかしい）
3. 細かさ・交差：細かいマス目（5×5 以上）や交差する形はどうか（楽しめそう／ふつうかな／まだ難しそう）
4. 目的・きっかけ（軸B 決定・単一選択）：はじめて／公文の次／図形が苦手／絵が好き／もっと難しく／立体

#### 3.3 レベル決定ロジック（軸A・決定的）

年齢で初期推定 → 手ごたえ 2 問で確定（**やさしい側が勝つ上限**）：斜め=すいすい & 細かさ=楽しめそう → Lv.4 以上許可（**8才以上のみ Lv.5 発展編まで**）／斜め=すいすい or 細かさ=楽しめそう → Lv.3 以上許可／細かさ=まだ難しそう → Lv.3 上限／斜め=まだ → Lv.2 上限。

#### 3.4 SKU 決定（軸A × 軸B）＋歯抜けスナップ

★最初の一冊 ＝ 軸B のタスク × 軸A の Lv。そのタスクが該当 Lv に存在しない（絵柄＝Lv.1 なし／立体＝Lv.3 開始 等）場合は**最も近い存在 Lv にスナップ**し一言注記（例「絵柄は入門編から始まります」）。同距離はやさしい側。

#### 3.5 結果画面

- はじめる位置（帯グラフで推奨レベルをハイライト）／★最初の一冊（タスク名＋レベル名＋内容解説＋設問サンプル SVG＋サンプルプレビュー＋商品リンク）／そのほかにおすすめ 2-3／逃げ道「ガイドを使わず全部見る」＋「もう一度」。共通フッター文「年齢はめやすです。迷ったときは、ひとつやさしい巻から」
- **商品リンクの遷移先**（[decisions.md §3.47](../decisions.md)）: ★最初の一冊＝推奨 Lv の Vol.1 が live なら SKU 詳細 `/products/{sku}`、scaffold ならタスク別一覧の該当 Lv アンカー `/products/{task}#lv{n}`。関連タスク＝タスク別一覧 `/products/{task}`。「ガイドを使わず全部見る」＝商品一覧ハブ `/products`。サンプルプレビューのみ未配線（サンプル閲覧の整備待ち・[decisions.md §4.9](../decisions.md)）

#### 3.6 TOP からの導線

- TOP（`/`）はガイド本体（Q&A フロー）を**内蔵せず**、帯グラフ直下の誘導 CTA から `/level-guide` へ**リンクで渡す**のみ。本ガイドが SSOT・TOP に設問を再実装しない（二重化回避・[decisions.md §3.44](../decisions.md)）。配線箇所＝ TOP 帯グラフ下 CTA／Hero・Close のゴースト CTA／ヘッダーナビ「レベル選び」／フッター。TOP の全体像把握は coverage 圧縮（3 群タブ＋種類リスト＋代表デモ）が担い、棚の全量＝チップ付きカタログは商品一覧ハブ `/products` が担う（[decisions.md §3.47](../decisions.md)）

#### 3.7 商品への遷移階層（TOP → タスク別一覧 → SKU 詳細）

チップ（Lv 単位）と SKU（Vol 単位）は 1:1 にならない（同一 Lv に複数 Vol が常態）ため、中間層「タスク別一覧」を挟む 3 層構造（[decisions.md §3.47](../decisions.md)）:

| 層 | URL | 役割 |
|---|---|---|
| 商品一覧ハブ | `/products` | 10 種類 × 5 段階の全量カタログ（レベルチップ付き）。「すべて見る」系の着地先 |
| タスク別一覧 | `/products/{task}`（copy/mirror 等 10 本） | 1 タスクの全 Lv × Vol を陳列。チップは `#lv{n}` アンカーで着地。準備中の巻も非リンクで陳列（棚の全体像は隠さない） |
| SKU 詳細 | `/products/{task}-lv{n}-vol{m}` | live SKU のみ。仕様表・レベルラダー・店主から・関連 3 冊 |

### §6. 購入導線

```
【新規・SEO 経由】
記事（P1-P4 ／ Cluster） → F2 メイン CTA「サンプルを見る」

  → Web ジェネレータ出力 PDF のフッター CTA「6×6 以上は商品 PDF で」

  → Stripe 決済

【新規・レベル選びガイド経由】
流入ワード記事 → ガイド 5-7 問 → おすすめ SKU 提示＋サンプルプレビュー

【新規・春 LP 経由（季節限定）】

  → 春 LP（§10）→ 形と位置の練習 7 枚紹介
  → F2 メイン CTA「サンプルを見る」または C1-5 年齢別入口
  → Stripe 決済

【リピーター】
MailerLite メール → パックリンク → Stripe 決済（Stripe Link）
```

#### 6.1 再訪設計（連載 × リマーケティング）

メアド取得もプッシュ通知もしない方針のため、**コンテンツの深さで再訪と信頼蓄積を作る**。

- Pillar 4 本＋Cluster 17 本＋FAQ 3 本の階層型構造で「次に読む」誘導が成立
- 1 回目の記事で離脱しても、リマーケティング広告で別の記事に再接触
- Google 広告リマーケティング（[channels.md §5.2](channels.md) 月¥3,000-4,000）から P4 配下への再接触

### §10. 季節限定 LP（春・1-4 月）= 入学準備モード

S-a 親層の春スパイク（[../market/targeting.md §1.4](../market/targeting.md)）を受ける季節限定 LP。**記事カウント外・Cluster 群とは別管理**。

#### 10.1 仕様

| 公開時期 | 1 月公開・2-4 月最大化（**3 ヶ月前から立ち上げ**・SEO 着地までのリードタイム逆算） |
| 受けワード | 入学準備 ドリル 320／春 880・入学準備 プリント 40 |

| FV ヒーロー | 春らしい季節感＋紙面 3-5 枚並列＋一週間プラン例 |
| 主 CTA | F2 メイン「サンプルを見る」＋ サブ「年長・小1 のおすすめを見る」（C1-5 へ） |

#### 10.2 内部リンク方針

- 上流: Google「入学準備 ドリル」「年長 プリント」「小1 プリント」SEO・LLMO 自発推薦・少額広告（[channels.md §5](channels.md)）
- 横: C1-5 年齢別入口 Cluster と相互リンク
- 下流: F2 メイン「サンプルを見る」 → Stripe 決済 ／ ガイド導線 → C1-3 レベル選びガイド

#### 10.3 SKU ピックアップ（仮）

春 LP で前面化する SKU は、9 タスクのうち **模写・補完・移動**系の Lv.1-2 を中心に 7 枚程度。詳細選定は春仕込み（10-11 月・[../launch/phases.md §4.3](../launch/phases.md)）時に [../product/pack-design.md](../product/pack-design.md) と突合。

- 通年運用しない（毎年 1 月→4 月限定・通年は C1-5 に流す）

### §11. 広告ファネル計測 10 GA4 イベント（2026-05-27 新設）

広告 → 着地 LP → Web ジェネレータ体験 → PDF 出力 → 商品ページ遷移 → 購入 → リピートの全工程を GA4 イベントで計測。GTM 経由で実装。Meta Pixel・Google 拡張コンバージョン（SHA256 ハッシュ化メール送信）と連携する。

#### 11.1 イベント定義

| イベント名 | 意味 | 広告活用 | 期別主 CV |
|---|---|---|---|
| `lp_view` | LP 閲覧 | リターゲティング母集団 | — |
| `tool_start` | Web ジェネレータ起動 | 静かな開店期 主 CV | ✅ 静かな開店期 |
| `tool_config` | 点数／難易度選択 | 興味分類 | — |
| `generated_pdf` | PDF 生成完了 | 静かな開店期 主 CV | ✅ 静かな開店期 |
| `download_pdf` | PDF 保存 | 高意欲 | — |
| `product_recommend_click` | 商品ページ遷移 | 高意欲 | ✅ 静かな開店期後半 |
| `view_item` | 商品詳細閲覧 | リターゲティング | — |
| `add_to_cart` | カート投入 | 購入直前 | — |
| `purchase` | 購入 | 本格化以降 主 CV | ✅ 本格化〜春スパイク期 |
| `repeat_purchase` | 2 回目以降購入 | LTV 分析 | — |

#### 11.2 実装方針

- **GA4 + GTM** を中心に置き、Meta Pixel・Google 広告タグは GTM 経由で配置
- **Google 拡張コンバージョン**: 購入時にメール等のファーストパーティデータを SHA256 でハッシュ化して送信（Cookie 廃止対応・既存 CV 計測の補強）
- **計測実装 TODO** は [../engineering/README.md](../engineering/README.md) 参照

### §13. 広告 LP 7 セクション構成（2026-05-27 新設）

広告クリック → 着地 → Web ジェネレータ起動への最短動線。SEO 記事のように長くしない。親が広告から来た瞬間に知りたいのは「無料？すぐ使える？子どもは画面を見るの？印刷できる？」。

| § | セクション | 中身 |
|---|---|---|
| 1 | ファーストビュー | 「親が作って、子どもは紙で解く。無料の点描写問題ジェネレータ」 |
| 2 | 3 つの安心 | インストール不要／PDF で印刷／5×5 までのやさしい模写問題 |
| 3 | 使い方 3 ステップ | 点の数を選ぶ／難易度を選ぶ／PDF で印刷する |
| 4 | 対象 | 年中〜小2／公文前の 3 分／机に向かう前の紙ワーク |
| 5 | ブランド姿勢 | 焦らせない／できたを広げる（拡張語彙シフト [../foundation/voice-tone.md §1](../foundation/voice-tone.md)）／子どもは紙で取り組む |
| 6 | CTA | 「無料で 1 枚作る」（[ads.md §2](ads.md) 主 CV `tool_start`） |
| 7 | 有料 PDF への接続 | 「もっと選びたい方へ：タスク別・レベル別プリント」 |

**広告コピーの禁止語**: 「アプリ」「DL」「インストール」（[../foundation/voice-tone.md §7.1](../foundation/voice-tone.md)）。

### §14. サンクスページ設計（2026-05-27 新設・最重要勝負所）

PDF 生成後の完了画面が**広告回収のほぼ全てを決める**。ここをただの「ダウンロード完了」にすると有料商品に進まない。

#### 14.1 完了画面に置くべき導線

| 場所 | 表示内容 |
|---|---|
| PDF 出力直後 | 「この問題がちょうどよければ、次はこの 3 枚」 |
| 難易度別 | 「もう少し線の向きを増やすならレベル 2」 |
| タスク別 | 「模写に慣れたら、左右対称・回転へ」 |
| 商品ページリンク | 1 枚 ¥200、プレビューあり |
| セット提案 | 「年長さんのはじめの 5 枚」（バンドル SKU・[../product/pack-commerce.md §24](../product/pack-commerce.md)） |
| UGC/レビュー | ブロガー・モニターの声（[channels.md §3.4](channels.md) で獲得） |
| メール任意登録 | 「作った問題をあとで見返したい方へ、PDF リンクとおすすめレベル表をメールで送れます」（ゲートではなく追加価値として置く） |

#### 14.2 自己カニバリ回避設計

無料 Web ジェネレータは 5×5 まで・模写のみで正解（§2.1）。有料 PDF は以下で差別化:

- 9 タスク展開（[../product/pack-design.md §13.4](../product/pack-design.md)）
- レベル 5 まで
- デザインの整い
- 印刷品質
- レベル別の選びやすさ
- 左右対称・回転・複合課題
- 親向けの使い方ガイド

**役割整理**:
- 無料 Web ジェネレータ = 体験
- 有料 PDF = 選びやすく整った教材
- バンドル SKU（春 LP 連動）= 広告で一発回収するための ¥1,000-2,000 単位
