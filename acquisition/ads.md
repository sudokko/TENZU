# 広告運用設計

## サマリ

- 点図形（点描写）プリント専門店 TENZU の **広告運用 SSOT**
- **主軸**: Meta（Instagram 中心）＋ Google 検索広告のハイブリッド・Phase 1（仕込み）から両方投入
- **CV 地点**: Phase 1 〜 Phase 2 M2a は `generated_pdf`（Web ジェネレータの PDF 出力）／Phase 2 M2b 〜 Phase 3 は `purchase`
- **¥200 単品では広告回収不能**。LTV ¥1,000-3,000（5-15 枚継続購入）で回収する構造
- **Phase 別予算**: Phase 1 ¥10,000 → Phase 2 M2a ¥20,000-30,000 → Phase 2 M2b 春 LP 連動 ¥50,000-80,000 → Phase 3 ¥100,000+
- **副業運用枠**: 週 1-2h（オーガニック [channels.md](channels.md) とは別枠）
- **計測**: GA4 + GTM + Meta Pixel + Google 拡張コンバージョン（10 イベント定義は [funnel.md §11](funnel.md)）
- **広告内蔵 AI 文言生成は禁止**（[../foundation/voice-tone.md §7](../foundation/voice-tone.md)）
- **アプリインストール広告は不採用**（Web ジェネレータのため・URL クリックで即起動）
- **P-MAX は Phase 3 以降**（少額予算では学習不成立）／**Threads は Meta 配信面の拡張**として混ぜる
- **3 フェーズ統合（2026-05-28・[decisions.md §3.41](../decisions.md)）**: 旧 4 フェーズ（Phase 0/1/2/3）の段差は新 Phase 2 内の M2a/M2b マイルストーンとして表現

#### 1.2 Meta 主軸の理由

- Instagram の日本広告リーチは大規模（親世代に十分到達）
- A4 プリント・レベル差・紙で解く流れを視覚的に見せやすい
- Web ジェネレータの「触ってみたい」を作りやすい
- オーガニック（[channels.md §2](channels.md) Instagram）と広告の見た目を揃えやすい
- ブロガー UGC、カルーセル、リールと広告素材を共用できる
- LP 訪問者・Web ジェネレータ体験者へのリターゲティングがしやすい

**ただし Phase 1（仕込み）では購入最適化は弱い**（購入 CV が溜まっていない）。最初は購入ではなく `tool_start` / `generated_pdf` を中間 CV にする。

#### 1.3 Google 検索広告の役割

| 役割 | 内容 |
|---|---|
| 顕在層刈り取り | 「点描写 プリント」1,600/月・「点描写 無料」「点描写 問題」等の高インテント KW |
| SEO/LLMO の KW 検証 | 検索広告で反応した KW を SEO 記事化（「点描写 無料」で起動率が高ければ「無料 Web ツールと有料 PDF の使い分け」記事に寄せる） |
| 春スパイク刈り取り | 「入学準備 ドリル」320（春 880）・「年長 プリント」320・「小1 プリント」320 |

#### 2.1 Phase 1（仕込み・月 ¥10,000・検証）

| 項目 | 内容 |

| 主 CV | `tool_start` / `generated_pdf` |
| 配信 | Meta ¥6,000 ／ Google 検索 ¥3,000 ／ RTG ¥1,000 |

### §3. CPA / LTV 設計

#### 3.1 ¥200 単品の構造

- Stripe 国内カード決済手数料 3.6% = ¥7.2／¥200
- PDF 原価は実質ゼロ
- **広告前粗利 ¥190 前後**

| 条件 | CPA 上限 |
|---|---|
| 利益を残す | ¥50-100 |
| ほぼ損益トントン | ¥150-180 |
| 初回赤字許容 | ¥200 超 |

**結論**: 冷たい広告から ¥200 商品を CPA ¥100 以下で安定獲得は不可能に近い。単品ではなく LTV で回収する設計が必須。

#### 3.2 LTV ¥1,000-3,000 の現実性

5-15 枚購入。親が「この子に合う」と感じれば十分あり得るが、**導線設計が必要**。

| ステップ | 役割 |
|---|---|
| 無料 Web ジェネレータ | まず体験（[funnel.md §2](funnel.md)） |
| PDF 出力 | 印刷行動を起こす |
| 出力完了ページ | 有料 PDF への最重要導線（[funnel.md §14](funnel.md) サンクスページ設計） |
| 初回 PDF ¥200 | 購入体験 |
| レベル別おすすめ | 次の 1 枚を提案 |
| タスク別おすすめ | 9 タスク横展開 |
| 春/夏休み/入学準備セット | 複数枚購入（バンドル SKU） |
| リピート導線 | LTV ¥1,000-3,000 へ |

#### 3.3 LTV 別の許容初回購入 CPA

| 購入者 LTV | 粗利目安 | 初回購入 CPA の現実ライン |
|---:|---:|---:|
| ¥200 | 約 ¥190 | ¥50-100 |
| ¥1,000 | 約 ¥960 | ¥250-400 |
| ¥2,000 | 約 ¥1,920 | ¥500-800 |
| ¥3,000 | 約 ¥2,880 | ¥800-1,200 |

#### 3.4 Web ジェネレータ体験 1 件あたり期待売上（CPL 設計）

Phase 1 〜 Phase 2 M2a は LTV 未確定のため、Web ジェネレータ体験 1 件あたりの期待売上で判断する。

例: 体験者 100 人のうち 10 人が購入、購入者 LTV ¥1,500 なら
**体験者 1 人あたり期待売上 = ¥1,500 × 10% = ¥150**

→ `generated_pdf` 獲得単価の目安: ¥50-100、上限 ¥150 程度

| 体験→購入率 | 購入者 LTV | 体験者 1 人あたり期待売上 | `generated_pdf` 許容単価 |
|---:|---:|---:|---:|
| 3% | ¥1,000 | ¥30 | ¥10-20 |
| 5% | ¥1,000 | ¥50 | ¥20-40 |
| 10% | ¥1,500 | ¥150 | ¥50-100 |
| 10% | ¥3,000 | ¥300 | ¥100-200 |
| 15% | ¥3,000 | ¥450 | ¥150-300 |

**Phase 1 目標**: `generated_pdf` 単価 ¥150-400 以内。Phase 2（M2a/M2b）で購入導線を改善し、`generated_pdf` 単価 ¥100-200・購入率 5-10% を目指す。

### §4. クリエイティブ自動化

#### 4.1 Meta Advantage+ Creative / Shopping

| 工程 | 採用 | 理由 |
|---|---|---|
| 配信面の最適化（誰にいつ出すか） | ✅ Phase 1 から | 副業 1-2h 運用の支え |
| 見出し案の複数生成 | ✅ 人間が選定する前提 | 検証速度向上 |
| 背景色・サイズ展開 | ✅ | ブランド統一しやすい |
| 画像比率の自動調整 | ✅ | 工数削減 |
| 動画字幕案 | ✅ 誤字チェック必須 | 検証速度向上 |
| CTA 文の AB 案 | ✅ | 検証しやすい |
| 親子写真の AI 生成 | ❌ | 実体験投稿なし方針と矛盾・フェイク感 |
| 子どもが解いている風の AI 画像 | ❌ | 同上 |
| 発達効果を断定するコピー生成 | ❌ | 煽り・誤認・責任リスク（[../foundation/voice-tone.md §7](../foundation/voice-tone.md)） |
| 不安訴求の自動生成 | ❌ | ブランド原則と衝突 |
| 毎回雰囲気が違う広告の自動生成 | ❌ | 専門店感が崩れる |

**Meta 公表値**: 生成 AI 広告機能で平均 CTR +11%、CVR +7.6%（採用判断材料）。ただし TENZU では Phase 2 M2b 以降の補助としてのみ採用。

#### 4.2 Google P-MAX

Phase 1 〜 Phase 2 M2a では非推奨。以下の条件まで待つ:
- 購入 CV が月 30 件以上
- Web ジェネレータ体験者の購入率が見えている
- LP が少なくとも 2 種類ある
- 画像・短尺動画・商品プレビューが揃っている
- 自動生成動画を使わず、自前素材を入れられる

### §5. 広告 × オーガニックの相互作用

#### 5.1 信頼貯金ゼロで広告を打つと CVR が死ぬ

¥200 とはいえ子ども向け教材。親は価格だけでなく以下を見る:
- 無料プリントと何が違うのか
- 子どもに合う難易度か
- 印刷する価値があるか
- 親を焦らせる教材ではないか
- 子どもの個人情報を取らないか
- 変に "効果" を断定していないか

→ 広告で直接購入させるより、**広告で無料 Web ジェネレータを触ってもらい、信頼の階段を上がってもらう**設計。

#### 5.2 リターゲティング設計

| オーディエンス | 出す広告 |
|---|---|
| LP 訪問のみ | 無料 Web ジェネレータ訴求 |
| `tool_start` 済み未出力 | 「PDF で印刷できます」訴求 |
| `generated_pdf` 済み未購入 | 「次に合うレベル別 PDF」訴求 |
| 商品ページ閲覧未購入 | プレビュー・レビュー・¥200 訴求 |
| 初回購入者 | 次のタスク・レベル提案 |
| 複数購入者 | 季節セット・新作案内 |

詳細は [funnel.md §12](funnel.md)。

#### 5.3 広告 LP と SEO 記事のすみ分け

| 種類 | 役割 | CTA |
|---|---|---|
| 広告 LP | 迷わせず Web ジェネレータ体験へ | 無料で 1 枚作る |
| SEO 記事 | 検索意図に深く答える | 関連する無料ツール／商品 |
| 商品ページ | 購入前の不安解消 | PDF 購入 |
| Web ジェネレータ完了ページ | 有料 PDF への橋渡し | 次の 1 枚を見る |
| 春 LP | 季節需要の受け皿 | 新学年向けに作る |

### §6. リードマグネット運用

#### 6.1 メール獲得は必須化しない

| タイミング | メール獲得 |
|---|---|
| Web ジェネレータ起動前 | 挟まない |
| PDF 生成前 | 挟まない |
| PDF 出力後 | 任意で案内 |
| 商品購入時 | 取得（Stripe 経由自動・[funnel.md §8](funnel.md)） |
| 2 回目利用時 | 任意で保存／新作通知 |
| Phase 2 以降 | 「春の紙ワーク 5 枚セット」等で任意登録 |

**Why**: Web ジェネレータの強みは「URL クリックで即起動」。ここでメール必須化すると体験率が落ちる。メールはゲートではなく追加価値として置く。

例: 「作った問題をあとで見返したい方へ、PDF リンクとおすすめレベル表をメールで送れます」

#### 6.2 広告コピーの禁止語

| NG | 理由 |
|---|---|
| アプリ／DL ／インストール | Web ジェネレータをネイティブアプリと誤解させる |
| 小1 の壁／今すぐ／手遅れ／差がつく | [../foundation/voice-tone.md §1・§7](../foundation/voice-tone.md) 煽り NG |
| 集中力が伸びる／発達に効果／頭が良くなる | 断定責任リスク（Air Canada 事件型） |

詳細は [../foundation/voice-tone.md §7](../foundation/voice-tone.md)。
