#### 1.2 配分の根拠

**ストック × フロー × 信頼補強の三角形**:
- **ストック**（LLMO/SEO ＋ note）= 24h 自動集客。LLM が引用してくれれば寝てる間に CV する
- **フロー**（Instagram）= 春スパイク等のタイミング型瞬発力。①の流入が立ち上がる前の橋渡し
- **信頼補強**（DM ＋ X）= ①と②のクレジットを後ろから支える（被リンク・専門家ポジ・受動拾い）

**1 つのコンテンツを 3 媒体で再利用**: 記事 1 本書いたら IG カルーセル 1 本＋ X スレッド 1 本に分解。AI で素材変換できるため労力比は実質 1.4x で済む。これが週 3-5h で 4 チャネル回せる前提。

#### 1.3 「自分の家庭での実体験投稿は出さない」方針

オーナーの運営方針として確定。以下が連鎖変化:

| 影響 | 対応 |
|---|---|
| IG ストーリーズの「日常風景フォト」型は使えない | ストーリーズは「制作中の図形チラ見せ」「サンプル PDF 配布告知」「FAQ 回答」「アンケート」に振り替え |
| 拡張語彙ブログ記事の自伝口調は使えない | 「TENZU の設計思想として」「専門店の見解として」**三人称・プロダクト主語**で書く |
| UGC（使用シーン）は他家庭依存に純化 | モニター制度＋ブロガー DM を UGC 獲得装置として再設計（§3） |
| 正規ハブ・制作裏側（Future Fonts 型）・設計意図連載（Kurasu 型） | ✅ 実体験不要・全面採用 |

### §3. ブロガー/インフルエンサー DM 戦略

#### 3.1 配信先選定基準

**足切り条件**:
- ジャンルが知育・幼児教育・中学受験準備
- 直近 3 ヶ月以内に更新あり
- 点図形（点描写） or 類似ワードの記事がある
- 連絡手段がある（問い合わせフォーム、X、Instagram 等）

**優先度スコアリング（高い順）**:
1. ドメインパワー（DA/DR）→ DA 10〜40 の中規模が最も反応率高い
2. 記事の質・独自性
3. SNS フォロワー数（拡散力の目安）
4. 商品紹介の実績（紹介慣れしてるか）
5. **思想チェック**（過度な早期教育寄り・スクリーン依存でないか・スパルタ教育推奨でないか）← 人間が必ず目視

**やってはいけない**:
- スクレイピングツールで大量抽出 → 自動 DM フロー（Meta Integrity Ecosystem 制限対象・[../foundation/voice-tone.md §7.4](../foundation/voice-tone.md)）

#### 3.2 リスト作成方法

- ラッコキーワードで「点描写」「点つなぎ」「知育プリント」「知育 家庭学習」「幼児教育 プリント」の上位記事を抽出
- 個人ブログのみ（法人メディア除外）
- **50 件以上**をスプレッドシートで管理（名前・URL・DA・連絡先・ステータス）
- 返信率は **5〜8%** で計算（副業個人 DM の現実値）

#### 3.3 運用ルール

- **週 5 件ペース**（旧「1 日 3-5 通」から週次集約・副業現実線）
- 送信優先順: 問い合わせフォーム > Instagram DM > X DM
- 返信なしは 1 週間後に 1 回だけフォローアップ（2 回以上 NG）
- 返信率目標: 10〜15%
- DM 1 通目送付から **2 週間** で「実反応・社交辞令・無反応」を判定
- 社交辞令ゾーンは追撃せず、LP 常設の「発信者向け窓口」（隠しページ）からの自己エントリーを待つ
- **送信は 100% 人間**（AI 自動 DM 規制対象）

#### 3.4 UGC 獲得装置としての DM（2026-05-27 新規）

「自分の家庭での実体験投稿は出さない」方針のため、UGC 獲得を DM 戦略の主目的の 1 つに格上げ。

| 段階 | アクション |
|---|---|
| Phase 1 〜 Phase 2 M2a | ブロガー DM 1 通目で記事ハブ誘導＋無料サンプル提供 |
| 紹介発生時 | DM 2 通目（お礼）でモニター制度予告 |
| Phase 2 M2a 後半 〜 M2b | モニター提供→使用シーン写真／感想を許諾付き取得 → LP §14 サンクスページ・商品ページ・広告 LP に掲載 |
| Phase 3 | DM 3 通目で本リリース＋クーポン |

UGC 素材の取り扱いは [../foundation/voice-tone.md §7.5](../foundation/voice-tone.md)（マスキング・契約範囲）。

### §4. DM 3 通の構造（SSOT）

> ⏳ **コピー文（件名・段落文）はたたき台。本リリース前にユーザー側で書き直し。** 本節が SSOT 化するのは段落要素・トリガー・禁止事項・配信ペース・Stripe 設定の方。

#### 4.1 DM 1 通目: 記事ハブ誘導（Phase 1 配信開始・Phase 2 M2a まで継続）

P3 ブルーオーシャン C3-1「見取り図 描き方」記事ハブ＋ Web ジェネレータ（おためし点描写メーカー）併記での誘導。

| 要素 | 内容（たたき台） |
|---|---|
| 件名 | 「〇〇さんの『△△△△』を読み、家庭での点図形（点描写）について考えさせられました（TENZU 店主より）」 |
| 1 段落目 | 自己紹介（点描写プリント専門店 TENZU 店主） |
| 2 段落目 | 相手記事への具体的言及（テンプレ禁止・1 箇所以上必ず具体パートを引用） |
| 3 段落目 | TENZU の紹介＋記事ハブ誘導＋ Web ジェネレータ URL（無料・インストール不要を明示） |
| 4 段落目 | 「読者さんに役立ちそうと感じたら紹介してくれたら嬉しい／合わなさそうならスルー OK」 |

**要件**:
- 文字数：約 450 字（スマホ 1 スクロール強）
- 各送付先に対し、相手記事の具体パートに必ず 1 箇所以上言及
- 週 5 件ペース

**禁止事項**:
- 「アプリ」表記（Web ジェネレータをネイティブアプリと誤解させる・[../foundation/voice-tone.md §7.1](../foundation/voice-tone.md)）
- βテスト感（「最初の公開物」「開業前」など）
- 処方箋・特効薬・弱点診断等の NG 語彙（[../foundation/voice-tone.md §1](../foundation/voice-tone.md)）

#### 4.2 DM 2 通目: 紹介発生時の即時お礼（トリガー型）

「実反応」を起点に 24〜48 時間以内に送る。社交辞令は追撃しない。

**「実反応」の判定基準**:

| 項目 | 例 |
|---|---|
| a. 公開言及 | X/Instagram/ブログで TENZU・記事に言及 |
| b. 具体感想 DM | 「〇〇の記事を読んで子供と話しました」等 |
| c. 商品・記事への質問 | 「これってこういう使い方できますか？」等 |
| d. 自発的フィードバック | 「ここ改善した方が良さそう」等 |

「ありがとうございます」「確認しますね」レベルの社交辞令は **追撃しない**。

**段落構造（たたき台）**:

| 要素 | 内容 |
|---|---|
| 1 段落目 | 紹介への純粋な感謝＋具体言及 |
| 2 段落目 | 先行モニター予告：「先行モニター募集もしますので、ご興味あればその時にまた連絡させてください」＋ UGC（使用シーン写真／感想）提供の意向確認 |
| 3 段落目 | 軽い結び（プレッシャーゼロ） |

**禁止事項**: クーポン言及／フォロー強要／AI 自動応答

#### 4.3 DM 3 通目: 本リリース＋クーポン（Phase 3）

Phase 1 〜 Phase 2 で実反応をくれたインフル／ブロガーへ、本リリース通知＋読者向け「初回 1 本無料」クーポンコード配布。

**段落構造（たたき台）**:

| 要素 | 内容 |
|---|---|
| 1 段落目 | 本リリース報告＋過去紹介への謝意 |
| 2 段落目 | サイト・商品全公開告知＋¥200 一律の差別化説明 |
| 3 段落目 | 読者向け「初回 1 本無料」クーポンコード提案（コード文字列・使用上限 30 回・有効期限 60 日・対象 SKU = 単品全 140 SKU を明示） |
| 4 段落目 | ステマ規制対応依頼（「TENZU より読者特典として提供されたコードである旨の明記をお願いします」） |
| 5 段落目 | 「ご活用は任意・興味なければスルーで構いません」 |

**Stripe Promotion Code 設定**:

| 項目 | 設定 |
|---|---|
| Coupon 内容 | 100% OFF・1 SKU 限定 |
| Promotion Code 命名規則 | `[インフル識別子]-FREE`（例：`MAMABLOG-FREE`） |
| 使用回数上限 | コードあたり 30 回 |
| 有効期限 | 配布から 60 日 |
| 対象 SKU | 単品全 140 SKU（バンドル除外） |
| 1 人 1 回制限 | あり |

### §5. マルチプラットフォーム運用ルール

DM の返信率を上げる「同じ土俵の住人」認識を作りつつ、Instagram は集客主軸として運用。

| プラットフォーム | 役割 | 頻度（[ads.md §7](ads.md) 月次オペと整合） |
|---|---|---|
| Instagram | 集客主軸（§2.2 3 型併用） | 週 2-3 投稿＋ストーリーズ |
| note | 思想ハブ（§2.5） | 月 1 本 |
| X | PLG ＋専門家ポジ（§2.4） | 週 3 投稿 |
| Ameba ブログ | ブロガー連携の名刺＋ Ameba Pick 親和性 | 自社運用しない（連携専用） |

**リンクルール**:
- 全プラットフォームからのリンク先 → TENZU 公式サイトに統一
- プラットフォーム間の相互リンクはしない（note ↔ Ameba 等は NG）
- 各プラットフォームはそのプラットフォーム内で完結させる

**コンテンツの棲み分け**:
- テーマの重複は OK。ただし書き方・切り口を変える
- note = 設計論・思想・拡張語彙の言語化（三人称）
- Instagram = 選び方／制作裏側／UGC（§2.2）
- X = 制作ログ／論文要約／受動拾い向け短文
- 自社サイト = 記事 31 本＋商品ページ＋ FAQ（フル SSOT）

### §6. 広告運用

詳細 SSOT は [ads.md](ads.md)。本節は要点のみ。

- **主軸**: Meta Instagram ＋ Google 検索広告（Phase 1 から両方）
- **CV 地点**: Phase 1 〜 Phase 2 M2a は `generated_pdf` ／ Phase 2 M2b 〜 Phase 3 は `purchase`
- **Phase 別予算**: Phase 1 ¥10,000 → Phase 2 M2a ¥20,000-30,000 → Phase 2 M2b 春 LP 連動 ¥50,000-80,000 → Phase 3 ¥100,000+
- **¥200 単品では広告回収不能**。LTV ¥1,000-3,000 で回収する設計
- **副業運用枠**: 週 1-2h（オーガニックとは別枠）
- **広告内蔵 AI 文言生成は禁止**（[../foundation/voice-tone.md §7.2](../foundation/voice-tone.md)）
- **アプリインストール広告は不採用**

#### 7.2 工程別 AI 自動化レベル

| 工程 | AI 比率 | 人間が握る範囲 |
|---|---:|---|
| 記事/note 草稿生成 | 80% | 最終人格・事実チェック・引用論文の精査 |
| IG カルーセル画像（Canva Bulk Create） | 80% | 1 枚目訴求・煽り除去・親への敬意 |
| IG リール動画字幕／カット | 60% | 撮影・最終確認 |
| X 投稿草稿 | 90% | トーン最終チェック（30 秒/投稿） |
| ハッシュタグ/KW 調査 | 70% | Instagram 上の実検索・温度感目視 |
| 投稿スケジューリング | 90% | 投稿後 15-30 分の初動コメント確認 |
| DM 文面パーソナライズ | 50% | 相手投稿への具体的言及部分・送信 |
| インフル選定 | 60% | 候補出しのみ AI・選定／思想チェックは人間 |
| **コメント/DM 返信** | **0%** | **送信は 100% 人間**（[../foundation/voice-tone.md §7.3](../foundation/voice-tone.md)） |
| 競合分析 | 70% | 真似ない判断・倫理チェック |
| 計測・改善示唆 | 80% | 次週テーマ決定・捨てる施策の判断 |

### §8. 不採用チャネルと理由

| チャネル | 理由 |
|---|---|
| TikTok | 「再生回数アルゴ最適化」と TENZU の煽り NG・温度感が全面衝突／ノースクリーン軸と矛盾／公文家庭 30-40 代の主滞在は IG ＞ TikTok |
| YouTube 通常動画 | 動画編集が週 3-5h の副業枠を 1 本で食い尽くす／IG リール＋ Shorts 同投稿で代替 |
| YouTube Shorts 単独運用 | IG リール流用ゼロ編集での同投稿として配信のみ（[§2.2](##2.2-instagramg30%E3%83%BB3-型併用) リール）。単独運用しない |
| Threads 単独運用 | 日本国内 CV 未成熟（2 AI 一致）／ Meta 配信面の拡張として広告内で混ぜる（[ads.md §1.1](ads.md)） |
| Pinterest | 日本ユーザー数規模／副業運用負荷（2026-05-23 後半撤回・[decisions.md §3.33](../decisions.md)） |
| Twitter/X（広告） | ターゲティング精度低・¥200 単価との相性悪（オーガニック X は §2.4 で採用） |
| アフィリエイト ASP | 単価 ¥200 で ASP 報酬が成り立たない |
| 教育系イベント出展 | 副業で物理イベントは非現実的 |
| LINE OpenChat | 営業 NG 規約・コミュ追放リスク／使うなら LINE 公式アカウントで「無料サンプル配布→新作通知→再購入」に限定（Phase 3 以降検討） |
