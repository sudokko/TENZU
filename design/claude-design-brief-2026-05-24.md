# Claude Design ブリーフ — 案H'' ビジュアル再構築

**日付**: 2026-05-24
**目的**: 案W で確定した旧ビジュアル（4 ドット symbol／配色 navy `#3F475F` + cream `#FAF3EB`／Custom geometric sans-serif）を案H''（5 Pillar・3軸コンセプト）対応でフラット再検討
**期待出力**: 添付テンプレート（TENZU BRAND IDENTITY SYSTEM - CLAUDE DESIGN TEMPLATE）の **7 セクション構造をそのまま踏襲**。色とフォントは**複数案（最低 3 案ずつ）**を比較表で提示

---

## 1. BRAND CORE（案H'' 反映）

**TENZU**: specialized "点図形（点描写）プリント" store. 知育意識のある親（年中〜小2 × 3 セグメント：先取り知育／紙とペン重視／図形・書字に不安）向け

**MISSION**: 点描写を家庭の当たり前にして、空間認知の土台を持つ子を増やす

**BRAND PROMISE**: 子供の "空間認知の土台" を、家庭で無理なく育てる点描写プリント

**METAPHOR**: Dots, Paper, Figures（点・紙・図形）

**TONE**: Professional, Expert, Intellectual（プロ・専門家・知的）— but **同じ親の目線**（指導者ぶらない）

**FORMALITY**: 4/5。NO ゲーミフィケーション・NO キャラクター・NO 道場/塾感

**3軸コンセプト（新規・必須反映）**:

| 軸 | 表現 | 主な実装場所 |
|---|---|---|
| **書店** | 専門店としての端正さ・整列・棚のような余白 | `/products/`・ヘッダー・OG 画像 |
| **研究室** | 知的解像度・図表と注釈の端正な共存 | `/articles/`・evidence 引用ブロック |
| **親の手元** | 家庭で続く温度・余白・脅さない声かけ | `/for-parents/`・PDF フッター・完了画面 |

3 軸はサイト全体で常時混在ではなく、**ディレクトリ／コンポーネント単位で主役を切り替える**中庸トーン。

**Brand Pillars 5 本柱（視覚翻訳の指針）**:

| Pillar | 視覚翻訳 |
|---|---|
| P1 体系 | 9×5 グリッド・段階接続を示す直交格子 |
| P2 解像度 | サンプル開示の透過レイヤー・メタデータの可視化 |
| P3 発見 | ドットの組み替えから新しい図形が生まれる動的モチーフ |
| P4 言語化 | タスク × 能力対応表・図と注釈の端正な共存 |
| P5 継続（新設） | 余白を残した PDF レイアウト・親向け声かけブロック |

**Tagline 3 段セット**（ロゴと並置）:
1. コアタグライン：「点と点がつなげるようになったら、点描写を。」
2. サブコピー：「空間認知の土台をつくる。」
3. 業態識別句：「点図形（点描写）プリントの専門店 TENZU」

## 2. LOGO STRUCTURE（再検討）

**要件**:
- Symbol（シンボル単体）／Wordmark（TENZU 文字組）／Horizontal Lockup／Vertical Lockup の 4 構成は維持
- Symbol は **「点描写の起点」を象徴**する幾何要素（F3「形の向き・位置・大きさをとらえる力」を含意）
- モノクロ完全機能（主色単色で全要素成立）
- ファビコン極小サイズでも判読可能

**比較対象（旧 symbol）**:
- 旧 4 ドット symbol：正方形枠（22,22-78,78）＋ 四隅 4 ドット（r=6）。意味論「4 ドット = 点描写の起点／正方形線 = 点と点を結ぶ直線」
- 旧 symbol を**比較案として 1 つは含める**。**採用前提ではない**。新案 2 つ以上と並べて提示

**NG 方向性**:
- 旧案F「戻れる／ピンポイント／解像度」の視覚化（案H'' で全面降格）
- 中受 P3-a に寄せた表現（受動拾い LP 専用）
- 「街の選書本屋」メタファー（撤回済）
- キャラクター・マンガ寄り・ゲーム寄り
- ネオン・グラデ・写真合成

---

## 3. COLOR PALETTE（**最低 3 案を比較提示**）

**役割構造（厳守）**:
- **主色**（ロゴ・見出し・本文・線・主要 UI）
- **アクセント**（達成・注目限定：完了・選択中・CTA 最強・図形内一点強調）
- **背景**（サイト背景・PDF 背景・カード地色）

**原則**:
- 2 色基調 ＋ アクセント 1 色（4 色目以降は導入しない）
- モノクロ完全機能（主色単色で成立・PDF 印刷適性・色覚配慮）
- アクセントは「子の歓び・楽しい・わくわく」用途禁止（マスプリント回避）
- 3 軸コンセプト（書店・研究室・親の手元）のいずれにも振り切らない中庸
- PDF と画面の同一性（彩度抑えめ・印刷でくすまない範囲）
- **Anti-Brand**：ネオン・蛍光・グラデ・暖色装飾過多・キャラクター色 NG

**比較対象（旧案W・採用前提ではない）**:

| 旧役割 | 旧 HEX |
|---|---|
| 主色（鉄紺/Calm Navy Gray） | `#2B3D5A`（visual-identity）または `#3F475F`（旧 brand-spec） |
| アクセント（山吹） | `#D9A237` |
| 背景（生成/Premium Off-White） | `#F7F2E7` または `#FAF3EB` |

**期待出力**: 主色 × アクセント × 背景の組み合わせを **最低 3 案**。それぞれに「3 軸コンセプトのうちどれを主役に置いたか」「採用根拠」「PDF 印刷時の見え方の想定」を併記

---

## 4. FONTS（**最低 3 案を比較提示**）

**ロール構造（厳守）**:
- 見出し（端正・知的・装飾系/手書き風 NG）
- 本文（長文記事 18-20 本を読ませる日本語 long-form 可読性）
- 数字（Lv.1〜5・線本数・Vol. 表示頻出。日本語フォントの数字ではなく**専用欧文フォント**で力強さと精度）

**原則**:
- 3 軸コンセプトのいずれにも振り切らない
- ウェイト運用：太字訴求を避け、整列とサイズで階層を作る
- 混植耐性：日本語＋数字＋欧文略号の混在で破綻しない
- Web フォント可・**ライセンス商用 OK**（個人事業の継続可用性）
- **Anti-Brand**：丸ゴシック過多・教科書体・ポップ体・手書き風・装飾セリフ NG

**比較対象（旧案W・採用前提ではない）**:

| 旧ロール | 旧フォント |
|---|---|
| 見出し | Zen Kaku Gothic New |
| 本文 | Noto Sans JP |
| 数字 | Schibsted Grotesk |

**期待出力**: 見出し × 本文 × 数字の組み合わせを **最低 3 案**。それぞれに「組み合わせの根拠」「Wordmark で使う場合の最終フォント候補」「ライセンス情報」を併記

## 5. LOGO VARIATIONS

要件は旧テンプレ通り：
- Horizontal Lockup（ヘッダー・名刺・LP 上部）
- Vertical Lockup（パッケージ・PDF カバー・縦長広告）
- Symbol Only（ファビコン・極小サイズ・アプリアイコン）
- Wordmark Only（フッター・記事末尾の小サイン）

**新規追加要件（案H''）**:
- ロゴ ＋ Tagline 3 段セット並置版（LP ヒーロー用・OG 画像用）

## 6. BACKGROUND & METAPHOR EXPRESSION

**Subtle Watermark Grid**（旧仕様継承）:
- 控えめなドットグリッドをヒーロー領域や帯のみに使用
- 全面適用は禁止
- フェード（radial / linear）で端を抜く

**新規追加（P5 親の手元軸）**:
- PDF フッター用の **親向け声かけブロック装飾**（細枠線＋背景色で本文から軽く分離・脅さない温度）

## 7. DUAL APPLICATION

要件は旧テンプレ通り：

| 媒体 | 主用途 | 留意点 |
|---|---|---|
| Print (A4 PDF) | 商品本体（140 SKU + 9 混在セット） | 黒線中心・印刷適性・モノクロ完全機能 |
| Screen UI | LP・記事・商品ページ・おためし点描写メーカー App | 2 色基調・モバイル 7 割 |

**新規追加（案H''）**:
- **おためし点描写メーカー App** UI も Dual Application に含める（[brand.md §11.3.1](../foundation/brand.md)・親向け・5×5 上限・「作るのは画面、練習は紙」明示）
