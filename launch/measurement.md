# GTM 計測・KPI 計画

## サマリ

- 6ヶ月の KPI 計画を3シナリオ（好調/普通/最低）で設定。**普通シナリオが基準線**
- **起点は T=0 = 2026-08-30 開店**（[decisions.md §3.76](../decisions.md)）。月1 = 2026年9月・3ヶ月チェック = 11月末（本格化 Go 判定と同時）・6ヶ月チェック = 2027年2月末（春スパイク中）
- 絶対ルール：「右肩上がりなら辞めない」。判断は3ヶ月・6ヶ月のチェックポイントで行う
- CVR想定：PV→アプリ 10〜15% / アプリ→購入 **1.5〜2%**（サイト遷移＋外部決済のため）
- 広告は CVR検証ツールとして割り切る（ROAS で判断しない）
- 計測ツール：GA4・Stripe・Google Ads・MailerLite

## 詳細

### §1. 前提条件

| 項目 | 値 |
|---|---|
| パック単価（平均） | ¥400 |
| 広告予算 | 静かな開店期 ¥10,000/月（学習運転）→ 本格化 ¥30,000 → 春スパイク期 ¥50,000-80,000（[ads.md §2](../acquisition/ads.md)） |
| 広告配分 | 新規 60〜70% ＋ リマーケティング 30〜40% |
| SEO本格効果 | 3ヶ月目以降（=11月以降。春スパイクに熟成が間に合う設計） |
| ブロガー記事 | 静かな開店期で 3〜5本公開想定 |

#### CVR想定

| ステップ | 値 | 算出根拠 |
|---|---|---|
| PV → アプリ | 10〜15% | 連載コンテンツ × アプリ動線設計の前提値 |
| アプリ → 購入 | **1.5〜2%** | サイト遷移→商品理解→Stripe決済の多段ステップを考慮したフリーミアム転換率の現実値 |

### §4. チャネル別貢献割合（仮説）

| チャネル | PV貢献 | 備考 |
|---|---|---|
| SEO（自然検索） | 40〜50% | 主力。3ヶ月目以降に本格化 |

| プレスリリース | 初月のみ | 一時的スパイク |

### §5. 判断基準

#### 5.1 月次チェック

- 前月比で右肩上がりか → YES なら継続
- 横ばい or 微減 → 原因分析（導線？コンテンツ量？広告設定？）
- 2ヶ月連続で下降 → 抜本的な見直し

#### 5.2 3ヶ月チェックポイント（2026年11月末・本格化 Go 判定と同時に実施）

| シナリオ | アクション |
|---|---|
| 好調ライン到達 | リマーケティング比率を拡大＋パック追加に集中 |
| 普通ライン | 現状維持。連載コンテンツ追加＋ブロガーDM追加 |
| 最低ライン | ボトルネック特定（導線？価格？コンテンツ？CVR改善余地？） |

#### 5.3 6ヶ月チェックポイント（2027年2月末・春スパイク中に実施）

| シナリオ | アクション |
|---|---|
| 好調 | 規模化施策開始（広告 ¥100,000+ は [ads.md §2.5](../acquisition/ads.md) の移行条件成立後・Instagram 本格運用拡張・新規 SKU 追加等） |
| 普通 | 継続。連載コンテンツの充実＋SEO記事追加で年内 ¥10,000/月 到達を目標 |
| 最低（右肩上がり） | 継続 |
| 最低（横ばい） | 方向転換を検討 |

#### 5.4 広告の判断ライン

広告の主目的は CVR検証。ROAS で増額/縮小を判断するのではなく、「学び」の有無で判断する。

| 判断 | 条件 | アクション |
|---|---|---|
| 継続 | リマーケティング経由の購入が月1件以上 | ¥10,000/月 を維持、KW 最適化 |
| 配分変更 | 新規 CPC が高騰 or CVR 低迷 | リマーケティング比率を 50% に引き上げ |
| 縮小 | 3ヶ月でデータ十分（CVR・KW の傾向が見えた） | ¥5,000/月 に縮小 or 停止、SEO に集中 |

#### 5.5 絶対ルール

**右肩上がりなら辞めない。** 最低6ヶ月は続ける。ニッチ市場は立ち上がりが遅い代わりに、ポジション取ると安定する。

### §6. 計測ツール

| 指標 | ツール |
|---|---|
| PV・流入元・ユーザー行動 | Google Analytics 4 |
| アプリ利用数 | GA4 イベントトラッキング |
| 購入数・売上・顧客メアド | Stripe ダッシュボード |
| 広告 ROAS | Google Ads 管理画面 + Stripe 突合 |
| メール配信効果（開封率・クリック率） | MailerLite 管理画面 |
