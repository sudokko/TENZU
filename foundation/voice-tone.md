## 詳細

### §1. Voice NG/OK

#### 表現置換ルール

| 強すぎる表現（NG） | TENZU 流置き換え（OK） |
|---|---|
| 処方箋／特効薬／治療 | 練習プラン／戻り道／次の一手 |
| 弱点診断／健康診断／自己診断 | レベル選びガイド／レベル相談／はじめる位置の目安 |
| 穴を埋める | 抜けを補う |
| ピンポイント治療 | ピンポイント練習 |

**注記**: 旧「スタート診断」表現も廃止（「診断」語彙を概念レベルで Anti-Brand 化したため）。「自己診断ツール」というプロダクト名は **「レベル選びガイド」** に統一（brand.md §11.1・§11.3 参照）。

#### 時間軸の煽り NG

- 「○年生で差がつく」「手遅れになる前に」「もう間に合わない」型は使わない
- 代わりに「いつからでも戻れる」「ここから整える」「今の地点から始める」

#### 修行・道場語彙 NG

- 「鍛える」「修行」「特訓」「猛特訓」「克服」「習得」「叩き込む」のような強い達成語は控えめに
- 代わりに「育てる」「身につける」「慣れる」「できるようになる」

#### 点つなぎを下に見る表現 NG（案H 新規）

啓蒙ブランドは「点つなぎより点描写の方が良い」と語りたくなるが、TENZU は**点つなぎを否定せず階段で位置づける**（brand.md §17）。

| NG | OK |
|---|---|
| 点つなぎでは物足りない／点つなぎでは効果が薄い | 点つなぎを楽しんだ後に／点つなぎを完走したら |
| 点つなぎを卒業しよう／点つなぎはもう古い | 点つなぎの次に、点描写を |
| 点つなぎは遊び・点描写は本物 | 点つなぎは楽しさと運筆／点描写は能力向上、と役割が違う |

#### 啓蒙の飛躍 NG（案H 新規）

一次資料の引用範囲を超える主張は書かない（[evidence.md §6](../content/evidence.md)）。

| NG | OK |
|---|---|
| 点描写をやれば算数が伸びる | 視覚空間スキルは算数達成と関連することが、複数の研究で示されています |
| 点描写は漢字書字の特効薬 | 視覚空間処理は漢字の習得を支える認知的な土台のひとつとされています |
| 点描写をやらないと土台ができない | 点描写は空間認知を育てる練習のひとつです |

#### 予防語彙 → 拡張語彙シフト（案H'' 新規）

Gemini が独立指摘した「**『空間認知は算数達成に効く』という事実そのものが、親の焦りを誘発する構造を持つ**」課題への対応。クッション言葉を足しても、受け手が「やらないと手遅れ」と勝手に変換するリスクは消えない。**主語を「欠落の予防」から「可能性の拡張」へシフト**することで、構造レベルで煽りを回避する。

| 軸 | NG（予防・欠落フレーム） | OK（拡張・獲得フレーム） |
|---|---|---|
| 図形 | 図形でつまずかないために／図形が苦手にならないように | 図形を頭の中で自由に動かせるように／図形の見え方を広げる |
| 漢字 | 漢字が崩れる前に／書字でつまずかないために | 漢字の形を捉える力を育てる／字形の解像度を上げる |
| 算数 | 算数で取りこぼさないために／○年生で差がつく前に | 算数の見通しを持てるように／数と図形の橋渡しを育てる |
| 効果 | ○○に効く／○○の予防になる | ○○の土台になる／○○を支える要素のひとつ／○○を広げる |
| 動機 | やっておかないと後悔する | 子の中にひとつ"見える道具"を増やす |

**運用ルール**:
- 啓蒙記事の本文・LP の主訴求は**拡張フレーム**を基本にする
- 「予防」「対処」「リスク」型の語彙は**受動拾い対処層向け LP・FAQ・記事**でのみ使う（§2 の場所別比率と整合）
- 「効く」「予防になる」「対策になる」を反射的に書きそうになったら、まず「**○○の土台になる／支える／広げる**」で書き直せないか試す
- 一次資料の引用範囲（[evidence.md §6](../content/evidence.md)）を超えないことは前提

#### 4 群命名規範：動詞ベース・教育用語直接 NG（2026-05-27 確定）

9 タスクを束ねる 4 群（顧客導線軸）の SSOT 命名は [pack-design.md §13.7](../product/pack-design.md) で確定済み。**親が子どもに口にできる粒度の動詞ベース**を採用し、教育・心理学の専門用語を**そのまま**ラベル化することを禁ずる。

| 群 | OK（SSOT 確定・動詞ベース） | NG（教育用語直接型） |
|---|---|---|
| A | **見て写す** | 観察 |
| B | **かたちを動かす** | 変換 |
| C | **重ねる・分ける** | 構成・合成 |
| D | **立体でとらえる** | 立体 |

**禁ずる理由**:
- 「観察 / 変換 / 構成 / 立体」は研究・教科書語彙で、親が日常で子どもに言わない硬さ。Brand Voice（親が子に寄り添う温度）と乖離する
- 「変換 = transform」は心理学・数学用語。「かたちを動かす」が機能の本質を残しつつ温度を出している
- 「観察」は §13.6 F3 三要素（向き／位置／大きさ）の**内部辞書側のラベル**であって、顧客語ではない。両者を混同しない

**運用ルール**:
- LP §2・商品一覧ナビ・breadcrumb・Chip・Pillar row 等、**顧客が触れる全レイヤー**で SSOT 動詞ベース表記を使う
- 内部資料・§13.6 内部辞書では教育用語（観察／変換等）を引き続き使って良い。顧客接点だけ動詞ベースに翻訳する
- Design AI／実装者へのブリーフでは**必ず §13.7 の確定表を同梱**する。「使いやすい群名にしてください」と依頼すると教育用語に流れる傾向あり

**経緯**: [decisions.md §3.38](../decisions.md)

#### SEO 例外運用ルール

NG 語彙でも、検索クエリとしては親が実際に打ち込んでいる現実がある（「弱点診断」「図形 苦手 処方箋」等）。流入機会を完全に捨てるのは V2 顧客受け取り価値ファーストと矛盾する。以下の限定運用を許容する。

**許容される使い方（記事のみ）**:
- 記事の**冒頭 1段落**で「『弱点診断』『処方箋』というキーワードでたどり着いた方へ」のような寄り添い文として、**クエリの引用**として使う
- 即座にブランド側の表現へ転換する

**禁止される使い方**:
- H1・タイトルでの使用（記事タイトル・LP H1・カテゴリ名）
- CTA ボタン・ナビゲーション文言
- 本文中で TENZU 自身が自己表現として使う（「TENZU の弱点診断」のような形）
- meta description の主文（補助句としてのみ可）

#### SEO 例外運用の固定テンプレ（自由記述禁止）

AI 記事生成・量産時のブレを防ぐため、SEO 例外を使う場合は**以下の固定テンプレ文のみ**を使う。テンプレを変えたい場合は本ドキュメントの改訂が必要。

> 「弱点診断」や「処方箋」という言葉で探している方もいるかもしれません。TENZU では、お子さんを判定するのではなく、**今の地点から始めやすい一枚を選ぶこと**を大切にしています。

このテンプレに含まれる NG 語彙（「弱点診断」「処方箋」）は**鉤括弧で引用** + **即座にブランド側転換**の 2 要素を必ず守る。

#### コピー強度マトリクス

煽らないブランドだからこそ、コピーの強度管理が必要。「弱すぎる」と CV が落ち、「強すぎる」と V1 を破る。記事執筆・LP 設計時は次の表に照らす。

| 強度 | 例 | 判定 |
|---|---|---|
| 強すぎる | 図形が苦手なままだと手遅れに／○年生で差がつく前に | **NG** |
| やや強い | 図形で手が止まる前に／焦らないうちに | 要注意（記事冒頭の寄り添いパートでのみ可） |
| **適正** | 今の地点から始める／一枚から試す／一つ下のレベルに戻る | **OK（推奨）** |
| 弱すぎる | よろしければご覧ください／ぜひお試しください | CV 弱い・NG |

「適正」帯のフレーズが TENZU の標準。AI 生成物のレビュー時は、CTA・H1・本文サマリがこの帯に収まっているかを必ず確認する。

#### 「空間認知」公式訳の初出併記ルール（案H'' 新規・F3 確定）

「空間認知」は TENZU の中核概念だが、親層には抽象度が高すぎる。**初出箇所では必ず公式訳を併記**する。

**公式訳（SSOT）**:

> **空間認知 ＝ 形の向き・位置・大きさをとらえる力**

**Why**:
- 視覚空間能力（visuospatial ability）の主要素（方向／位置／大きさ）と整合・[evidence.md](../content/evidence.md) と矛盾なし
- TENZU の 9 タスク全部に対応（模写=位置／線対称・回転=向き／拡大縮小=大きさ／立体=3 要素全部）
- 「とらえる」は静かで Anti-Brand 適合（「鍛える」「叩き込む」を排除）
- LLM 引用しやすい（「TENZU の言う空間認知とは…」と AI が定義をそのまま引用できる構造）

**併記ルール（運用）**:

| 場所 | 併記方法 |
|---|---|
| LP ファーストビュー直下 | FV 一文の直後に解説ブロックで併記必須（[brand.md §10.1 F1](brand.md) の FV 解説と整合） |
| 記事 H1 直下 | 初出段落で `空間認知（＝形の向き・位置・大きさをとらえる力）` の形で必ず併記 |
| FAQ 初出箇所 | 同上 |
| 商品ページ・ナビゲーション | 紙幅が許せば併記。困難な場合はリンクで公式訳ページに飛ばす |
| 2 回目以降 | 同一ページ内では「空間認知」単独で OK |

**禁止**:
- 「空間認識能力」「視覚空間スキル」「ビジュアル・スペーシャル」等の別語彙への流用（混乱を招く）
- 「鍛える」「強化する」「磨く」など達成語との接続（「とらえる」「育てる」「広げる」「身につける」と接続）

#### 🔴 看板語彙の用途分け（フロント／図形文脈／学術 RTB の3層）

コンセプト §0「考えながら書く力」の確定（[decisions.md §3.62](../decisions.md)）に伴い、旧「フロント＝図形の基礎力」2層ルール（§3.36）を 3 層へ改定。

**運用ルール**:

| レイヤー | 採用語 | 使用場所 |
|---|---|---|
| **フロント（看板）** | **見て、考えて、書く力**（コアタグライン）／考えて書く力 | 広告コピー・初回購入導線・OG タイトル・LP Hero サブ位置（Hero H1 は業態主役「点描写プリントの、専門店です。」維持＝[decisions.md §3.39](../decisions.md)） |
| **図形文脈** | **図形の基礎力**／図形の土台／図形に強くなる／「図形の基礎は、点描写から。」（降格コア） | 図形系 LP（S-c）・図形系記事まとめ・商品サムネキャッチ・学校算数/中受受動拾い近傍 |
| **学術 RTB（裏付け）** | **空間認知の土台**／空間認知を育てる | LP 効能セクション・記事 H2-2 以降・PR 文・LLMO 引用・evidence.md・専門家向け説明 |
| **橋渡し併記** | 「考えて書く力・図形の基礎力＝空間認知の土台」 | LP 中盤の RTB 開示・FAQ「Q. なぜ図形や文字につながる？」 |

**Why**:

- 主戦場＝就学前後（年長〜小1前半）の親の現在の関心は「書く準備」。「図形」は小1後半以降に現在形になるペインで、フロントと図形文脈を年齢レイヤーで分担する（[brand.md §0/§12](brand.md)）
- 「空間認知」は親への翻訳負荷が高く看板に不向き・専門性と LLM 引用獲得には最強、という §3.36 の判断は不変
- TENZU の SKU は実態として「考えて書く行為の変奏カリキュラム」であり、看板（書く力）・図形文脈（図形の基礎力）・裏（空間認知）の三段は実態と整合

**禁止**:

- LP Hero・広告に「空間認知」を看板として置くこと・初回購入 CTA に「空間認知」を主語で使うこと
- 商品ページ「主に伸びる力」に「空間認知」だけを書くこと（フロント語 or 図形文脈語との併記が原則）
- 「書く力」を作文・記述指導の意味で使うこと（「見て」「写す」等の視写文脈を必ず伴わせる）
- 「点つなぎ・運筆は考えていない」型の比較（§1 点つなぎルールと同型・運筆にも適用）
- 「**算数の壁を越える**」「**○年生で差がつく**」「**入学までに**」等の煽り型は引き続き NG（拡張フレーム維持）

**禁止**:

- ロゴ・ヘッダー・OG で「TENZU」単独表示
- 「TENZU」ローマ字単体での 1 行ヘッダー
- descriptor の省略・縮約（「点描写ストア」「点プリント」等の俗称化）

**Why**:

- 「TENZU」は造語感が強く、初見の意味整合性が弱い（「点図形」も「点描写」も自動連想されない）
- 日本酒「天美 TENBI」のような既存ブランド衝突を避ける意味でも、業態 descriptor で TENZU の独自性を明示する必要あり
- ブランドナラティブ（「点と点をつなげると頭の中に図が構築される」）は About で語り、descriptor は毎接触点で繰り返す

#### 「空間認知」と「空間認識」の使い分けルール（2026-05-25 新設）

ラッコ実測で「空間認識」族のほうが**5倍以上**のビッグワードであることが判明（空間認識能力 **9,900/月**・競合性 0／空間認知能力 1,900/月）。一方、購買意図のある「**空間認知 プリント** 320/月・競合性 1」は「認知」族に集中。**用途で完全に使い分ける二刀流運用**を採用。

**実測ハイライト**（[keyword-research.md §10.5](../content/keyword-research.md) 参照）:

| 語族 | 主要語 | VOL/月 | 親意図 |
|---|---|---:|---|
| 空間認**識** | 〜能力／鍛える／低い／テスト／診断 | 約 15,000+ | 自己診断・大人・スポーツ・運転（TENZU 縁遠い） |
| 空間認**知** | 〜能力／プリント／トレーニング | 約 5,000 | 教育・知育・**プリント探し**（TENZU 直結） |

**運用ルール**:

| 場所 | 採用語 | 補足 |
|---|---|---|
| **ブランド軸**（MISSION・brand.md・サブタグライン・About） | **空間認知** 固定 | F3 公式訳「形の向き・位置・大きさをとらえる力」と必ずセット |
| **LP Hero（H1・サブ）** | H1=業態主役・サブ=**見て、考えて、書く力**（コア） | 「空間認知」は Hero に置かない（学術 RTB 層へ） |
| **商品ページ・FAQ・サンプル・voice** | **両方併記**「図形の基礎力＝空間認知の土台」 | 購買検索層は「認知」族 |
| **P4 啓蒙まとめ C4-2「子供の空間認識能力を育てる」H1・冒頭** | **空間認識** 許容（SEO 例外） | 流入母数 9,900/月を取りに行く。本文 1 段目で「教育心理学では『空間認知』と呼ばれます」とブランド語へブリッジ必須 |
| **C4-2 本文 2 段目以降** | **空間認知** へブリッジ済み | 以降は「空間認知」固定 |
| **LLMO 専用記事 L-2** | **両方併記**＋違いの FAQ 必須 | ChatGPT/Gemini の引用源を押さえる・FAQPage Schema 厳密実装 |
| **他の記事 H1（C4-1 効果・C4-3 プリント・C3-x 等）** | **空間認知** または **図形の基礎力** | H''' で「空間認識」H1 採用範囲を C4-2 と L-2 に限定（範囲縮減） |

**禁止**:
- ブランド軸の語彙（LP Hero／MISSION／About／商品説明）に「空間認識」を流用しない
- 「空間認識能力 低い」「病気」「発達障害」「脳梗塞」「認知症」など**不安煽り・医療文脈・大人向け検索**は啓蒙記事 H1 に出さない（汚染ゾーン回避）
- 「空間認識」をブランド側の自己表現として使う（「TENZU は空間認識を…」型は禁止）

**Why**:
- ブランド整合（MISSION・evidence.md 学術 SSOT が「空間認知」採用）と SEO 流入（「空間認識」族 9,900）の両取り
- voice-tone.md §1 既存「SEO 例外運用ルール」と思想一致（NG 語彙をクエリ引用としてのみ許容）
- LLMO で AI が「違い」を聞かれた際の引用源として TENZU が**両方をブリッジする立場**を取る戦略

### §2. 温度設計（ページ種別ごと）

#### 温度レベルの定義

「企業並みの端正さ」と「個人運営の温度」を場所で使い分ける。

| ページ | 温度 | 方針 |
|---|---|---|
| LP | 中 | 専門性を主軸に、少しだけ親向けの安心感 |
| 商品一覧 | 低 | 比較・選択・価格・レベルが最優先 |
| 商品詳細 | 低〜中 | 教材品質、対象、使い方、サンプルを明快に |
| カート・決済 | 最低 | 無駄な情緒は入れない |
| FAQ | 低 | 不安解消に徹する |
| 法的ページ | 最低 | 完全に事務的でよい |
| 記事 | 中〜高 | 根拠を持った親の語り口を出す主戦場（同じ親として先に気付いた立場・選択理由を静かに開示する） |
| About | 高 | 個人運営の思想・動機を出す |
| 完了画面 | 中 | やさしい一文を添える |
| サンクスメール | 中 | 事務連絡＋少しだけ温度 |

#### 場所別 予防：啓蒙：対処 の3軸比率（案H・3軸化）

ペルソナ層・ページ種別によって「**予防**（早期から備える）」「**啓蒙**（点描写の価値・空間認知を広く伝える）」「**対処**（すでにつまずいた）」の3軸でメッセージ比率を調整。案H で**啓蒙軸を主**に据えたため、旧2軸（予防：対処）から3軸へ拡張。

**LP は1枚にせず、ブランドトップと獲得 LP を分けて獲得側を尖らせる**のが原則は維持。

##### ブランドトップ・共通 LP

- **ブランドトップ**: **3:5:2**（啓蒙を主・予防と対処を両翼に）

##### 獲得 LP（ターゲット別・尖らせる）

- **公文家庭 LP**（P-公文-a 旗艦）: **3:6:1**（啓蒙寄せ・「公文の図形補填」軸／タグライン「計算の次は、点描写を。」）
- **ノースクリーン LP**（P-知育-a / 知育志向）: **2:7:1**（啓蒙寄せ・「画面のない時間に、点と点を。」バリアント）
- **中受獲得 LP**（受動拾い P3-a）: **2:2:6**（対処寄せ・旧コア「図形に、戻り道を。」を限定運用）
- **学校算数獲得 LP**（受動拾い P2-b）: **3:3:4**（対処寄り・宿題で揉める／親が教えると喧嘩文脈）

##### 記事

- **啓蒙記事**（点描写の価値・コグトレ文脈・空間認知）: **1:8:1**（啓蒙ど真ん中）
- **公文家庭向け記事**: **3:6:1**
- **ノースクリーン記事**: **2:7:1**
- **中受記事**（受動拾い）: **2:2:6**
- **学校算数記事**: **3:3:4**

> 注意：「ブランドトップを獲得 LP として兼用する」は禁止。複数セグメントを 1枚で同時に説得しようとすると、すべてに薄まる。
> 啓蒙軸の本領は**記事**にある。LP は購買判断に寄せ、記事は価値の言語化に寄せる、と役割分担。

### §3. 語り手の立ち位置

#### 根本姿勢

「専門家が上から教える」ではなく「**同じ親として、先に気付いた立場**で語る」（brand.md §4 Brand Story・§9 P3 と整合）。

具体的には：
- 「お子さんは…」と読者の子を客体化せず、「うちの子も…」「私も知らなかったが…」と並走する
- 「正しいやり方は X です」と断定せず、「TENZU では X を選んでいます。理由は…」と選択の根拠を開示する
- 「専門的に言うと…」「研究によると…」のような権威付けは最小限。論文引用は出典明示でクールに（権威マウントしない）

#### 一人称使い分け

屋号「TENZU」を一人格化し、場面別に主語を固定：

| 場面 | 主語 |
|---|---|
| 商品説明 | TENZU は |
| 記事 | TENZU では |
| About | TENZU は、点図形（点描写）を… |
| FAQ | TENZU では、以下のように… |
| メール | TENZU をご利用いただき… |

「私」「制作者」「運営者」は About の一部のみ許容。基本は屋号で立てる。

#### About での「私」と屋号の境界

About ページでは「TENZU というサービス人格として語るパート」と「運営者個人として語るパート」を**構造的に分離**する。混在させると読者の認知にノイズが走る。

- **TENZU として語る部分**: ページ冒頭の自己紹介・サービス紹介・コンセプト解説。主語は「TENZU は…」
- **運営者個人として語る部分**: 屋号語源・原体験・なぜ始めたか。段落の冒頭に**「以下、運営者個人として一言」**のような区切り見出しを明示し、その範囲内でのみ「私」を許容
- 区切りなしで「TENZU は…私が…TENZU では…」と混在させない

### §4. 期別の温度デチューン

最初から完全実装すると重いので段階的に：

- **開店〜静かな開店期前半**: 端正さを優先。サイト本体・商品ページ・開店時公開 12 本で専門性を確立。完了画面だけ少し温度
- **静かな開店期後半（10-11 月）**: 記事群（週 1 段階公開の積み上がり）と About で屋号人格を育てる（公開後モニターの FB 反映 Lead 文言を含む）
- **本格化以降（12 月〜）**: サンクスメール、レベル相談まで温度を拡張
- Web ジェネレータ（おためし点描写メーカー）は開店時から常設（[brand.md §11.3.1](brand.md)）。Web ジェネレータ体験の温度設計は §11.3 を参照

### §5. 表記階層化「点図形（点描写）」

| 文脈 | 表記 |
|---|---|
| 屋号紹介・LP H1・About 本文冒頭・記事 H1 | **点図形（点描写）** 並記 |
| 記事 H2 以降・本文中の概念語 | **点図形** 優先（文脈で読みづらければ「点描写」可） |
| 商品ジャンル名・カテゴリ・SKU 表記 | **点描写プリント** 維持（市場文脈・比較対象との整合） |
| meta description・タグ・OG タイトル | **点描写** 厚め（SEO 担保） |
| URL スラッグ | 既存維持（`point-drawing-*` は変更しない） |

- 主語＝**点図形**／副記＝**点描写**
- 屋号紹介・LP H1・記事 H1／H2・About では「点図形（点描写）」と並記、本文導入で 1回切替宣言してそれ以降はどちらかに統一可
- 「『点図形』語彙の SEO 併用網羅は不採用」は引き続き有効（全 KW 総ナメはしない・屋号レベル並記のみ追加）

### §6. 温度を出す具体4箇所（キャラ不採用との整合）

[brand.md](brand.md) §9 でブランドキャラクター不採用を確定。代わりに以下 4箇所で温度を出す：

1. **記事の語り口**: §3 の「同じ親として先に気付いた立場」を文体に滲ませる
2. **マイクロコピー**: ボタン文言・完了画面・空状態メッセージで人格を出す
3. **幾何グラフィックのアニメーション**: 点と点が静かにつながる等の動き
4. **About・制作ノート**: 個人運営の思想・動機を率直に開示

### §7. acquisition 運用 NG（2026-05-27 新設）

acquisition の 4 チャネル＋広告軸（[../acquisition/channels.md](../acquisition/channels.md)／[../acquisition/ads.md](../acquisition/ads.md)）を回す際に、ブランド毀損・法的責任・プラットフォーム規制違反を防ぐ運用 NG ルール。2 AI DR 合議結果（Gemini ＋ ChatGPT・①②③④）反映。

#### 7.1 広告コピー NG

| NG 語 | 理由 | 代替 |
|---|---|---|
| **アプリ／DL ／インストール** | TENZU の Web ジェネレータをネイティブアプリと誤解させる。親が「ストアからダウンロード」と読む | 「ブラウザで使える」「インストール不要」「URL を開くだけ」 |
| **小1 の壁／今すぐ／手遅れ／差がつく** | §1 煽り NG と整合。広告で特に出やすいため再掲 | §1 拡張語彙シフト表に従う |
| **集中力が伸びる／発達に効果／頭が良くなる／IQ が上がる** | 教育効果の断定責任リスク（Air Canada チャットボット事件型・誤認表記法的責任） | 「形の向き・位置・大きさをとらえる練習」「紙で考える時間を整える」 |

#### 7.2 広告プラットフォーム内蔵 AI 文言生成 NG

Meta Advantage+ Creative ／ Google Ads 生成 AI ／ Performance Max の自動生成見出し・自動生成画像 機能で**テキスト/画像をプラットフォーム任せに生成することは禁止**。

| 何が問題か | 具体例 |
|---|---|
| 煽り文言が生成される | 「小1 の壁！今すぐやらないと手遅れ！」型を AI が反射的に出す |
| 不自然な彩度の AI 画像が出る | フェイク感が「専門店の静かな統一感」を破壊 |
| 子ども風の AI イラスト・親子写真風素材 | 実体験投稿なし方針（[../launch/phases.md](../launch/phases.md)）と矛盾し、実在家庭っぽいフェイク感が出る |

**例外**:
- **見出し案の複数生成**（人間が選定する前提）は OK
- **背景色・サイズ展開・画像比率の自動調整**は OK（ブランド統一済テンプレを変えない範囲）
- **動画字幕案の自動生成**は OK（誤字チェック必須）

詳細は [../acquisition/ads.md §4.1](../acquisition/ads.md)。

#### 7.3 コメント／DM の AI 自動応答 NG

**Air Canada チャットボット事件**（2024 年・チャットボットが誤情報を提供したことについて企業責任が問われた判例）型のリスクを回避。教育・子ども領域では誤情報の責任が特に重い。

| NG（自動応答が出しがちな例） | 代替（人間が手動で返す） |
|---|---|
| 「5 歳ならこのレベルで大丈夫です」 | 「最初は『少し簡単に感じる 1 枚』からがおすすめです。年齢だけでなく、点の数や線の向きで選べるようにしています。」 |
| 「集中力が伸びます」 | 「TENZU は『形の向き・位置・大きさをとらえる練習』として設計しています。」 |
| 「発達に効果があります」 | 「視覚空間処理は漢字や図形の習得を支える認知的な土台のひとつ、と研究では示されています」（§1 啓蒙の飛躍 NG と整合） |

**運用ルール**:
- DM・コメント返信の**送信は 100% 人間**
- AI は**下書き作成のみ**OK（Claude / ChatGPT で草稿 → 人間が NG 表現を grep して送信）
- FAQ 定型文の作成は OK（送信前に必ず人間が最終確認）
- 自動応答ボット（Chatbase 等の AI チャットボット）を商品ページ・LP に置かない

#### 7.4 自動 DM・自動フォロー・自動いいね NG

X / Meta の規制対象。アカウント凍結・配信制限リスク。

| プラットフォーム | 規制内容 |
|---|---|
| X | 2026 年に LLM 自動返信スパム対策として API 経由のプログラム返信を制限 |
| Meta（Instagram） | Integrity Ecosystem で「不自然な大量行動」を制限対象として運用 |

**運用ルール**:
- DM は週 5-10 件まで（[../acquisition/channels.md §3](../acquisition/channels.md)）
- 1 件ごとに相手の投稿を 1 つ以上具体的に言及（テンプレ転送 NG）
- スクレイピングツールで大量抽出 → 自動 DM フローは禁止
- 「いいね返し」「フォロー返し」の自動ツールは使わない

#### 7.5 UGC・モニター素材の取り扱い NG

| NG | 理由 |
|---|---|
| 子供の顔・名前が映った素材を許諾なし掲載 | 個人情報・肖像権侵害 |
| マスキング漏れ（モザイク忘れ等）のまま広告／LP 掲載 | 同上・特に未成年は重い |
| モニター提供素材を商用転用範囲外で使う | 契約違反リスク |

**運用ルール**:
- UGC 素材は**人間が必ずマスキング確認**してから掲載（Gemini DR ③ 指摘）
- モニター契約書に「商用利用範囲・期間・媒体」を明記
- 子供の顔は原則ぼかし or 後ろ姿 or 手元のみ
- ブランド側で「親が自分の家庭の実体験は投稿しない」方針（[../launch/phases.md](../launch/phases.md)）と整合

#### 7.6 NG 語彙の grep 対象（§7 追加分）

新規広告コピー作成時・LP 改修時に必ず以下を grep：

`アプリで作る|アプリをDL|アプリをダウンロード|アプリをインストール|集中力が伸びる|発達に効果|頭が良くなる|IQが上がる|今すぐ始めないと|小1の壁|集中力アップ|学力が上がる`

「アプリ」単独語は Web ジェネレータの説明文脈で混入しやすいため特に注意（「Web ジェネレータ」「無料 Web ツール」「おためし点描写メーカー」に置換）。
