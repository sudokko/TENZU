# TENZU KDP出版に向けた教材とサイトの修正計画

## サマリ

- 9種類216問の1冊として作った本文・特典・サイトを、**「はじめての点図形（点描写）」1冊**（欠け補完・模写12巻144問・98ページ）へ組み替える。商品仕様の正本は [kdp-paperback.md](kdp-paperback.md)。
- 7課題の本（旧2冊目）は凍結。書き出しと文面は残し、この計画の工程には含めない（[kdp-paperback.md §7](kdp-paperback.md)）。
- 本文は新しい並び（Lv・Volごとに たす→うつす）と巻の1ページ目（れいだいと解説は最初の巻だけ）で作る。全問2問・横。問題でないページ19（巻末にWebの7課題の見開き）を足す。
- 表紙デザインはオーナー担当。本文・特典・サイト・販売原稿の制作を進め、表紙の自動生成・サイト掲載は行わない。
- 現在は未公開。著者はTENZU、ISBNはKDP無料ISBNを使う。
- 購入者特典は固定期限なし、本に記載する共通コード方式、メール登録不要とする。
- 順序は、設定 → 本文の書き出しと校正 → 特典PDFと受取入口 → Amazon販売準備（表紙はオーナーが並行制作） → 校正刷り → 公開。
- 本文は実本比較で採用済みの黒40％、内側18mmを基準とし、最終校正刷りで再確認する。
- 対象は4〜6才を主軸に、小学校低学年の図形練習と小学校受験の基礎練習にも接続する。
- 価格は税込¥1,320。題名は「はじめての点図形（点描写）」、副題は「4才ごろからの　図形を写す練習 144問」。オーナーの決め残し：受取URL。
- 問題仕様は [pack-design.md](pack-design.md) と [pack-tasks.md](pack-tasks.md) を使う。

### 特典PDFとダウンロードの設計

#### サイトの入口

受取URLは `tenzu.jp/book/hajimete` の1つ（本のQRが指す）。URLに問題数を入れない。QRと短いURLはこの入口に向け、ダウンロードファイルの直URLや期限付きURLを本に印刷しない。216問版の `/book/216` は公開していないため、旧URLを残す必要はない。

サイトのフッターに「本をお持ちの方へ」を常設し、受取ページへつなぐ。トップと商品一覧の書籍案内は、書籍紹介・Amazonで購入・購入者PDFの受け取りの役割が分かる小さな枠にする。販売開始前はAmazonの仮リンクを一般公開しない。

受取画面は次の順にする。

1. 「ご家庭で、くり返しどうぞ。」と、問題数・追加料金なし・期限なし・登録不要の短い案内。表紙画像は使用しない。
2. 本のどこにコードがあるかを案内し、入力欄を表示。
3. コード確認後、問題PDFの保存ボタンを並べる。「自分に合う紙面にする」を開くと本番サイトと同じ詳細設定をすべて使える。課題別PDFは折りたたむ。
4. 次への案内。中身は [kdp-paperback.md §6](kdp-paperback.md)。主は7課題の入口（各課題のLv.2、立体はLv.3）、次に模写・欠け補完のLv.5。
5. 「自分で作るメーカー」で作図・紙面設定・PDF印刷の流れ、無料範囲と料金を説明。
6. 家庭内利用の条件、保存・印刷のFAQ、レベル表記、PDFの更新・訂正案内を折りたたみで表示。

コードの入力や保存エラーは、その場で直し方を示す。利用条件はコード確認の前後ともページ下部から読めるようにする。スマホではPDF表示後の保存手順も添える。画像だけに依存せず、見出し・説明・エラーをHTMLテキストで用意し、キーボード操作と読み上げに配慮する。

#### 配布物

| ファイル | 中身 |
|---|---|
| 全問の問題PDF | 144問 |
| 解答PDF | なし（見本が答え。確かめ方を受取ページに書く） |
| 課題別 | たす72問・うつす72問 |
| じぶんでつくろう | 空いた盤面（本のデザインページをA4に拡大） |
| 配布管理情報 | 版番号、更新日、元問題IDとSKU、全体番号、ファイルのチェックサム |

配布版はKDP入稿PDFをそのまま置く方式にせず、同じ問題データから印刷用として生成する。問題番号を保ったまま選んで印刷できるようにする。配布版の濃度は本文40％を出発点に、家庭の白黒印刷で確認する。紙の本が改訂されても、特典の問題が別のものへ無言で置き換わらないよう、版と問題対応を管理する。正誤訂正がある場合は訂正箇所を読者ページに示す。

#### コードと配布処理

共通コードは購入者が利用しやすい簡易ゲートとして扱う。転送やAmazonの試し読み等で第三者に知られる可能性があるため、厳密な購入証明としては扱わない。コード掲載ページと試し読み範囲は入稿時にも確認する。

コードをURLのクエリ、QR、アクセス解析、公開JavaScriptへ埋め込まない。サーバー側で確認し、書籍特典用の状態を既存Stripe商品の購入権限と区別する。PDFは公開フォルダへ置かず、コード確認後の配布経路で渡す。後から7課題の本を出す場合も、コードと配布を本ごとに分けられる作りにしておく。

再ダウンロードに回数制限は設けない。連続した不正コード入力には制限を設けるが、家庭での反復利用を妨げない。入口URLは保持し、保管場所の変更やコード更新が必要になっても、旧版の本を持つ読者が受け取れる経路を残す。

利用条件は「購入者の家庭内での利用、きょうだいでの利用、繰り返し印刷可」を基本とし、転載・再配布・販売は禁止する。教室・塾等の利用は問い合わせへ案内する。一般向け無料サンプルと購入者特典を混同させない。

### 表紙とAmazon販売情報

表紙デザインの制作・修正はオーナーが行う。ポンチ絵の案B（難易度のものさし）を出発点にする。縮小した表紙で題名・年齢・問題数・特典が読めるかを最終表紙で確認する。

Amazon用には次をひとまとまりの入力原稿にする（[listing.md](../docs/drafts/kdp/series-1-hajimete/listing.md)）。

- タイトル、副題、著者を表紙と一致させる。シリーズ登録はしない。
- 内容紹介の冒頭で、4〜6才・欠け補完と模写・144問・3×3からの段階を伝える。
- 購入者PDFは繰り返し取り組める内容上の特徴として説明し、無線綴じの本を補う印刷利用も案内する。
- 小学校低学年の図形練習と小学校受験の基礎練習を、内容に合う範囲で自然に含める。
- 最大7枠の検索キーワードを本の内容に即して選ぶ。
- A+は「段階」「課題」「実際の紙面」「本で始めて繰り返す」の構成で制作する。外部URLやQR、他ストアへの誘導をそのまま転記しない。
- Author Central用にTENZUの専門性と教材設計を紹介する文章・画像を準備する。
- 素材・フォントのライセンスと制作経路を整理し、AI生成とAIアシストを区別してKDP申告用の一覧を作る。

### 検証と公開の条件

- 収録問題の重複・欠落と出典照合。
- 本文・配布PDFの全ページ画像と主要ページの拡大表示。フォント埋め込み、文字サイズ、線幅、点径、灰色、余白、寸法を検査。
- 仮QR・仮URL・216問版や2冊版の表記・旧ページ参照が採用成果物に残らないこと。
- 正しいコード／誤ったコード／直接アクセス／再取得／配布失敗時の案内を確認。書籍コードで既存の有料商品が解放されないこと。
- PC・iPhone Safari・Android Chromeで受取から保存、印刷までを確認。実機が必要な箇所はオーナーの確認項目にする。
- Webは変更範囲の型・lintと本番ビルド、主要な既存商品・購入後PDF・メーカーの回帰確認。

公開の順序：

1. ローカルで受取ページ、本文、配布PDF、Amazon原稿を確認する。表紙の制作待ちを、これらの検証の前提にしない。
2. 公開依頼の範囲で特典サイトと配布ファイルを先に本番へ反映し、正式URLとPDF取得を確認する。
3. 最終本文と表紙でKDP Previewerを全ページ確認し、校正刷りを注文する。KDP操作はオーナーが行う。
4. 鉛筆・消しゴム、点と補助線、黒40％、のど、裏写り、QR、バーコード、ページ順を実物で確認する。
5. 合格したら、価格・メタデータ・AI申告一覧を揃え、オーナーが出版操作を行う。
6. 販売開始後、商品URL、著者・年齢・価格・表紙・説明、TENZUからのリンクと特典受取を確認する。

### 公式情報と制作資料

外部AIレビューの価格・仕様・制度の記述は、実装と入稿時に公式情報で確認する。以下は2026年10月18日に確認した計画上の基準。

- B5相当の大判・黒インク・白紙は、24〜110ページの範囲で印刷費530円。登録画面の見積もりを最終値にする。[KDP 印刷コスト](https://kdp.amazon.co.jp/ja_JP/help/topic/G201834340)
- タイトル・副題と表紙の整合を取る。Amazonの内容紹介にはURL、価格、期間限定告知、他ストアの注文情報等の制限がある。[KDP メタデータ](https://kdp.amazon.co.jp/ja_JP/help/topic/G201097560)
- 自作バーコードの推奨寸法と自動配置の領域を混同せず、最終ページ数の公式テンプレートとPreviewerで確認する。[KDP バーコード](https://kdp.amazon.co.jp/ja_JP/help/topic/G5HDYGP4BXLX4RUW)
- 無料ISBNの出版社表示は「個人出版」。著者TENZUの表示とは区別する。[KDP ISBNと出版社](https://kdp.amazon.co.jp/ja_JP/help/topic/G201834170)
- AIで実際に生成したテキスト・画像等は申告対象で、校正等のAIアシストとは区別される。[KDP コンテンツガイドライン](https://kdp.amazon.co.jp/ja_JP/help/topic/G200672390)
- 制作と検品の参照先は [書き出し元](../web/scripts/export-kdp-series.ts)、[冊子設定](../web/scripts/kdp/book.ts)、[本文検査](../web/scripts/preflight-kdp-book.py)、[表紙組立](../web/scripts/assemble-kdp-cover.py)、[表紙検査](../web/scripts/preflight-kdp-cover.py)。
