# SNS アカウント設計書・外部レビュー依頼プロンプト（Gemini / ChatGPT 用）

> 使い方: 下の「----- ここからプロンプト -----」以降を全文コピーして、Gemini と ChatGPT にそれぞれ貼り付ける。
> 末尾 §7 の「モデル別の追い足し」だけ、貼り付け先に応じて 1 行を残して他方を消す。
> 添削対象（§6）は 2026-07-10 時点の `acquisition/sns-accounts.md` のスナップショット。SSOT は md 側。

----- ここからプロンプト -----

あなたは日本市場の SNS マーケティングとコピーライティングの専門家です。個人運営の EC ブランドの「SNS アカウント設計書」を添削してください。目的は、アカウント開設前に設計の穴・コピーの甘さ・媒体理解の事実誤認を潰すことです。忖度のない辛口の指摘を歓迎します。ただし後述の【動かせない前提】を覆す提案は不要です（検討済みの経営判断のため）。

## 1. ブランドの前提（この要約だけで判断できます）

- **TENZU（てんず）**: 点図形（点描写）プリントの専門店。点描写＝見本を見て、点の位置を考えて、同じ図形を書き写す練習。年長〜小1前半の子を持つ家庭が主戦場
- **商品**: レベル別の点描写 PDF プリント（1巻 ¥200・全49巻）＋ブラウザで点描写を自作できる「模写メーカー」（無料・上位機能は ¥980 買い切り）。**ネイティブアプリではない**（Web ツール）。現在ローンチ前
- **運営**: 個人・副業。SNS に使える時間は**週 3〜5 時間＋Pinterest 別枠 1〜2 時間**。投稿素材は「メーカー出力（実際の問題画像）＋幾何グラフィック」で撮影ゼロ・無限に量産できるのが構造的な強み
- **ブランドコンセプト**: 「考えながら書く力を育てる、点図形（点描写）プリント専門店」
- **タグライン（コア）**: 「見て、考えて、書く力を、点描写から。」
- **経営戦略の要（クリティカルコア）**: 「**設計図ごと、全部公開する**」——難易度の根拠・レベル分けのロジック・サンプルを買う前に全部見せ、煽らずに情報の対称性と信用で売る
- **集客の全体構造**: 幹は検索・LLM 経由の自社記事（労力の 35%）。**SNS は枝であり、バズは狙わない**。北極星 KPI は「流入元別の無料メーカー利用（PDF 生成数）」と購入。フォロワー数・再生数・いいねは KPI にしない
- **この設計書のスコープ**: 各 SNS アカウントの「コンセプトと看板」（誰に何を約束するか・プロフィール実文言・固定要素・担当ツール）。投稿カレンダー・在庫運用・チャネル労力配分・DM 運用は**別文書で定義済み**のため、このレビューの対象外

## 2. 動かせない前提（ここへの反対提案は不要）

1. **顔出しなし**。運営者の家庭・子どもは見せない。無記名の三人称（「専門店」として語る）で運用する（※三人称ルールに限り、§3 の重点論点 B では緩和案の提案を認めます。顔出しなし・家庭非開示は論点 B でも維持）
2. **煽らない**: 「手遅れ」「差がつく」「小1の壁」「今すぐ」等の不安・時間軸訴求は使わない。教育効果の断定（「集中力が伸びる」「IQ が上がる」「発達に効果」）も使わない
3. **禁止語彙**: 「診断」「処方箋」「治療」系はブランドとして使わない。「〜でつまずかないために」型（欠落予防）ではなく「〜の土台を育てる」型（拡張）で書く
4. 「空間認識」をブランドの自己表現・ハッシュタグに使わない（ブランド語は「空間認知」）。「アプリ」とも呼ばない（「ブラウザで使える」「Web ツール」と表現）
5. **採用チャネルは Pinterest / Instagram / X / note / Ameba の 5 つで確定**（TikTok・YouTube 単独運用・Threads 等の不採用は検討済みの決定。役割: Pinterest＝送客主戦場、IG＝認知、X＝専門家ポジ、note＝思想ハブ、Ameba＝低優先の記事再掲）
6. X の通常投稿は**リンクを本文に入れずリプ欄に置く**（リンク付きポストのインプレッション抑制への対応。固定ポストのみ本文 URL 可）
7. **実写写真・AI 生成画像は使わない**（素材はメーカー出力＋幾何グラフィックのみ。アイコン/ヘッダーはロゴ）
8. 価格（¥200 / ¥980）・商品構成・「バズより検索が幹」という配分は変更しない

## 3. 重点論点（オーナーが特に迷っている 2 点・必ず明確に立場を取って答えてください）

### 論点 A: 「設問の中身押し」か「クリエイティブ押し」か

現行設計は全媒体とも**実用情報押し**です——Pinterest＝問題プレビュー、Instagram＝選び方カルーセル＋制作裏側、X＝論文要約・制作ログ。つまり「実際の問題・選び方・設計根拠」を見せて信用を作る構成。

対案として、もっと**クリエイティブ押し**——見て気持ちいいビジュアル表現を前面に出す方向——がありえます。例: 点だけの状態から線が現れて図形が完成していく過程のアニメーション/動画、幾何パターンとしての美しさを立てた作品ギャラリー、描き上がる過程の心地よさ（プロセス系コンテンツ）、季節モチーフの完成作品など。

質問:
1. **媒体ごとに**、実用押し／クリエイティブ押しのどちらが（あるいはどの配合比が）合うか。特に Pinterest と Instagram で「保存され、広がり、送客につながる」のはどちらか
2. 日本語圏の類似ジャンル（知育プリント・ぬりえ/迷路系・手書き文字系・文具系・ジェネラティブアート系など）で参考になる実例アカウント・勝ちパターンがあれば挙げてください
3. クリエイティブ押しに振る場合、この設計書のどこ（1 行コンセプト・約束・投稿タイプ・固定要素）をどう書き換えるべきか

制約: 素材は「メーカー出力（実問題）＋幾何グラフィック＋画面録画」の範囲は維持（実写・AI 画像なし）。その範囲内でのクリエイティブ表現の余地を論じてください。

### 論点 B: 「人間味チャネル」の是非（Ameba＝店主の戯言案）

現行設計は全アカウントを無記名三人称の「専門店」人格で統一し、人間味は投稿内の「店主メモ」引用と、完全に別人格のオーナー個人 note 連載（開発実録・一人称）に隔離しています。

オーナーの仮説: **どこか 1 媒体は「店主の戯言」的な人間味コンテンツを流す場にした方がよいのではないか**——店主が思ったこと、気になった記事の感想、趣味（囲碁など商材と無関係の話題）の雑記。候補は Ameba（現行は公式記事の再掲のみの低優先チャネル）。ブロガーに DM を送る商売である以上、「中の人の顔が（比喩的に）見える場所」があった方が信用・親近感・DM 返信率に効くのではないか、という考え。

質問:
1. この仮説に**賛成か反対か**、理由とともに。個人 EC・スモールブランドの実例や一般論からの根拠があれば添えて
2. やるなら**どの媒体が適切か**（Ameba／X／note／新設せず個人 note 連載に寄せる／やらない）
3. やる場合の**人格設計**: 一人称「店主」をどの範囲で解禁するか。屋号アカウントでやるか、屋号と紐づく別アカウントにするか。専門店の三人称トーンとの同居ルールをどう引くか
4. 趣味話（囲碁など）の混入は、専門店ブランドの統一感・専門性をどこまで毀損するか。逆にアメブロという媒体の文化では自然に働くか
5. 反対の場合: 「人間味・実在感」を現行設計の枠内（店主メモ・制作裏側・個人 note 連載）で強化する具体案を代わりに示してください

この論点に限り、【動かせない前提】1 の「無記名の三人称」を緩める提案を認めます（顔出しなし・家庭/子ども非開示は維持）。

## 4. 添削してほしい観点（優先順）

1. **コンセプトの切れ味**: 各アカウントの「1 行コンセプト」と 5 要素（誰に/約束/トンマナ/媒体特性/なぜ TENZU）は、その媒体で「フォローする理由」として立っているか。約束が弱い・曖昧・他チャネルと重複しているのはどれか。あなたならどう書き直すか
2. **コピーの添削**: bio・X 固定ポスト・note 固定記事リード・Pinterest ボード名・IG ハイライト名を、実際の媒体の作法と字数制限で添削し、**修正後の文案**を提示してください（§2 の禁止語彙を守ること）
3. **媒体理解の事実チェック**: Pinterest（ビジネスアカウント・ドメイン認証・ボード設計・ピンの SEO）、Instagram（bio 仕様・ハイライト・SNS 内検索）、X（固定ポスト・リンク運用・bio 検索）、note、Ameba について、2025〜2026 年時点の仕様・アルゴリズム理解として**古い/誤っている前提**があれば根拠つきで指摘
4. **SNS 内検索（各媒体の SEO）**: 表示名・bio・ボード名・ハッシュタグのキーワード設計は妥当か。日本語圏の実際の検索行動（例: 「点描写」「点図形」「年長 プリント」「入学準備」等の語彙選択）から見て、足すべき語・引くべき語
5. **抜け・盲点**: 開設チェックリストに足りない実務（例: なりすまし・類似ハンドル対策、各媒体の認証、リンク先の受け皿ページの妥当性、通知・返信の初期設定など）。この設計書に「**書かれていないことによるリスク**」
6. **Ameba 設計の妥当性**: 公式サイト記事の再掲運用（月 1 本目安・主目的は DM を送る相手のブロガーに対する「実在する専門店」の証明）について、重複コンテンツ/SEO・アメブロの文化との相性の観点で問題点や改善案
7. **工数の現実性**: 週 3〜5 時間＋Pinterest 1〜2 時間の個人運営で、この 5 アカウント体制は破綻しないか。削る・薄めるならどこか

### §1. アカウントコンセプト（1行＋5要素）

SNS 立ち上げの成否はアカウントコンセプトでほぼ決まる。コンセプトが曖昧なまま運用すると、企画が毎回ゼロベースになりネタが枯渇し、トンマナがブレ、見るべき数字が定まらず、「意味がない」と感じて止める——という順で失敗する。逆にコンセプトが 1 行で言えれば、投稿企画・世界観・KPI・運用ルールはすべてそこから導出できる。

#### §1.1 原則

- **1 行テスト**: 「誰に向けて、何を、どう届けるアカウントか」が 1 行で言えるまで、そのアカウントでは投稿を始めない
- **導出の順序**: 1 行コンセプト → 投稿の型（channels.md §2）→ 企画ストック・在庫（sns-operations.md §1-§3）→ KPI（channels.md §7.4・フォロワー数ではなく保存/CTR/流入元別 `generated_pdf`）。逆流させない
- **迷ったら 1 行に戻る**: ネタに詰まる・トンマナが揺れる・数字の見方に迷う、はすべてコンセプト側の症状。投稿量を増やす前に 1 行と 5 要素を読み直す。伸びない状態が続くときも同じ（Pinterest は 90 日ゲート＝sns-operations.md §6 が別途ある）

#### §1.2 5 要素と共通の土台

各アカウントは次の 5 要素を言語化する（§4 の各チャネル節に個別表）。

| 要素 | 問い | TENZU での土台 |
|---|---|---|
| ① 誰に | 「30代女性」の粒度は禁止。行動と状況まで絞る | 主戦場＝就学前後（年長〜小1前半）の親（targeting.md §0）。チャネルごとに S-a/S-b/S-c・受動拾いの重心を変える |
| ② 何を約束する | このアカウントを見続けると何が得られるか、一言で | チャネルごとに定義（§4） |
| ③ どう届ける（トンマナ） | 視覚と言語の一貫性 | 全アカウント共通で固定: 純白＋点格子・幾何グラフィック・メーカー出力素材（visual-identity.md）／煽らない・拡張フレーム・三人称（voice-tone.md） |
