## 4 本目｜G4 何歳から、はじめる？

```
年長の点描写プリント、何歳から始めるかの選び方です。

点描写は、年齢よりも点の数で選ぶのがこつです。

いちばんやさしい入門編は、3×3 の点に線が 2 本から。
点が増えるほど見るところが増えるので、3×3 と 5×5 では目の動かし方が変わります。

各レベルに年齢のめやすは載せていますが、重なりを広くとっています。
同じ年でも、ちょうどいい点の数は違うからです。

迷ったら、やさしい方から。手が止まるより、物足りないほうが次につながります。

🔖 レベル選びの目安に、保存しておいてください。
くわしくはプロフィールのリンクから。
```

## 5 本目｜G5 合わなかったら？

```
点描写プリントのレベルが合わなかったときの、戻り方の話です。

線が引けずに止まる、点を数え直す回数が増える。それは「まだ早い」の合図です。

一つ下の巻に戻ると、同じ形でも点の数が減ります。
書けるところから積み直すほうが、結局は早く進みます。戻るのは、やり直しではありません。

同じレベルの中にも複数の巻があります。巻ごとに盤面や線の向きが変わるので、隣の巻を試す手もあります。
すらすら書けて時間が余るなら、次のレベルへ。

🔖 手が止まったときのために、保存しておいてください。
くわしくはプロフィールのリンクから。
```

## 6 本目｜G6 点つなぎの、次に。

```
点つなぎの次にやる教材を探している方へ、点描写プリントの話です。

点つなぎは、番号の順に線を引くと絵ができる。手を動かす楽しさを覚える、いい入口です。

点描写には番号がありません。
どこから書くか、どの点とどの点を結ぶかを、自分で決めます。

たどるから、決めるへ。同じ「点と線」でも、頭の使い方が変わります。
だから入門編は 3×3・線 2 本から始まります。

いきなり写せなくても大丈夫です。線の数が少ない巻から、少しずつ増やしていけます。

🔖 次の一手を選ぶときのために、保存しておいてください。
くわしくはプロフィールのリンクから。
```

## 7 本目｜G1 見て、写す。

```
点図形（点描写）プリントの「見て写す」3 タスクの紹介です。

形をそのまま読み取る、いちばんの基礎。立体に起こすところまであります。

・模写 … 見本のとおりに、点をつないで写す
・模写（立体）… 平面の点から、立体を起こして写す
・欠け補完 … 足りない辺を補って、形を閉じる

同じ「写す」でも、点の数が増えると見るべきところも増えます。
3 つのタスクは、それぞれレベル別に分かれています。

🔖 タスクの選び方に、保存しておいてください。
くわしくはプロフィールのリンクから。
```
