## KDP の設定

- 判型：A4（21 × 29.7 cm）。B5 から変える
- 本文：白黒・白い紙・塗り足しなし
- ページ数：106（背幅 106 × 0.0572 ＝ 6.0632mm）
- 表紙：光沢あり（前回の試し刷りと同じ）
- 印刷費：大判・24〜110ページなので 530円のまま（登録画面の見積もりで確かめる）

## 書き出しで確かめたこと

- 106ページすべて A4。フォントはすべて埋め込み
- 問題のあるページはすべて右ページで、裏の左ページは白紙か扉
- 扉（巻の1ページ目の向かい）は、前のページの解答欄の真裏に何も刷っていない（11か所）
- 全ページ、KDP の余白（24〜150ページは内側9.6mm・外側と上下6.4mm）の内側に収まっている
- 表紙の寸法が 106ページ・白い紙の計算と一致
- 表紙の文字は、表・裏とも仕上がり線から3.2mm以上内側。背の文字は背の左右から1.6mm以上内側（1.78mm・1.62mm）
- 表紙の絵の画像は300dpiで置いている（元の絵は約90dpiのまま）

## 試し刷りで見ること

- たすのページで、下に重なる次の紙の線が解答欄に透けて気にならないか
- 黒88%の線と点の見え方、鉛筆で描いた線との見分けやすさ
- 3×3・4×4 の盤（点の範囲34.6mm）で描きやすいか
- 扉と、巻の1ページ目の「ここから」で、新しい巻に入ったと分かるか
- 表紙の文字がくっきり出ているか（題名、裏の説明文、レベルのカード、背の題名）
- 背の（点描写）のかっこが、つぶれずに読めるか
