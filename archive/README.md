## 運用ガイド

### アーカイブへ移すタイミング

- 設計を変更したら、旧記述は**即座に**アーカイブへ移す
- 設計書本体には「→ archive/{path} 参照」の1行リンクのみ残す
- 議論経緯は「直近セッション」セクションを設計書に残さず、最初からセッションファイルを作って書く

### アーカイブから参照するタイミング

- 「あれ、この設計いつ変わったっけ？」と探したくなったとき
- 過去の判断根拠を再確認したいとき
- 撤回された設計を誤って復活させそうになったとき
