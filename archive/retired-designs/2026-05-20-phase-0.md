# 撤回：Phase 0（アプリ＋アプリ専用LP＋初期記事10本）（2026-05-09 → 2026-05-20）

## 経緯

- **2026-05-09 確定**: 4フェーズ構成（Phase 0/1/2/3）の Phase 0 として、無料の点描写作成アプリ ＋ アプリ専用1枚LP ＋ 初期記事10本を公開する設計を確定
- **2026-05-15 Phase 0 アプリLP Priority Guide 完成**：`design/phase-0-app-lp-guide.md`
- **2026-05-20 案F確定で Phase 0 廃止**：3 AI 合議 ＋ ユーザー判断で Phase 0 を撤回し、3フェーズ構成（Phase 1/2/3）に移行

## 撤回理由

1. **案F の P3-a 全振りと不整合**: Phase 0 の主役だった「無料作成アプリ」は P1-b ライト層・P2-a 予防層向けの低摩擦フックとして設計されており、案F の初期突破口「中受 P3-a 緊急対応」と温度感がズレている。藁にもすがる緊急モードの P3-a に「無料アプリで遊んでみて」は刺さらない
2. **「上から下波及法則」との相性が悪い**: X バズの起点は「立体図形が解けた」「補助線が引けた」等の結果体験であり、アプリで作った問題のスクショではない。アプリは波及の起点になりにくい
3. **自己診断ツールとの役割衝突**: 案F で「選択肢ベース自己診断ツール（5-7問・1日実装）」が確定。これがファネル最上部の役割を担うため、アプリを診断ツール化すると役割が衝突する
4. **Phase 0 スコープの肥大化**: アプリ開発は数日〜数週間の工数。Search Console で勝てる記事を見極めるという Phase 0 本来の目的に対してオーバーキル
5. **DM 4通構造の前提崩壊**: DM 1通目「アプリ使ってみて」は P3-a 全振り戦略と整合しないため、DM 構造ごと再設計が必要

## 新方針（3フェーズ構成 + ポスト・ローンチ）

| Phase | 構成 |
|---|---|
| Phase 1（初期フェーズ） | サイト本体 ＋ 全140 SKU 通常販売 ＋ 先行モニター ＋ 初期記事 8-10本（P3-a 偏重）＋ 自己診断ツール（5-7問）＋ サンプルPDF 1本（無料） |
| Phase 2（修正期間） | 新規執筆なし・修正中心 |
| Phase 3（本リリース） | Pillar 残り ＋ Cluster 残り記事10本前後 ＋ クーポン配布 |
| ポスト・ローンチ（運営判断） | アプリ投入（Phase 1/2/3 には組み込まず別個実施・市場反応とリソースを見て決定） |

## 引き継ぐもの

- 無料の点描写作成アプリの開発資産：**Phase 3 後のポスト・ローンチで運営判断による別個投入**（Phase 2 にも Phase 3 にも組み込まない・廃止ではなく延期）
- 「無料体験」役：**選択肢ベース自己診断ツール（無料）＋ サンプルPDF 1本（無料）** で代替
- インフルDM 経路：**4通 → 3通へ再設計**（別タスク・今日のスコープ外）。1通目は記事ハブ誘導に変更
