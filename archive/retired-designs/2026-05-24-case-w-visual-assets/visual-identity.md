# Visual Identity — ビジュアル実装ルール

## サマリ

- 本ファイルは「見せ方の実装ルール」担当。ブランド哲学・MISSION・Voice 原則は [../foundation/brand.md](../foundation/brand.md) を参照
- 配色：鉄紺 `#2B3D5A`／山吹 `#D9A237`（達成・注目限定）／生成 `#F7F2E7`
- タイポ：見出し Zen Kaku Gothic New／本文 Noto Sans JP／数字 Schibsted Grotesk
- 主役グラフィック：「点・直線・図形」の幾何要素（写真不使用・子どもイラスト不使用）
- CTA 強度4段階（弱／中／強／最強）で視覚差。モバイル7割想定
- ディレクトリレベルで UI 密度を変える（`/products/` ミニマル・密度高め／`/articles/` ゆとり）
- コアの幾何学グラフィック・商品サムネ・ロゴには**画像生成 AI 使用禁止**（Figma または SVG で生成）
- 旧 D0 案B' は破棄。新ロゴは Claude Design 側で 2-3 案叩き台 → 選定中

## 詳細

### §1. 配色

| 役割 | カラー |
|---|---|
| 主役 | 鉄紺 `#2B3D5A` |
| アクセント | 山吹 `#D9A237` |
| 背景 | 生成 `#F7F2E7` |

**山吹の用途は「達成・注目」に限定**。「子の歓び」「楽しい・わくわく」表現としては使わない（マスプリント寄りになるため）。

許容用途：完了・選択中・重要な補助線・レベル達成・CTA アクセント・図形内一点の強調。

### §2. タイポグラフィ

| 用途 | フォント |
|---|---|
| 見出し | Zen Kaku Gothic New |
| 本文 | Noto Sans JP（長文記事 18-20本を読ませる可読性重視） |
| 数字 | Schibsted Grotesk（Lv.1〜5、線本数、Vol. 表示が頻出） |

### §3. 主役グラフィック

「点」「直線」「図形」の幾何要素そのものを主役のグラフィック要素として扱う。ドットグリッド・直線・斜線・点の連なり・多角形・レベル別の幾何パターン。この視覚言語を一貫させる。

写真は使わない。図版・幾何グラフィックを主役に。手描きの揺らぎ・子どもイラスト・文房具・教室・黒板・木目・紙雑貨・暖色の装飾は不採用。

**ディレクトリレベルで UI 密度を変える**：`tenzu.〇〇/products/` 等のトランザクション画面はミニマル・機能的・密度高め、`tenzu.〇〇/articles/` 等のコンテンツ画面はゆとりを持たせる。

### §4. ロゴ

旧 D0（案B'・正方形枠＋ドットグリッド＋斜線・TZ 風）は破棄。新ロゴは Claude Design 側で 2-3 案叩き台を作成中。新方向性：

- 案F キーフレーズ（戻れる／ピンポイント／解像度）を視覚言語化
- 中受層 P3-a 向けの**端正・知的・落ち着き**をより強く出す（マンガ寄り・ゲーム寄り絶対回避）
- 配色 navy + cream + 山吹（達成・注目限定）は維持
- タイポ Zen Kaku Gothic New / Noto Sans JP / Schibsted Grotesk は維持
- 主役グラフィック「点・直線・図形」の幾何要素方針は維持

SVG 格納先：`design/brand-assets/`

### §5. コンポーネント

ボタン・カード・スライダー・トグルが必須。

**CTA 強度4段階で視覚差**：弱（テキストリンク）／中（アウトライン）／強（ベタ紺）／最強（ベタ山吹）

Hero CTA は装飾なし。Difficulty Badges は**図形タイプ別**（年齢非依存）。記事カードには shape glyph（三角・四角等）を識別子として配置。

モバイル7割想定。

### §6. スパイス

- **記事カテゴリ・難易度解説**には「図形ラボ」風の知的トーンを少し（例：カテゴリ名「考察」、難易度を「分類体系」と表現）。ただしビジュアル・サイト名はラボ化させない
- **導線設計**（はじめての方へ・スタート診断・目的別おすすめ）には「親向けガイド」観点で迷わせない設計を

### §7. マイクロコピー

構造で温度を出すため、ボタン周り・フォームのプレースホルダー・404・完了画面・エラーメッセージなどに専門家としての配慮と人間味を仕込む。

例：「PDF の準備ができました。今日の1枚が、図形を見る目を少し育てますように。」

### §8. トランジション

決済（硬）→ 完了画面（温）への移行時に唐突感が出ないよう、完了画面冒頭は事務的に入り、スクロールするにつれて「TENZU からのメッセージ」が現れる情報階層化。

### §9. AI 生成物の運用ルール

- **コアの幾何学グラフィック・商品サムネ・ロゴには画像生成 AI 使用禁止**（Figma またはコードで SVG 生成）。AI の揺らぎが「企業並みの端正さ」を一撃で破壊するため
- AI 生成物は**都度生成ではなくパーツライブラリ化**：グリッド背景パターン／斜線パターン／レベル別多角形モチーフ／404用の崩れた点描写／完了画面用の完成図形／OGP 固定テンプレート／記事カテゴリ別の抽象図版 等

### §10. 資産アップロード

|---|---|---|
| Link code on GitHub | ⬜ 空欄 | D-5 Tokens 抽出 → コード化以降に連携 |
