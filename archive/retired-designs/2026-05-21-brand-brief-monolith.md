## ③【コンセプト短期定義】（2026-05-20 案F C改）

> TENZUは、図形が苦手になる前にも、つまずいた後にも使える点図形（点描写）専門店。9タスク × 5レベル × Vol細刻みで、見る・写す・回す・重ねる力を、戻れるところから育てます。

---

## ④【差別化キーフレーズ】（2026-05-20 案F）

- **戻れる**：レベル・Vol を下げて「戻り道」を確保。前進だけでなく後退も設計に含む
- **ピンポイント**：9タスク × 5レベル × Vol細刻みで、ピンポイントに練習対象を絞れる
- **解像度**：図形の「見え方」の解像度を上げる。曖昧な認識を明確にする

ビジュアル言語化の方向（D0/D1 刷新時の指針）：
- 「戻れる」→ 分解→再構築の幾何モチーフ／レベルバッジに「戻る矢印」を仕込む
- 「ピンポイント」→ 9タスク × 5レベルのグリッドが瞬時に視覚化できる商品一覧
- 「解像度」→ 点密度の階調表現（疎な点 → 密な点）／ドットグリッドの粒度可変

## ⑦ Any other notes?

```
TENZUのデザインコンセプトは「専門特化型ミニマルブランド × 個人運営の温度（顔出しなし版）」です。一言でまとめると：**見た目はミニマルD2C、語り口は専門家、記事の芯は図形ラボ、導線は親向けガイド**。

ベンチマークは **すたぺんドリル系のブランド型知育プリント** の品質ライン。ちびむす・ぷりんときっず系のマスプリント（雑多・カラフル・子供イラスト多用）には絶対に寄せないでください。「点図形（点描写）だけを徹底深掘りする、専門特化型ミニマルブランド」と捉えてください。フォーマル度は5段階中4。詩的にしすぎず、抑制的・端正・知的、ただし要所で温かい。

【矛盾を構造で解く】
個人事業主1名運営でありながら、AIをフル活用して企業並みのコンテンツ品質・デザイン品質を出します。「個人感」と「企業並み信頼感」の矛盾は、**場所の使い分け（情報設計）で解きます**：

- **企業並みの端正さで作る場所**: 商品ページ・商品一覧・カート・決済・FAQ・法的ページ・ロゴ・配色・タイポ
- **専門家個人の声を置く場所**: 記事の語り口・About・完了画面・サンクスメール・404ページ

【ページ種別ごとの温度レベル】
温度を足す場所を間違えると個人サイト化、恐れすぎると無機質化します。以下を実装ルールとして固定してください：

| ページ | 温度 | 方針 |
|---|---|---|
| LP | 中 | 専門性を主軸に、少しだけ親向けの安心感 |
| 商品一覧 | 低 | 比較・選択・価格・レベルが最優先 |
| 商品詳細 | 低〜中 | 教材品質、対象、使い方、サンプルを明快に |
| カート・決済 | 最低 | 無駄な情緒は入れない |
| FAQ | 低 | 不安解消に徹する |
| 法的ページ | 最低 | 完全に事務的でよい |
| 記事 | 中〜高 | 専門家の語り口を出す主戦場 |
| About | 高 | 個人運営の思想・動機を出す |
| 完了画面 | 中 | やさしい一文を添える |
| サンクスメール | 中 | 事務連絡＋少しだけ温度 |

【一人称使い分け】
屋号「TENZU」を一人格化し、場面別に主語を固定します：

| 場面 | 主語 |
|---|---|
| 商品説明 | TENZUは |
| 記事 | TENZUでは |
| About | TENZUは、点図形（点描写）を… |
| FAQ | TENZUでは、以下のように… |
| メール | TENZUをご利用いただき… |

「私」「制作者」「運営者」は About の一部のみ許容。基本は屋号で立てます。

【Phase別のWの濃度】（2026-05-20 案F：3フェーズ構成）
最初から完全実装すると重いので段階的に：

- **Phase 1（初期フェーズ）**: Y寄りの端正さを優先。LP・記事 8-10本・商品ページで専門性を確立。完了画面だけ少し温度
- **Phase 2**: 記事群とAboutで屋号人格を育てる
- **Phase 3（本リリース）**: サンクスメール、レベル相談まで温度を拡張
- **ポスト・ローンチ**: アプリ投入時にアプリ体験の温度を追加（運営判断・別個実施）

→ Claude Design では **Phase 3 想定の完全版** を設計してください。実装時に Phase 1〜2 へ段階的にデチューンします。アプリ周辺はポスト・ローンチで投入時に別途設計。

【ターゲット】（2026-05-20 案F確定）
4〜10歳の子を持つ親。**商品は3層対応**（①小学校受験層 ②中学受験層 ③中学受験しない一般家庭層）を維持しつつ、**集客は予防+対処の両軸寄せ・初期突破口を中受 P3-a に全振り**。X実況・口コミバズで上から下へ波及させ、低学年予防層 P2-a と学校算数フォロー層 P2-b に権威付け（「上から下波及法則」）。子ども本人ではなく親（特にINTJ気質を含む知的層）が選ぶUI。子ども向けに媚びたデザイン・ゲーミフィケーション過多・キャラクター押しは避け、親が「ちゃんとした専門の人がやっている」と直感できる端正さを優先してください。

【主役グラフィック】
「点」「直線」「図形」の幾何要素そのものを主役のグラフィック要素として扱ってください。ドットグリッド・直線・斜線・点の連なり・多角形・レベル別の幾何パターン。この視覚言語を一貫させてください。

写真は使わない。図版・幾何グラフィックを主役に。手描きの揺らぎ・子どもイラスト・文房具・教室・黒板・木目・紙雑貨・暖色の装飾は不採用。

**ディレクトリレベルでUI密度を変える**：`tenzu.〇〇/products/` 等のトランザクション画面はミニマル・機能的・密度高め、`tenzu.〇〇/articles/` 等のコンテンツ画面はゆとりを持たせる。

【配色】
- 主役: 鉄紺 #2B3D5A 前後
- アクセント: 山吹 #D9A237
- 背景: 生成 #F7F2E7 系

**山吹の用途は「達成・注目」に限定**してください。「子の歓び」「楽しい・わくわく」表現としては使わない（マスプリント寄りになるため）。
許容用途: 完了・選択中・重要な補助線・レベル達成・CTAアクセント・図形内一点の強調。

【タイポ】
- 見出し: Zen Kaku Gothic New
- 本文: Noto Sans JP（長文記事 18-20本を読ませる可読性重視）
- 数字: Schibsted Grotesk（Lv.1〜5、線本数、Vol.表示が頻出）

【ロゴ】（2026-05-20 刷新中）
旧 D0（案B'・正方形枠＋ドットグリッド＋斜線・TZ風）は破棄。新ロゴは Claude Design 側で 2-3 案叩き台を作成中。新方向性：

- 案F キーフレーズ（戻れる／ピンポイント／解像度）を視覚言語化
- 中受層 P3-a 向けの**端正・知的・落ち着き**をより強く出す（マンガ寄り・ゲーム寄り絶対回避）
- 配色 navy + cream + 山吹（達成・注目限定）は維持
- タイポ Zen Kaku Gothic New / Noto Sans JP / Schibsted Grotesk は維持
- 主役グラフィック「点・直線・図形」の幾何要素方針は維持

【スパイス】
- **記事カテゴリ・難易度解説**には「図形ラボ」風の知的トーンを少し（例：カテゴリ名「考察」、難易度を「分類体系」と表現）。ただしビジュアル・サイト名はラボ化させない
- **導線設計**（はじめての方へ・スタート診断・目的別おすすめ）には「親向けガイド」観点で迷わせない設計を

【コンポーネント】
ボタン・カード・スライダー・トグルが必須。CTA強度4段階（弱／中／強／最強）で視覚差。モバイル7割想定。

【マイクロコピー】
構造で温度を出すため、ボタン周り・フォームのプレースホルダー・404・完了画面・エラーメッセージなどに専門家としての配慮と人間味を仕込んでください。例：「PDFの準備ができました。今日の1枚が、図形を見る目を少し育てますように。」

【トランジション】
決済（硬）→ 完了画面（温）への移行時に唐突感が出ないよう、完了画面冒頭は事務的に入り、スクロールするにつれて「TENZUからのメッセージ」が現れる情報階層化。

【ブランドキャラクター】
**不採用**（Gemini／ChatGPT 両方の独立評価で No 結論。AI生成での一貫性担保困難・撤去時負債・INTJ層への媚び感リスクのため）。代わりに以下4箇所で温度を出す：
1. 記事の語り口
2. マイクロコピー
3. 幾何グラフィックのアニメーション（点と点が静かにつながる等）
4. About・制作ノート

【NG リスト】
- 「鍛える」系の語彙ビジュアル
- 傷つけ表現（年齢ではなく図形タイプで難易度分類する方針）
- 「処方箋」「特効薬」「治療」「弱点診断」「健康診断」「穴を埋める」「ピンポイント治療」（2026-05-20 案F NG）
- 「街の選書本屋」のビジュアル語彙（暖簾・本・棚・版木・印鑑・セピア・和風雑貨）
- 個人の手作り感を強調する素朴さ
- 子供キャラクター・イラスト多用
- ブランドキャラクター・マスコット
- ちびむす系のマスプリントUI（雑多・カラフル・子供イラスト多用）
- 山吹色の「歓び」表現としての多用
- 写真使用

【AI生成物の運用ルール】
- **コアの幾何学グラフィック・商品サムネ・ロゴには画像生成AI使用禁止**（FigmaまたはコードでSVG生成）。AIの揺らぎが「企業並みの端正さ」を一撃で破壊するため
- AI生成物は **都度生成ではなくパーツライブラリ化**：グリッド背景パターン／斜線パターン／レベル別多角形モチーフ／404用の崩れた点描写／完了画面用の完成図形／OGP固定テンプレート／記事カテゴリ別の抽象図版 等

【出力依頼】
専門ブランドとしての凛とした抑制感を保ったまま、知育硬派系↔親しみ系のスペクトラムで微調整案を3案ほしい。
```

## ⑧【屋号語源（裏話）】

屋号 TENZU は「点（てん）」を頭文字に置く一方、音韻として「せんず」とも読みうる。これは設計上の偶然だが、開発時の内部メモとして残す。記事・LP・コピー・ロゴ・ビジュアルいずれにも特定の固有名・作品参照は一切出さない（IP 配慮）。本欄は About ページの末尾コラム等で「屋号にまつわる小さな読み方の話」程度に活用してよいが、必須ではない。
