### §2. Phase 別広告設計

#### 2.1 Phase 0（月 ¥10,000・検証）

| 項目 | 内容 |
|---|---|
| 目的 | Web ジェネレータの反応検証＋ Meta ピクセル学習データ収集 |
| 主 CV | `tool_start` / `generated_pdf` |
| 配信 | Meta ¥6,000 ／ Google 検索 ¥3,000 ／ RTG ¥1,000 |
| クリエイティブ | カルーセル 2 本・短尺動画 1 本・検索広告文 2 案 |
| LP | Web ジェネレータ専用 LP（[funnel.md §13](../../acquisition/funnel.md) 7 セクション構成） |
| 成功条件 | `generated_pdf` 単価 ¥150-400 ／ 商品ページ遷移率 10% 以上 |
| 見ない指標 | ROAS・購入 CPA（データ量不足のため判定材料にしない） |

**Phase 0 の本質**: 売上目的ではなく「親が Web ジェネレータを触りたくなるか／PDF 出力まで進むか／有料商品ページへ自然に進むか」の検証。

#### 2.2 Phase 1（月 ¥20,000-30,000）

| 項目 | 内容 |
|---|---|
| 目的 | 初回購入導線の検証＋ SEO 立ち上げ前の刈り取り |
| 主 CV | `generated_pdf` / `product_recommend_click` / `purchase` |
| 配信例（¥30,000） | Meta 新規 ¥12,000 ／ Meta RTG ¥5,000 ／ Google 検索 ¥10,000 ／ クリエイティブ AB ¥3,000 |
| クリエイティブ | Web ジェネレータ訴求／レベル選び訴求／紙ワーク訴求 |
| SEO 連携 | 検索広告で反応した KW を記事化 |
| 成功条件 | Web ジェネレータ体験 → 購入率 5% 前後 ／ 初回購入 CPA ¥500-1,000 以内 |

#### 2.3 Phase 2（月 ¥50,000-80,000・春 LP 連動）

| 項目 | 内容 |
|---|---|
| 目的 | 春需要（新学年・入学準備・公文前・春休み）の獲得 |
| 主 CV | `purchase`（春 LP バンドル SKU） |
| 配信例（¥80,000） | Meta 新規 ¥32,000 ／ Meta RTG ¥12,000 ／ Google 検索 ¥18,000 ／ YouTube/Demand Gen ¥8,000 ／ クリエイティブ AB ¥5,000 ／ 予備 ¥5,000 |
| 成功条件 | LTV ¥1,000 以上 ／ 初回購入 CPA ¥500-800 以内 ／ ROAS 100% 超え |

#### 2.4 Phase 3（月 ¥100,000+・規模化）

| 項目 | 内容 |
|---|---|
| 目的 | 勝ち筋が見えた後の拡張 |
| 主 CV | `purchase` / value optimization |
| 配信例（¥100,000） | Meta 新規 ¥40,000 ／ Meta RTG ¥15,000 ／ Google 検索 ¥20,000 ／ YouTube/Demand Gen ¥10,000 ／ P-MAX テスト ¥10,000 ／ 新 LP/新訴求テスト ¥5,000 |
| 自動化 | Meta Advantage+ Creative / P-MAX 一部導入 |
| Lookalike | 有料 PDF 購入者の高 LTV 層をシードに類似オーディエンス配信 |

#### 2.5 Phase 3 へ進む条件

| 条件 | 目安 |
|---|---|
| 月間購入 CV | 30 件以上 |
| 初回購入 CPA | ¥500-800 以内 |
| 購入者 LTV | ¥1,000 以上 |
| Web ジェネレータ体験 → 購入率 | 5-10% 以上 |
| リターゲティング CPA | 新規より明確に低い |
| UGC/レビュー | LP に 3 件以上掲載 |
