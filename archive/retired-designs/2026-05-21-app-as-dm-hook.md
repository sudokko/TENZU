# アプリ＝ブロガーDM フック戦略 撤回（2026-05-21）

## 撤回内容

旧 `market/gtm.md` §3「点描写作成アプリ戦略」全節を撤回。アプリを「ブロガーDM のフック＋SEO 流入の入口＋TENZU の第一印象」として位置付ける戦略を完全廃止し、acquisition/ 配下には移植しない。

## 撤回理由

1. **アプリの Phase 3 後降格**（2026-05-20 案F確定・decisions.md §3.21）: アプリは Phase 1/2/3 のいずれにも含めず、本リリース後の運営判断による別個投入に降格。DM フックとしての前提が崩壊
2. **P3-a 全振り戦略との不整合**: 中受緊急対応層（P3-a）に「アプリで遊んでみて」は刺さらない。X バズ起点になりにくく、初期突破口としての DM 1通目フックには記事ハブ誘導の方が適切
3. **「無料体験」役の置換**: アプリが担っていた試食機能は「レベル選びガイド（5-7問）＋ サンプル PDF 1本」で代替済み（funnel.md §1・§3）

## 旧戦略の骨子（撤回内容）

| 節 | 旧主張 |
|---|---|
| §3.1 位置づけ | ブロガーDM のフック＋SEO 流入の入口（「点描写 作成」「点描写 メーカー」等で SEO） |
| §3.2 無料プリントではなくアプリを選んだ理由 | ブロガーの食いつき／記事の書きやすさ／読者の巻き込み／SNS 拡散性／被リンクの自然さ |
| §3.3 有料パックとの棲み分け | アプリ＝入門（模写のみ）／プロ設計＝本格（全9タスク × 3難易度） |
| §3.4 アプリの仕様方針 | 完全無料・メアド不要・PDF 保存自由・アプリ内バナーで有料パック導線 |
| §3.5 開発方針 | MVP 的に削らない・AI を活用して品質高く・DM 戦略全体の第一印象 |

## 後継方針

- **DM 1通目**: アプリ言及廃止 → 中受 P3-a 向け立体図形記事ハブへの誘導（[acquisition/channels.md §3](../../acquisition/channels.md)）
- **試食機能**: アプリ → レベル選びガイド＋サンプル PDF 1本（[acquisition/funnel.md §1・§3](../../acquisition/funnel.md)）
- **アプリの将来位置付け**: ポスト・ローンチで投入する場合の運営判断条件は [launch/phases.md §8](../../launch/phases.md)
