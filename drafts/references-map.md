## 全体構造：5本の系譜

TENZUの記事で参照している文献は、大きく5つの知的系譜に分類できる。

```
[系譜1] ピアジェ認知発達論 ─── 空間認知・対称・比例の発達順序の根拠
[系譜2] メンタルローテーション研究 ─── 回転・対称の困難度と訓練効果の根拠
[系譜3] フロスティッグ/視覚運動統合 ─── 模写・欠け補完・視知覚の発達測定の根拠
[系譜4] ワーキングメモリ研究 ─── かさね・拡大縮小・複合タスクの難しさの根拠
[系譜5] 描画発達・立体模写研究 ─── 立体模写の発達段階・年齢目安の根拠
```

## 系譜1：ピアジェ認知発達論

### 起点
- **Piaget, *The Child's Conception of Space*** (1967)
  → EN[9]、JP版は[7][8]で発達段階論として参照
  空間概念（座標・保存・変換）の発達段階を体系化した出発点。具体的操作期（7歳〜）・形式的操作期（11歳〜）の枠組みは、9タイプの年齢目安の基盤。

### 直接の発展
```
Piaget (1967)
  ├─ EN[15] Simply Psychology "Piaget's Stages" ────────── 解説資料（C）
  ├─ JP[7]  ピアジェ発達段階論の意義と射程 (2011) ────── 日本での批判的継承（A）
  ├─ JP[8]  ピアジェを読み直す（2005）─────────────────── 具体的操作の再検討（A）
  └─ JP[6]  児童・生徒の空間認識（1997）────────────────── 回転・対称概念の実証（A）
               └─ JP[11] 対称性教材研究（2015）────────────── [6]の知見を踏まえた教材開発（A）
               └─ JP[20] 図形の論理的思考（2019）──────────── [6]の空間認識を学校教育へ応用（A）
```

### 比例推論への枝
```
Piaget の形式的操作論
  ├─ EN[14] Number Line & Proportional Reasoning (PMC) ── 比例推論の発達実証（A）
  ├─ JP[12] 面積変化を具現化する教授（2015）────────────── 拡大縮小の教授法研究（A）
  └─ JP[13] 学習指導要領・数学科改訂論（2015）────────────── 制度的根拠（A）
```

## 系譜3：フロスティッグ / 視覚運動統合（VMI）

### 起点
- **Frostig, *Developmental Test of Visual Perception*** (DTVP 初版: 1960年代)
  視知覚を「目と手の協応・図と地・形の恒常性・空間位置・空間関係」5領域に分類した先駆的枠組み。

### 検査ツールの発展系譜
```
Frostig DTVP（1960年代）
  ├─ EN[7]  DTVP-3 (WPS, 第3版)
  │          ─ フロスティッグの現代的改訂版。現在も標準的な視知覚検査（B）
  │
  ├─ EN[4]  Beery VMI（第6版）
  │          ─ 「視覚運動統合」に特化して発展した独立検査（B）
  │
  ├─ EN[3]  NEPSY-II（Pearson）
  │          ─ 神経心理学的包括検査。視覚・空間処理の独立下位検査を含む（B）
  │
  ├─ JP[1]  発達障害の視知覚的特徴（日本心理学会, 2013）
  │          ─ フロスティッグDTVPを発達障害の日本人サンプルに適用（B）
  │
  └─ JP[24] フロスティッグプログラムによる早期介入効果（東北福祉大, 2015）
             ─ 4〜5歳児への実施で視覚運動+自己肯定感+行動安定を確認（A）
             ─ フロスティッグの訓練プログラムの教育効果の直接実証
```

### 視覚認知指導への応用
```
フロスティッグ / Beery VMI
  └─ JP[9]  視覚認知に問題がある児童への指導効果（2016）
             ─ 視知覚トレーニングの学習改善効果を実証（A）
             ─ [24]と同じ「介入効果」の問いへの別アプローチ

## 系譜4：ワーキングメモリ研究

### 起点（記事には直接引用なし・暗黙的基盤）
- **Baddeley & Hitch (1974)** ワーキングメモリモデル（視空間スケッチパッドを含む）
  → 以下の研究の理論的枠組み

### 発展系譜
```
Baddeley & Hitch (1974)【暗黙的基盤・記事には直接引用なし】
  ├─ JP[10] ワーキングメモリと実行機能の発達（湯澤ほか, 2019）
  │          ─ 日本のWM発達研究をリードする湯澤正通（広島大）らによる特集（A）
  │          ─ 視空間WMの発達軌跡（6〜7歳での基礎形成）を整理
  │
  ├─ JP[21] 児童・生徒用WMアセスメントテストの作成（湯澤ほか, 2019）
  │          ─ [10]と同年・同著者グループによる測定ツール開発（A）
  │          ─ [10]の理論に基づいた実用ツールの構築
  │
  ├─ JP[22] 視空間WMのトレーニング効果（2009）
  │          ─ WMトレーニングの転移効果を検証（B）
  │          ─ [10]の理論的知見を訓練実践に応用
  │
  └─ Oka et al. (2010) 視空間WM発達（脳と発達 42(4):277-282）
             ─ 6〜14歳定型児 n=60、視空間WMは思春期まで上昇継続
             ─ Pillar B（中受層）H2-3「後付けで鍛えられる」根拠として B-2 Step 1c で採用
             ─ 旧 EN[18] 帰属誤りで判明した実体（J-Stage URL先）を系譜4に正式分類
             ─ 詳細書誌は本マップ末尾「No.25以降の追加文献詳細」を参照（※既存EN番号は付与しない／新規追加扱い）
```

> **JP[10]とJP[21]の関係**: 同じ著者グループ（湯澤チーム）による2019年発達心理学研究誌の特集企画。[10]が理論的整理、[21]が測定ツール開発という分業関係。

> **空間訓練→数学転移の遠転移エビデンス**: 系譜4の応用拡張として、**No.32 Gilligan, Thomas, Farran (2020)** Developmental Science・8歳 n=250 RCT を採用。空間スケーリング訓練が比例推論を介して数学スキルへ far-transfer することを実証。詳細は末尾参照。

## 系譜5：描画発達・立体模写研究

### 起点（記事には直接引用なし・暗黙的基盤）
- **Luquet (1913/1927)** 「知的リアリズム → 視覚的リアリズム」概念
  子どもの絵が「知っていることを描く」から「見えているように描く」に移行することを概念化。
  → 立体模写の年齢目安（7〜8歳以前/以後）の理論的根拠。

### 模写能力の発達実証
```
Luquet (1927)【暗黙的基盤・記事には直接引用なし】

  ├─ ~~JP[14]~~ **【2026-05-07 完全除外確定】** 依光ら（2013掲載・データ収集2007〜2010）「立方体透視図模写の定量的採点法の開発」高次脳機能研究 33(1)：原典精査の結果、対象は **平均66.8歳・58.5歳の成人脳損傷患者**。WAB／VPTA／MMSE／RCPM／WAIS-III 等の成人神経心理検査と相関分析した臨床研究で、**子ども発達研究ではない**。3 Pillar・Cluster ともに不適合。代替として No.25 / No.26 を採用（既存ファイル `14_立方体透視図採点法.pdf` は史料として保管継続）
  │
  ├─ ~~EN[18]~~ **【2026-05-07 完全除外確定】** J-Stage URL先 = Oka et al. (2010) 視空間WM発達（系譜4へ正式分類済み）。立方体模写発達研究としては不在。代替は No.25 / No.26 / No.28
  │
  ├─ JP[2]  久保田：図形模写能力の発達（1970）
  │          ─ 日本で最も古い体系的な模写発達研究（A）
  │
  ├─ JP[3]  幼児における描画行動の発達的研究（1993）
  │          ─ 対象は **3歳・4歳・5歳児（計87名）**（旧記述「3歳・5歳・7歳」は誤りで2026-05-06訂正済み）

  ├─ JP[4]  幼児期における摸写的活動の教育的妥当性（2018）

  │
  ├─ JP[18] **【2026-05-06 帰属誤り判明】** 添付PDF「18_空間表現発達指導2.pdf」の実体は阿部宏行『子どもの絵における空間表現の発達と指導(2)』2015 美術教育学会誌。3 Pillarには不適合・Cluster候補にも温存しない判断（2026-05-06 セッション）
  │
  ├─ No.25 大伴 潔 (2009) 視空間課題としての立方体模写の発達的検討—漢字書字との比較—
