# 点描写には「9つのタイプ」がある ― TENZUが体系化した理由と、身につく力のすべて

> **この記事の対象読者**: 点描写プリントを子どもにやらせたいけど、「模写以外に何があるの？」「どの順番でやればいいの？」が分からない保護者の方

---

## はじめに：「点描写＝模写」だけではもったいない

「点描写」と聞いて、多くの方がイメージするのは**お手本をそのまま写す「模写」**ではないでしょうか。

もちろん模写は点描写の基本であり、とても大切な練習です。でも実は、点描写にはお手本を写す以外にも**9つの異なるタイプ**があり、それぞれが子どもの**異なる脳の力**を鍛えてくれます。

TENZUでは、この9タイプを**発達の順番に沿って体系化**しました。

この記事では、
- なぜ9タイプなのか
- どんな順番で取り組むべきか
- それぞれどんな力が身につくのか

を、できるだけ分かりやすくお伝えします。

## 点描写で育つ「5つの力」

9タイプの詳細に入る前に、点描写全体で育つ力を整理しておきましょう。

### 1. 見たものを正確に写しとる力（視覚運動統合）

目で見た情報を、手を使って正確に再現する力です。模写や立体模写で特に鍛えられます。文字を書く、図を描くといった学習の土台になります。この力は「視覚運動統合（Visual-Motor Integration）」と呼ばれ、日本でも広く使われるフロスティッグ視知覚発達検査（DTVP）の「目と手の協応」下位検査で測定される重要な発達指標です<sup>[1]</sup>。

### 2. 頭の中で図形を動かす力（空間的視覚化・心的回転）

「この形を90°回したらどうなる？」「鏡に映したら？」を頭の中でシミュレーションする力です。回転・線対称・点対称で鍛えられます。中学受験の図形問題、さらには将来の理系的思考の基盤になります。心的回転（メンタルローテーション）の研究は日本でも盛んに行われており、この能力は**練習によって改善できる**ことが示されています<sup>[5]</sup>。

### 3. 見たものを覚えておく力（視覚的作業記憶）

お手本の形を頭に入れたまま、別のグリッドに再現する。2つの図形を同時に覚えて重ね合わせる。こうした「覚えながら作業する」力は、算数の文章題や、複数の情報を組み合わせて考える場面で活きてきます。ワーキングメモリ研究の第一人者である湯澤正通教授（広島大学）らの研究によると、視空間ワーキングメモリは少なくとも6〜7歳までに基礎が存在し、学齢期を通じて徐々に成熟していくことが示されています<sup>[10]</sup>。

### 4. 全体と部分を行き来する力（図形の分析・合成）

「この図形はどんなパーツでできている？」「この2つを重ねたら何になる？」という、全体を分解したり、部分を組み立てたりする力です。欠け補完やかさねで特に鍛えられます。

### 5. 比率や奥行きを理解する力（比例推論・空間推論）

「2倍に拡大する」「立体を平面に描く」といった、より高度な空間把握の力です。拡大・縮小や立体模写で鍛えられ、小学校高学年以降の算数・数学に直結します。

| 2 | 欠け補完 | 消えた線を描き足す | 4〜5歳 |

## 各タイプの詳しい解説

### タイプ1：模写（もしゃ）

**お手本をそのまま写す。点描写のすべての土台。**

```
【やること】
左のグリッドに描かれた図形を、右の空のグリッドにそっくりそのまま描き写す。
```

#### どんな力が育つ？

- **見たものを正確に写す力**が最も直接的に鍛えられます
- 最初は点を1つずつ数えて「上から2番目、左から3番目」と確認しながら描きますが、慣れてくると**図形全体の形を一目でとらえて**描けるようになります
- この「1つずつ数える」から「パッと見て分かる」への変化が、まさに空間認知の発達です

久保田（1970）による図形模写能力の発達研究では、子どもの模写能力が年齢とともにどのように発達するかが体系的に報告されています<sup>[2]</sup>。また、幼児期の描画行動の発達研究では、3歳頃から垂直線や円の模写が可能になり、5歳頃に斜線を含む複雑な図形の模写が安定することが示されています<sup>[3]</sup>。

さらに、フロスティッグ視知覚プログラムを4〜5歳児に実施した研究では、視覚運動能力の向上だけでなく、**自己肯定感の向上や行動面の安定**にも効果があることが報告されています<sup>[24]</sup>。「見て・考えて・描く」というサイクルを繰り返すことで、「できた！」という成功体験が積み重なり、子どもの心の発達にもよい影響を与えるのです。

点描写のグリッドは「外部参照枠」として機能し、子どもが図形を「位置関係の集合」として分析的に捉えることを助けます。ピアジェの空間概念理論においても、座標系を使った空間把握は認知発達の重要なマイルストーンとされています<sup>[7]</sup>。

#### 何が難しくなると、レベルが上がる？

模写は9タイプの中で**最も幅広い難易度レンジ**を持っています。

| レベルの上げ方 | 具体例 |
|---|---|
| グリッドを大きくする | 3×3 → 5×5 → 7×7 |
| 斜めの線を入れる | 縦横だけ → 45度の斜め → もっと急な斜め |
| 線の数を増やす | 3本 → 8本 → 15本 |
| 線を交差させる | 独立した線 → 交差あり → 複雑な交差 |

特に**「斜めの線」が入ると一気に難しくなる**のが特徴です。幼児の描画発達研究において、斜線の模写は垂直・水平線よりも発達的に遅れて獲得されることが一貫して報告されています<sup>[3][4]</sup>。

#### なぜTENZUに入れたの？

入れない理由がありません。模写は点描写の原点であり、**他の8タイプすべての前提**になるスキルです<sup>[15]</sup>。TENZUでは模写だけで**8〜10段階**の難易度を用意する予定です。「3歳の初めての点描写」から「小学校高学年のチャレンジ問題」まで、模写1つで長く使えます。

### タイプ2：欠け補完（かけほかん）

**消えた線を見つけて、描き足して完成させる。「見えないものを見る」力の入り口。**

```
【やること】
お手本の図形から一部の線が消されている。どこが消えているかを見つけ、
描き足して元の図形を完成させる。
```

#### どんな力が育つ？

- **視覚的閉合（Visual Closure）** という、不完全な情報から全体像を推測する力が鍛えられます。フロスティッグ視知覚発達検査（DTVP）でもこの力は独立した下位検査として位置づけられており、4歳から評価対象となっています<sup>[1]</sup>
- これは実は**文字の読み書き**にも深く関わる力です。私たちが手書きの文字を読めるのは、多少崩れていても「全体の形」から文字を推測できるから。欠け補完はまさにこの脳の働きを鍛えます
- 「どこが消えている？」を探す**注意力**も同時に育ちます
- 視覚認知に問題がある児童への指導効果を検討した研究では、視知覚トレーニングが図形の補完能力や学習全般の改善につながることが報告されています<sup>[9]</sup>

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 消す線の量を増やす | 1本消し → 3本消し → 半分消し |
| 推測しにくい形にする | 正方形（推測しやすい）→ 不規則な多角形（推測しにくい）|
| 交差点の近くを消す | 直線部分を消す → 交差点付近を消す |

#### なぜTENZUに入れたの？

模写ができるようになった子どもの**次のステップ**として最適だからです。模写は「見たまま写す」ですが、欠け補完は「見えない部分を頭で補う」。この一歩が、後の対称や回転で求められる**「頭の中で図形を操作する」力の入り口**になります。

### タイプ3：平行移動（へいこういどう）

**形はそのまま、場所だけ変える。最もシンプルな「図形の変換」。**

```
【やること】
「右に3マス」「下に2マス」のように、図形を指定された方向・距離だけ移動した結果を描く。
形も向きも変わらない。位置だけが変わる。
```

#### どんな力が育つ？

- **空間内での位置と方向の把握**が鍛えられます
- 「すべての点を同じ分だけずらす」というルールを一貫して適用する**手順管理力**も育ちます
- 9タイプの中では認知的な負荷が最も軽いタイプですが、子どもが「図形の各点を対応させる」という考え方を身につける入り口になります

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 斜め方向の移動 | 右だけ → 右下（2方向同時）|
| 移動距離を伸ばす | 1マス → 4マス |
| 図形を複雑にする | 三角形 → 複雑な多角形 |

#### なぜTENZUに入れたの？

平行移動は「形を変えずに位置をずらす」だけなので、一見すると簡単すぎるように思えます。でも実は、**回転や対称に進む前の重要な橋渡し**です。

児童・生徒の空間認識に関する研究では、回転・対称の概念理解には「点の位置を対応させて移す」操作の習得が前提として重要であることが示されています<sup>[6]</sup>。平行移動はその最もシンプルな形であり、ここで**「点を1つずつ対応させて移す」という考え方**を身につけておくと、回転や対称にスムーズに進めます。

### タイプ4：線対称（せんたいしょう）

**鏡に映したら、どう見える？ 左右反転の世界を描く。**

```
【やること】
真ん中に引かれた「対称軸」に対して、左側に描かれた図形の鏡像を
右側に描く。折り紙を半分に折って開いたときの、反対側の形。
```

#### どんな力が育つ？

- **頭の中で図形を反転させる力**（空間的視覚化）が鍛えられます
- 「対称軸からの距離を保つ」という**論理的なルール適用**の練習にもなります
- ピアジェの理論では、この「軸を基準に位置を保存する」操作は「具体的操作期（7歳頃〜）」の発達と結びついています<sup>[7][8]</sup>

#### 何が難しくなると、レベルが上がる？

線対称の難易度を決める最大の要素は、**対称軸の向き**です。

| 軸の向き | 難しさ | 理由 |
|---|---|---|
| 縦の軸 | ★☆☆ やさしい | 人間の体や顔が左右対称なので、直感的に分かる |
| 横の軸 | ★★☆ 普通 | 「水面の反射」のイメージ。縦軸ほど直感的ではない |
| 斜めの軸 | ★★★ 難しい | 左右と上下の座標が同時に入れ替わるため、頭の中の処理が一気に複雑になる |

児童・生徒を対象とした空間認識の研究では、**線対称・面対称・点対称の3種を混同する傾向**があること、特に**面対称（斜め軸を含む）の認識が低い**ことが報告されています。同研究では、**実物を提示した条件の方が正答率が高い**ことも確認されており、紙面だけの抽象的な問題に入る前に、具体物での体験を挟むことの有効性が示唆されています<sup>[6]</sup>。

また、図形の対称性に関する教材研究では、**鏡を使った教材が、具体的な操作から抽象的な理解への橋渡しとして有効**であることが報告されています<sup>[11]</sup>。TENZUの難易度設計で「やさしい（縦軸）→ 普通（横軸）→ 難しい（斜め軸）」と段階を分けているのは、こうした知見に基づいています。

#### なぜTENZUに入れたの？

線対称は**小学校の算数で正式に登場する単元**であり、中学受験でも頻出のテーマです。点描写で「手を動かして体感する」ことで、教科書の知識が**体に染み込んだ理解**になります。TENZUでは**縦軸→横軸→斜め軸**の段階をきちんと分けて提供します。

### タイプ5：回転（かいてん）

**形をぐるっと回したら、どうなる？ 頭の中の「回転エンジン」を鍛える。**

```
【やること】
「時計回りに90°回転させなさい」のように、指定された角度で
図形を回した結果を描く。
```

#### どんな力が育つ？

- **心的回転（メンタルローテーション）** という、頭の中で図形を回す力が直接的に鍛えられます
- 心的回転は、空間認知の研究で**最も多く研究されている能力**の1つです<sup>[5]</sup>
- この力は算数・数学の図形分野だけでなく、地図の読み取り、理科の実験観察、さらには将来の工学的・デザイン的思考にまでつながります

日本の心理学研究では、心的回転課題における反応時間は回転角度に応じて線形に増加すること、またこの能力に性差が見られるものの**トレーニングによって差が縮小する**ことが報告されています<sup>[5]</sup>。

興味深いことに、漢字の書字に困難がある児童（平均年齢9.8歳）を対象とした研究では、その困難の原因が汎用的な心的回転の低さではなく、**鏡像判断に特異的な困難**にあることが明らかになっています<sup>[23]</sup>。つまり、「左右を反転させた図形を正しく判断する力」が弱いと、漢字の鏡文字（反転誤り）が生じやすくなるのです。点描写の回転や線対称の練習は、図形の力だけでなく、**文字の正確な読み書きにもつながる**可能性を示す重要な知見です。

#### 何が難しくなると、レベルが上がる？

意外かもしれませんが、**180°回転より90°回転の方が難しい**のです。

| 回転角度 | 難しさ | 理由 |
|---|---|---|
| 180° | ★★☆ やや易しい | 「上下と左右を両方ひっくり返す」というシンプルなルールで処理できる |
| 90°/270° | ★★★ 難しい | 横の線が縦になり、縦の線が横になる。**線の性質が入れ替わる**ため、脳の処理が複雑 |
| 45°など | ★★★★ とても難しい | 通常のグリッドでは正確な表現が難しく、高度な空間把握が必要 |

児童・生徒の空間認識研究でも、**回転方向の認識が低い**ことが課題として報告されており<sup>[6]</sup>、段階的なトレーニングの必要性が示唆されています。

#### なぜTENZUに入れたの？

心的回転能力は**練習で伸びる**ことが研究で繰り返し示されています<sup>[5]</sup>。面白いことに、研究では**回転の概念理解は3〜5歳で急速に発達する**ことが分かっています。つまり、小さな子どもでも「回す」ということ自体は理解できる。ただし、それをグリッド上で正確に描くには7〜8歳まで待つ必要がある、ということです。

TENZUでは、この「概念は早いが作図は後」という特性を活かし、**無料アプリでは早い段階から回転を体験、有料プリントでは作図力がついてからじっくり練習**という設計を考えています。

### タイプ6：かさね

**2つの形を重ねたら、何が見える？ 「統合する力」を鍛える。**

```
【やること】
2つの図形が別々に提示される。これらを同じ位置に重ね合わせたとき、
どんな図形になるかを描く。
```

#### どんな力が育つ？

- **図形の合成力**が鍛えられます。2つの別々の情報を頭の中で統合して、新しい1つの形を作り出す力です
- **視覚的作業記憶**も強く要求されます。2つの図形を同時に頭に入れておかなければならないからです。ワーキングメモリの発達研究によれば、複数の視覚情報を同時に保持・処理する能力は学齢期を通じて徐々に成熟し、課題が複雑になるほど高年齢まで発達が続きます<sup>[10]</sup>
- 重ね合わせの結果、元の図形にはなかった**「新しい形」が生まれる**ことがあります。これに気づく力は、WISC（ウェクスラー式知能検査）の「視覚パズル」で測られる能力と直結しています

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 交差する点を増やす | 線が交わらない → 1箇所交差 → 複数箇所交差 |
| 重ねる図形を増やす | 2つ → 3つ |
| 情報の密度を上げる | スカスカな図形 → 線が密集した図形 |

かさねの特徴は、**グリッドのサイズよりも「交差の複雑さ」が難易度を決める**点です。5×5のグリッドでも、交差が複雑なら十分に難しい問題が作れます。

#### なぜTENZUに入れたの？

かさねは、他の8タイプとは**認知的な操作が違います**。模写・回転・対称が「1つの図形を変換する」のに対し、かさねは「2つの情報を統合する」。この**「統合」の経験**は、算数の文章題（複数の条件を組み合わせて考える）や、理科の実験（複数のデータを重ねて傾向を読む）にも通じる力です。小学校受験でも定番の出題形式であり<sup>[16]</sup>、教材としてのニーズも十分にあります。

### タイプ7：点対称（てんたいしょう）

**中心をぐるっと180°。線対称とは「別の脳の使い方」をするタイプ。**

```
【やること】
中心点を基準に、図形を180°回転させた結果を描く。
すべての点が、中心点を挟んで反対側の同じ距離の位置に移る。
```

#### どんな力が育つ？

- 180°の**心的回転**に加え、**中心点からの座標を抽象的に逆転させる力**が鍛えられます
- 線対称が「軸で折り返す」という比較的イメージしやすい操作なのに対し、点対称は「すべての点を中心点に対して飛ばす」という**より数学的な操作**です

#### 線対称との違いは？

保護者の方から「線対称と点対称って似たようなものでは？」というご質問をいただくことがあります。

実は、脳の中での処理はかなり違います。

| | 線対称 | 点対称 |
|---|---|---|
| イメージ | 鏡に映す / 折り紙を折る | 中心をぐるっと回す |
| 体感しやすさ | 鏡で体験できる → 直感的 | 日常で体験しにくい → 抽象的 |
| 処理方法 | 「軸からの距離を保って反転」 | 「中心からの距離を保って全方向を逆転」 |
| 小学校での登場 | 5年生 | **6年生**（より後に扱われる）|

児童・生徒の空間認識研究では、3種の対称（線対称・面対称・点対称）を**混同する傾向**が報告されており、特に実物を使った体験の有無で正答率に差が出ることも確認されています<sup>[6]</sup>。このことからも、それぞれを独立して丁寧に学ぶことの重要性が分かります。天才ドリルシリーズが点対称を**独立した1冊**にしているのも、この認知的な独立性ゆえです。

#### なぜTENZUに入れたの？

点対称は高難度ですが、それだけに**「できるようになったときの達成感」が大きい**タイプです。また、小学校6年生で学ぶ「点対称な図形」の単元の先取り・定着に直結します。

TENZUでは、点対称に取り組む前に**線対称を十分にマスターすること**を推奨しています。「縦軸で線対称」+「横軸で線対称」を連続で行うと、結果的に点対称になるという橋渡し学習が有効です。

### タイプ8：拡大・縮小（かくだい・しゅくしょう）

**同じ形を、大きくしたり小さくしたり。「比率」を体で覚える。**

```
【やること】
3×3のグリッドに描かれた図形を、6×6のグリッドに2倍に拡大して描く。
あるいはその逆で、半分に縮小して描く。
```

#### どんな力が育つ？

- **比例推論**が鍛えられます。「元の図形で1マスだった距離が、拡大後は2マスになる」という比率の感覚です
- ピアジェの認知発達理論では、比例の理解は**「形式的操作期」（11歳頃〜）の指標能力**とされています<sup>[7]</sup>。ただし、整数倍の単純な拡大なら、それより前の段階から取り組めます
- 面積変化を具現化する教授が大学生にも効果的であったという研究<sup>[12]</sup>が示すように、拡大・縮小における比率の直感的理解は年齢を問わず教育的価値が高いテーマです

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 倍率を変える | 2倍 → 3倍 → 1.5倍 |
| 拡大か縮小か | 拡大（広げる）→ 縮小（狭める）。縮小の方が難しい |
| 図形の細部を増やす | 大まかな形 → 小さな凹凸がある形 |

拡大・縮小は、日本の点描写教材では**あまり見かけないタイプ**です。しかし小学校学習指導要領では「拡大図と縮図」が6年生の単元として位置づけられており<sup>[13]</sup>、教育的重要性は明確です。

#### なぜTENZUに入れたの？

他の教材にないからこそ、TENZUの**差別化ポイント**になります。比例推論は段階的に発達していくため、**細かく刻んだ難易度（6段階以上）**を提供することで、「比率の感覚」を無理なく体に染み込ませることができます。

### タイプ9：立体模写（りったいもしゃ）

**平面の紙の上に、立体を描く。点描写の最終ステージ。**

```
【やること】
立方体やその組み合わせなどの立体図形を、
斜眼（アイソメトリック）グリッドの上にそのまま描き写す。
```

#### どんな力が育つ？

- **3次元の空間推論**が鍛えられます。目の前にある立体を、2次元の紙の上に「どう表現するか」を考える力です
- この「3D→2D変換」は、他の8タイプにはない**唯一のスキル**です
- WISC（ウェクスラー式知能検査）の「積木模様」下位検査と深く関連する能力です

#### 他の8タイプとの大きな違い

立体模写は、**使うグリッドの種類が違います**。他の8タイプは「正方形グリッド」を使いますが、立体模写では**「斜眼グリッド（アイソメトリックグリッド）」**を使います。60度の角度で交わる3方向の点の並びで、この上に描くことで立体を表現できます。

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 立方体の数を増やす | 1個 → 2個横並び → 段積み |
| 隠れる面を増やす | 全面見える → 奥に隠れる面がある |
| 段差・凹凸を入れる | 単純な形 → 階段状 → L字型 |

#### なぜTENZUに入れたの？

立体模写は、**中学受験の空間図形問題に最も直結する**タイプです。

日本の研究では、立方体透視図模写の定量的採点法（10点満点）が開発されており<sup>[14]</sup>、5〜18歳のデータから**9歳頃に模写得点が有意に上昇する**ことが報告されています。さらに同研究では、立方体模写の得点がWAIS-III（成人用知能検査）の複数の下位検査と強い相関を持つことが示されています：**符号 r=.67、絵画完成 r=.54、積木模様 r=.52**。これは、立体模写が「描く力」だけでなく、処理速度・視覚的注意・空間構成といった**複合的な知的能力と結びついている**ことを意味します。

またワーキングメモリ研究の文脈でも、立方体模写の得点は「構成能力」と「運筆能力」によって有意に予測されることが示されています<sup>[10]</sup>。

発達心理学では、8歳未満の子どもは立体を描くとき「平面的な図」として描いてしまう**「知的リアリズム」**の段階にあり、7〜8歳を超えると奥行きを統合的に表現できる**「視覚的リアリズム」**に移行することが分かっています。この発達の節目に合わせた段階設計が重要です。

## 取り組みの順番：「4つのフェーズ」で考える

9タイプには、**取り組みやすい順番**があります。TENZUでは4つのフェーズに分けて考えています。

### フェーズ1：基礎（3〜5歳ごろ）

```
模写 → 欠け補完 → 平行移動
```

まずは「見て写す」から始めます。模写ができるようになったら、「消えた線を足す」欠け補完と、「同じ形を別の場所に描く」平行移動に進みます。この3つは、**形を変えない**タイプです。

### フェーズ2：変換の入り口（5〜7歳ごろ）

```
線対称（縦軸 → 横軸） ＋ 回転（180°）
```

いよいよ「形を変える」世界に入ります。鏡に映す（線対称）とぐるっと回す（回転の180°）。この2つは**並行して取り組むことも可能**です。

### フェーズ3：変換の深化（7〜9歳ごろ）

```
線対称（斜め軸） ＋ 回転（90°） ＋ かさね ＋ 拡大・縮小 ＋ 立体模写（入門）
```

フェーズ2の発展形に加え、新しいタイプ（かさね・拡大縮小・立体）が登場します。このフェーズでは**子どもの得意不得意に合わせて、進む順番を変えてOK**です。

### フェーズ4：抽象操作（9歳〜）

```
点対称 ＋ 回転（非直角） ＋ 拡大・縮小（非整数倍） ＋ 立体模写（複合）
```

高度な操作の世界。ここまで来ると、小学校の算数を超えた**数学的思考**の領域に入ります。中学受験を見据えたお子さんにとって、大きなアドバンテージになるフェーズです。

## 大切なのは「順番」と「スモールステップ」

### 全部やる必要はない

9タイプすべてを制覇する必要はまったくありません。お子さんの年齢、目的、興味に合わせて、**必要なタイプを必要な段階だけ**取り組めばOKです。

### 「できた！」の積み重ねが一番大事

点描写の一番の価値は、**正解が目に見える**ことです。お手本と見比べれば、合っているかどうかがすぐ分かる。だから「できた！」という達成感を得やすく、子どもが自分から「もう1枚やりたい」と思える教材です<sup>[15]</sup>。

教育における認知負荷の研究では、課題が適切な難易度に設定されていることで学習効率が最大化されることが示されています<sup>[17]</sup>。TENZUが各タイプで細かく難易度を分けているのは、この「スモールステップ」を実現するためです。

### タスクごとに得手不得手がある

「模写は得意なのに回転ができない」「線対称はできるのにかさねが苦手」ということは普通にあります。9タイプはそれぞれ**脳の使う場所が違う**ので、統一的な「レベル」は存在しません。

フロスティッグ視知覚発達検査でも、同じ「視知覚」領域内に複数の下位検査が併置され、個人のプロファイル（得意不得意の凹凸）を見る設計になっています<sup>[1]</sup>。TENZUでも同様に、「うちの子は回転が苦手 → 回転を段階的に練習する」という**タイプ別の取り組み**を基本にしています。

---

## まとめ：9タイプで「図形力」をまるごと鍛える

| 得られる力 | 関連するタイプ |
|---|---|
| 見たものを正確に写す力 | 模写、立体模写 |
| 頭の中で図形を動かす力 | 回転、線対称、点対称 |
| 覚えながら作業する力 | かさね、拡大・縮小 |
| 全体と部分を行き来する力 | 欠け補完、かさね |
| 比率や奥行きを理解する力 | 拡大・縮小、立体模写 |

点描写は「模写」だけではありません。9つのタイプを体系的に、発達の順番に沿って取り組むことで、**図形力をまるごと鍛える**ことができます。そして研究が示すように、その効果は認知能力だけにとどまりません。「できた！」の積み重ねは、**子どもの自己肯定感や情緒面の安定**にもつながっていくのです<sup>[24]</sup>。

TENZUは、この9タイプを**レベルで選べて、中身が見える**形でお届けする、点描写の専門店です。
