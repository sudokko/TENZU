# 点描写には「9つのタイプ」がある ― TENZUが体系化した理由と、身につく力のすべて

> **この記事の対象読者**: 点描写プリントを子どもにやらせたいけど、「模写以外に何があるの？」「どの順番でやればいいの？」が分からない保護者の方

---

## はじめに：「点描写＝模写」だけではもったいない

「点描写」と聞いて、多くの方がイメージするのは**お手本をそのまま写す「模写」**ではないでしょうか。

もちろん模写は点描写の基本であり、とても大切な練習です。でも実は、点描写にはお手本を写す以外にも**9つの異なるタイプ**があり、それぞれが子どもの**異なる脳の力**を鍛えてくれます。

TENZUでは、この9タイプを**発達の順番に沿って体系化**しました。

この記事では、
- なぜ9タイプなのか
- どんな順番で取り組むべきか
- それぞれどんな力が身につくのか

を、できるだけ分かりやすくお伝えします。

---

## 点描写で育つ「5つの力」

9タイプの詳細に入る前に、点描写全体で育つ力を整理しておきましょう。

### 1. 見たものを正確に写しとる力（視覚運動統合）

目で見た情報を、手を使って正確に再現する力です。模写や立体模写で特に鍛えられます。文字を書く、図を描くといった学習の土台になります。この力は「視覚運動統合（Visual-Motor Integration）」と呼ばれ、国際的に標準化された認知検査（Beery VMI）でも測定される重要な発達指標です<sup>[4][5]</sup>。

### 2. 頭の中で図形を動かす力（空間的視覚化・心的回転）

「この形を90°回したらどうなる？」「鏡に映したら？」を頭の中でシミュレーションする力です。回転・線対称・点対称で鍛えられます。中学受験の図形問題、さらには将来の理系的思考の基盤になります。研究によれば、空間認知能力は**練習によって改善できる（malleable）**ことがメタ分析で繰り返し示されています<sup>[10]</sup>。

### 3. 見たものを覚えておく力（視覚的作業記憶）

お手本の形を頭に入れたまま、別のグリッドに再現する。2つの図形を同時に覚えて重ね合わせる。こうした「覚えながら作業する」力は、算数の文章題や、複数の情報を組み合わせて考える場面で活きてきます。視覚的作業記憶は6歳から14歳にかけて継続的に発達することが示されています<sup>[16]</sup>。

### 4. 全体と部分を行き来する力（図形の分析・合成）

「この図形はどんなパーツでできている？」「この2つを重ねたら何になる？」という、全体を分解したり、部分を組み立てたりする力です。欠け補完やかさねで特に鍛えられます。

### 5. 比率や奥行きを理解する力（比例推論・空間推論）

「2倍に拡大する」「立体を平面に描く」といった、より高度な空間把握の力です。拡大・縮小や立体模写で鍛えられ、小学校高学年以降の算数・数学に直結します。

## 9つのタイプ一覧

TENZUが扱う9つの設問タイプを、**取り組む順番**に並べると以下のようになります。

| 順番 | タイプ | ひとことで言うと | 目安の開始年齢 |
|---|---|---|---|
| 1 | 模写 | お手本をそのまま写す | 3〜4歳 |
| 2 | 欠け補完 | 消えた線を描き足す | 4〜5歳 |
| 3 | 平行移動 | 同じ形を別の場所に描く | 5〜6歳 |
| 4 | 線対称 | 鏡に映した形を描く | 5〜6歳 |
| 5 | 回転 | 形を回した結果を描く | 7〜8歳 |
| 6 | かさね | 2つの形を重ねた結果を描く | 7〜8歳 |
| 7 | 点対称 | 中心をぐるっと回した形を描く | 8〜10歳 |
| 8 | 拡大・縮小 | 同じ形を大きく/小さく描く | 8〜10歳 |
| 9 | 立体模写 | 立体をそのまま写す | 8〜9歳 |

> **年齢はあくまで目安です。** 大切なのは年齢ではなく、「前のタイプがある程度できてから次に進む」こと。詳しくは後述の「取り組みの順番」で説明します。

## 各タイプの詳しい解説

### タイプ1：模写（もしゃ）

**お手本をそのまま写す。点描写のすべての土台。**

```
【やること】
左のグリッドに描かれた図形を、右の空のグリッドにそっくりそのまま描き写す。
```

#### どんな力が育つ？

- **見たものを正確に写す力**が最も直接的に鍛えられます
- 最初は点を1つずつ数えて「上から2番目、左から3番目」と確認しながら描きますが、慣れてくると**図形全体の形を一目でとらえて**描けるようになります
- この「1つずつ数える」から「パッと見て分かる」への変化が、まさに空間認知の発達です

発達段階の研究によれば、子どもは2歳で垂直線、3歳で円と水平線、4歳で十字と四角形、5歳でようやく斜線を含む図形を正確に模写できるようになります<sup>[1][2]</sup>。この発達順序は、標準化された認知検査「NEPSY-II（Design Copying下位検査）」でも3歳から評価対象となっており<sup>[3]</sup>、「Beery VMI」においても模写を中心に視覚運動統合を測定しています<sup>[4]</sup>。

点描写のグリッドは「外部参照枠」として機能し、子どもが図形を「位置関係の集合」として分析的に捉えることを助けます。ピアジェの空間概念理論においても、座標系を使った空間把握は認知発達の重要なマイルストーンとされています<sup>[9]</sup>。

#### 何が難しくなると、レベルが上がる？

模写は9タイプの中で**最も幅広い難易度レンジ**を持っています。

| レベルの上げ方 | 具体例 |
|---|---|
| グリッドを大きくする | 3×3 → 5×5 → 7×7 |
| 斜めの線を入れる | 縦横だけ → 45度の斜め → もっと急な斜め |
| 線の数を増やす | 3本 → 8本 → 15本 |
| 線を交差させる | 独立した線 → 交差あり → 複雑な交差 |

特に**「斜めの線」が入ると一気に難しくなる**のが特徴です。縦と横の線は「まっすぐ右」「まっすぐ下」で描けますが、斜めの線は「右に2マス、上に1マス」のように2つの方向を同時に考える必要があるからです<sup>[1]</sup>。

#### なぜTENZUに入れたの？

入れない理由がありません。模写は点描写の原点であり、**他の8タイプすべての前提**になるスキルです<sup>[22]</sup>。TENZUでは模写だけで**8〜10段階**の難易度を用意する予定です。「3歳の初めての点描写」から「小学校高学年のチャレンジ問題」まで、模写1つで長く使えます。

### タイプ2：欠け補完（かけほかん）

**消えた線を見つけて、描き足して完成させる。「見えないものを見る」力の入り口。**

```
【やること】
お手本の図形から一部の線が消されている。どこが消えているかを見つけ、
描き足して元の図形を完成させる。
```

#### どんな力が育つ？

- **視覚的閉合（Visual Closure）** という、不完全な情報から全体像を推測する力が鍛えられます<sup>[6]</sup>。「視覚的閉合」とは、不完全に描かれた図形を見て、欠けた部分を脳が自動的に補い、完全な形として認識する能力のことです
- これは実は**文字の読み書き**にも深く関わる力です。私たちが手書きの文字を読めるのは、多少崩れていても「全体の形」から文字を推測できるから。欠け補完はまさにこの脳の働きを鍛えます<sup>[6]</sup>
- 「どこが消えている？」を探す**注意力**も同時に育ちます
- 視覚的閉合は標準化検査「DTVP-3（視覚知覚発達検査 第3版）」の独立した下位検査として位置づけられており、4〜12歳の発達評価に使用されています<sup>[7]</sup>

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 消す線の量を増やす | 1本消し → 3本消し → 半分消し |
| 推測しにくい形にする | 正方形（推測しやすい）→ 不規則な多角形（推測しにくい）|
| 交差点の近くを消す | 直線部分を消す → 交差点付近を消す |

図形の「予測可能性」も難易度を左右します。円や正方形のような強いゲシュタルト（まとまり）を持つ図形は欠損していても補完しやすいですが、不規則な多角形では難易度が著しく上昇します<sup>[7]</sup>。

#### なぜTENZUに入れたの？

模写ができるようになった子どもの**次のステップ**として最適だからです。模写は「見たまま写す」ですが、欠け補完は「見えない部分を頭で補う」。この一歩が、後の対称や回転で求められる**「頭の中で図形を操作する」力の入り口**になります。

### タイプ3：平行移動（へいこういどう）

**形はそのまま、場所だけ変える。最もシンプルな「図形の変換」。**

```
【やること】
「右に3マス」「下に2マス」のように、図形を指定された方向・距離だけ移動した結果を描く。
形も向きも変わらない。位置だけが変わる。
```

#### どんな力が育つ？

- **空間内での位置と方向の把握**が鍛えられます<sup>[21]</sup>
- 「すべての点を同じ分だけずらす」というルールを一貫して適用する**手順管理力**も育ちます
- 9タイプの中では認知的な負荷が最も軽いタイプですが、子どもが「図形の各点を対応させる」という考え方を身につける入り口になります

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 斜め方向の移動 | 右だけ → 右下（2方向同時）|
| 移動距離を伸ばす | 1マス → 4マス |
| 図形を複雑にする | 三角形 → 複雑な多角形 |

研究によれば、斜め方向への移動は水平・垂直の移動に比べて格段に難しく、x方向とy方向を同時に処理する必要があるため認知的負荷が大きく上昇します<sup>[21]</sup>。

#### なぜTENZUに入れたの？

平行移動は「形を変えずに位置をずらす」だけなので、一見すると簡単すぎるように思えます。でも実は、**回転や対称に進む前の重要な橋渡し**です。「点を1つずつ対応させて移す」という考え方をここで身につけておくことで、回転や対称にスムーズに進めます<sup>[12]</sup>。

### タイプ4：線対称（せんたいしょう）

**鏡に映したら、どう見える？ 左右反転の世界を描く。**

```
【やること】
真ん中に引かれた「対称軸」に対して、左側に描かれた図形の鏡像を
右側に描く。折り紙を半分に折って開いたときの、反対側の形。
```

#### どんな力が育つ？

- **頭の中で図形を反転させる力**（空間的視覚化）が鍛えられます
- 「対称軸からの距離を保つ」という**論理的なルール適用**の練習にもなります
- ピアジェの理論では、この「軸を基準に位置を保存する」操作は「具体的操作期（7歳頃〜）」の発達と結びついています<sup>[9][15]</sup>

#### 何が難しくなると、レベルが上がる？

線対称の難易度を決める最大の要素は、**対称軸の向き**です。

| 軸の向き | 難しさ | 理由 |
|---|---|---|
| 縦の軸 | ★☆☆ やさしい | 人間の体や顔が左右対称なので、直感的に分かる |
| 横の軸 | ★★☆ 普通 | 「水面の反射」のイメージ。縦軸ほど直感的ではない |
| 斜めの軸 | ★★★ 難しい | 左右と上下の座標が同時に入れ替わるため、頭の中の処理が一気に複雑になる |

幾何学的変換の発達研究によれば、子どもは対称の理解を**「長さが同じ」→「角度が同じ」→「向きが逆」**の順番でステップアップしていきます<sup>[8]</sup>。また、幼児研究では**斜め軸の反射は特に難しく**、水平・垂直軸と比べて正答率が低いことが一貫して報告されています<sup>[8]</sup>。

#### なぜTENZUに入れたの？

線対称は**小学校の算数で正式に登場する単元**であり、中学受験でも頻出のテーマです。点描写で「手を動かして体感する」ことで、教科書の知識が**体に染み込んだ理解**になります。TENZUでは**縦軸→横軸→斜め軸**の段階をきちんと分けて提供します<sup>[23]</sup>。

### タイプ5：回転（かいてん）

**形をぐるっと回したら、どうなる？ 頭の中の「回転エンジン」を鍛える。**

```
【やること】
「時計回りに90°回転させなさい」のように、指定された角度で
図形を回した結果を描く。
```

#### どんな力が育つ？

- **心的回転（Mental Rotation）** という、頭の中で図形を回す力が直接的に鍛えられます<sup>[10]</sup>
- 心的回転は、空間認知の研究で**最も多く研究されている能力**の1つで、地図の読み取り、理科の実験観察、工学的・デザイン的思考にまでつながります<sup>[11]</sup>
- 7〜11歳の空間推論の発達軌跡を追った研究では、心的回転は学校教育の中で継続的に伸びる重要な能力として位置づけられています<sup>[16]</sup>

#### 何が難しくなると、レベルが上がる？

意外かもしれませんが、**180°回転より90°回転の方が難しい**のです。

| 回転角度 | 難しさ | 理由 |
|---|---|---|
| 180° | ★★☆ やや易しい | 「上下と左右を両方ひっくり返す」というシンプルなルールで処理できる |
| 90°/270° | ★★★ 難しい | 横の線が縦になり、縦の線が横になる。**線の性質が入れ替わる**ため、脳の処理が複雑 |
| 45°など | ★★★★ とても難しい | 通常のグリッドでは正確な表現が難しく、高度な空間把握が必要 |

この180°と90°の難易度の順序は、幾何学的変換を扱う教育研究でも実証されています<sup>[12]</sup>。また、**回転の中心がどこにあるか**でも難易度が変わります。図形の外の点を中心に回す場合、頭の中で軌道をシミュレーションする必要があるため格段に難しくなります<sup>[10]</sup>。

#### なぜTENZUに入れたの？

心的回転能力は**練習で伸びる**ことが研究で繰り返し示されています<sup>[10][11]</sup>。面白いことに、研究では**回転の概念理解は3〜5歳で急速に発達する**ことが分かっています<sup>[10]</sup>。つまり、小さな子どもでも「回す」ということ自体は理解できる。ただし、それをグリッド上で正確に描くには7〜8歳まで待つ必要がある、ということです。

TENZUでは、この「概念は早いが作図は後」という特性を活かし、**無料アプリでは早い段階から回転を体験、有料プリントでは作図力がついてからじっくり練習**という設計を考えています。

### タイプ6：かさね

**2つの形を重ねたら、何が見える？ 「統合する力」を鍛える。**

```
【やること】
2つの図形が別々に提示される。これらを同じ位置に重ね合わせたとき、
どんな図形になるかを描く。
```

#### どんな力が育つ？

- **図形の合成力**が鍛えられます。2つの別々の情報を頭の中で統合して、新しい1つの形を作り出す力です
- **視覚的作業記憶**も強く要求されます。2つの図形を同時に頭に入れておかなければならないからです
- 重ね合わせの結果、元の図形にはなかった**「新しい形」が生まれる**ことがあります。これに気づく「図形の分解・再構成力」は、WISC-V（ウェクスラー式知能検査 第5版）の「視覚パズル」下位検査で測られる能力と直結しています<sup>[13]</sup>
- 「どの線がどの図形のものか」を識別する**「図と地の分離（Figure-Ground）」**能力も鍛えられます<sup>[20]</sup>

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 交差する点を増やす | 線が交わらない → 1箇所交差 → 複数箇所交差 |
| 重ねる図形を増やす | 2つ → 3つ |
| 情報の密度を上げる | スカスカな図形 → 線が密集した図形 |

かさねの特徴は、**グリッドのサイズよりも「交差の複雑さ」が難易度を決める**点です。5×5のグリッドでも、交差が複雑なら十分に難しい問題が作れます。

#### なぜTENZUに入れたの？

かさねは、他の8タイプとは**認知的な操作が違います**。模写・回転・対称が「1つの図形を変換する」のに対し、かさねは「2つの情報を統合する」。この**「統合」の経験**は、算数の文章題（複数の条件を組み合わせて考える）や、理科の実験（複数のデータを重ねて傾向を読む）にも通じる力です。小学校受験でも定番の出題形式であり<sup>[23]</sup>、教材としてのニーズも十分にあります。

### タイプ7：点対称（てんたいしょう）

**中心をぐるっと180°。線対称とは「別の脳の使い方」をするタイプ。**

```
【やること】
中心点を基準に、図形を180°回転させた結果を描く。
すべての点が、中心点を挟んで反対側の同じ距離の位置に移る。
```

#### どんな力が育つ？

- 180°の**心的回転**に加え、**中心点からの座標を抽象的に逆転させる力**が鍛えられます
- 線対称が「軸で折り返す」という比較的イメージしやすい操作なのに対し、点対称は「すべての点を中心点に対して飛ばす」という**より数学的な操作**です<sup>[8]</sup>

#### 線対称との違いは？

保護者の方から「線対称と点対称って似たようなものでは？」というご質問をいただくことがあります。

実は、脳の中での処理はかなり違います。

| | 線対称 | 点対称 |
|---|---|---|
| イメージ | 鏡に映す / 折り紙を折る | 中心をぐるっと回す |
| 体感しやすさ | 鏡で体験できる → 直感的 | 日常で体験しにくい → 抽象的 |
| 処理方法 | 「軸からの距離を保って反転」 | 「中心からの距離を保って全方向を逆転」 |
| 小学校での登場 | 5年生 | **6年生**（より後に扱われる）|

興味深いことに、幼児研究では**回転（＝点対称の基本操作）の概念理解は反射（＝線対称）よりも早期に成立する**ことが報告されています<sup>[10]</sup>。ただし、「概念を理解すること」と「グリッド上で正確に描くこと」は別であり、中心点からの座標を保ちながら全点を移す作図は8〜10歳まで安定しません<sup>[8]</sup>。

天才ドリルシリーズが点対称を**独立した1冊**にしているのも、この認知的な独立性ゆえです。

#### なぜTENZUに入れたの？

点対称は高難度ですが、それだけに**「できるようになったときの達成感」が大きい**タイプです。また、小学校6年生で学ぶ「点対称な図形」の単元の先取り・定着に直結します。

TENZUでは、点対称に取り組む前に**線対称を十分にマスターすること**を推奨しています。「縦軸で線対称」+「横軸で線対称」を連続で行うと、結果的に点対称になるという橋渡し学習が有効です<sup>[12]</sup>。

---

### タイプ8：拡大・縮小（かくだい・しゅくしょう）

**同じ形を、大きくしたり小さくしたり。「比率」を体で覚える。**

```
【やること】
3×3のグリッドに描かれた図形を、6×6のグリッドに2倍に拡大して描く。
あるいはその逆で、半分に縮小して描く。
```

#### どんな力が育つ？

- **比例推論**が鍛えられます。「元の図形で1マスだった距離が、拡大後は2マスになる」という比率の感覚です<sup>[14]</sup>
- 子どもは7歳頃から、図形の**「中点（真ん中）」を手がかりにして分割する戦略**を使い始めることが明らかにされています<sup>[14]</sup>。拡大・縮小はこの戦略を自然に引き出す練習になります
- ピアジェの認知発達理論では、比例の本格的な理解は**「形式的操作期」（11歳頃〜）の指標能力**とされています<sup>[15]</sup>。ただし、整数倍の単純な拡大なら、それより前から取り組めます

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 倍率を変える | 2倍 → 3倍 → 1.5倍 |
| 拡大か縮小か | 拡大（広げる）→ 縮小（狭める）。縮小の方が難しい |
| 図形の細部を増やす | 大まかな形 → 小さな凹凸がある形 |

比例推論は5〜9歳の間に段階的に発達していくことが研究で示されています<sup>[14]</sup>。この段階的な発達に合わせて**細かく刻んだ難易度（6段階以上）**を提供することで、「比率の感覚」を無理なく体に染み込ませることができます。

拡大・縮小は、日本の点描写教材では**あまり見かけないタイプ**です。しかし海外（特にイギリス）では "enlargement" として中学数学の定番テーマであり<sup>[12]</sup>、教育的価値は高く評価されています。

#### なぜTENZUに入れたの？

他の教材にないからこそ、TENZUの**差別化ポイント**になります。海外の研究知見に基づき、段階設計を丁寧に行うことで、「比率の体感」という他にはない学習体験を提供します。

---

### タイプ9：立体模写（りったいもしゃ）

**平面の紙の上に、立体を描く。点描写の最終ステージ。**

```
【やること】
立方体やその組み合わせなどの立体図形を、
斜眼（アイソメトリック）グリッドの上にそのまま描き写す。
```

#### どんな力が育つ？

- **3次元の空間推論**が鍛えられます。目の前にある立体を、2次元の紙の上に「どう表現するか」を考える力です
- この「3D→2D変換」は、他の8タイプにはない**唯一のスキル**です
- WISC-V（ウェクスラー式知能検査 第5版）の「積木模様（Block Design）」下位検査と深く関連する能力です<sup>[13]</sup>

#### 他の8タイプとの大きな違い

立体模写は、**使うグリッドの種類が違います**。他の8タイプは「正方形グリッド」を使いますが、立体模写では**「斜眼グリッド（アイソメトリックグリッド）」**を使います。60度の角度で交わる3方向の点の並びで、この上に描くことで立体を表現できます。

#### 何が難しくなると、レベルが上がる？

| レベルの上げ方 | 具体例 |
|---|---|
| 立方体の数を増やす | 1個 → 2個横並び → 段積み |
| 隠れる面を増やす | 全面見える → 奥に隠れる面がある |
| 段差・凹凸を入れる | 単純な形 → 階段状 → L字型 |

#### なぜTENZUに入れたの？

立体模写は、**中学受験の空間図形問題に最も直結する**タイプです。

発達研究によれば、8歳未満の子どもは立体を描くとき「平面的な図」として描いてしまう**「知的リアリズム」**の段階にあり、7〜8歳を超えると奥行きを統合的に表現できる**「視覚的リアリズム」**に移行することが明らかにされています<sup>[17]</sup>。

日本の研究では、等角（アイソメトリック）立方体の模写得点が**8〜9歳で有意に上昇**し、その得点は「構成能力」と「運筆能力」によって有意に予測されることが報告されています<sup>[18]</sup>。この発達の節目に合わせた段階設計が重要です。

## 取り組みの順番：「4つのフェーズ」で考える

9タイプには、**取り組みやすい順番**があります。TENZUでは4つのフェーズに分けて考えています<sup>[16]</sup>。

### フェーズ1：基礎（3〜5歳ごろ）

```
模写 → 欠け補完 → 平行移動
```

まずは「見て写す」から始めます。模写ができるようになったら、「消えた線を足す」欠け補完と、「同じ形を別の場所に描く」平行移動に進みます。この3つは、**形を変えない**タイプです。

### フェーズ2：変換の入り口（5〜7歳ごろ）

```
線対称（縦軸 → 横軸） ＋ 回転（180°）
```

いよいよ「形を変える」世界に入ります。鏡に映す（線対称）とぐるっと回す（回転の180°）。この2つは**並行して取り組むことも可能**です。幼児期の研究では、回転の概念は5歳頃から急速に発達し、線対称（特に斜め軸）はやや後になって安定してくることが示されています<sup>[8][10]</sup>。

### フェーズ3：変換の深化（7〜9歳ごろ）

```
線対称（斜め軸） ＋ 回転（90°） ＋ かさね ＋ 拡大・縮小 ＋ 立体模写（入門）
```

フェーズ2の発展形に加え、新しいタイプ（かさね・拡大縮小・立体）が登場します。7〜11歳は空間推論が急速に伸びる時期として研究で注目されています<sup>[16]</sup>。このフェーズでは**子どもの得意不得意に合わせて、進む順番を変えてOK**です。

### フェーズ4：抽象操作（9歳〜）

```
点対称 ＋ 回転（非直角） ＋ 拡大・縮小（非整数倍） ＋ 立体模写（複合）
```

高度な操作の世界。ここまで来ると、小学校の算数を超えた**数学的思考**の領域に入ります。中学受験を見据えたお子さんにとって、大きなアドバンテージになるフェーズです。

## 大切なのは「順番」と「スモールステップ」

### 全部やる必要はない

9タイプすべてを制覇する必要はまったくありません。お子さんの年齢、目的、興味に合わせて、**必要なタイプを必要な段階だけ**取り組めばOKです。

### 「できた！」の積み重ねが一番大事

点描写の一番の価値は、**正解が目に見える**ことです。お手本と見比べれば、合っているかどうかがすぐ分かる。だから「できた！」という達成感を得やすく、子どもが自分から「もう1枚やりたい」と思える教材です<sup>[22]</sup>。

認知負荷理論（Cognitive Load Theory）によれば、課題が適切な難易度に設定されていることで学習効率が最大化されます<sup>[19]</sup>。TENZUが各タイプで細かく難易度を分けているのは、この「スモールステップ」を実現するためです。

### タスクごとに得手不得手がある

「模写は得意なのに回転ができない」「線対称はできるのにかさねが苦手」ということは普通にあります。9タイプはそれぞれ**脳の使う場所が違う**ので、統一的な「レベル」は存在しません<sup>[16]</sup>。

TENZUでは「うちの子は回転が苦手 → 回転を段階的に練習する」という**タイプ別の取り組み**を基本にしています。

## まとめ：9タイプで「図形力」をまるごと鍛える

| 得られる力 | 関連するタイプ |
|---|---|
| 見たものを正確に写す力 | 模写、立体模写 |
| 頭の中で図形を動かす力 | 回転、線対称、点対称 |
| 覚えながら作業する力 | かさね、拡大・縮小 |
| 全体と部分を行き来する力 | 欠け補完、かさね |
| 比率や奥行きを理解する力 | 拡大・縮小、立体模写 |

点描写は「模写」だけではありません。9つのタイプを体系的に、発達の順番に沿って取り組むことで、**図形力をまるごと鍛える**ことができます。

TENZUは、この9タイプを**レベルで選べて、中身が見える**形でお届けする、点描写の専門店です。
