# てんびょうしゃ モチーフ生成 プロトタイプ

## セッション: 2026-03-18

### 背景
ピグマリオン「てんびょうしゃ かんたん」シリーズのように、
**現実の物体をモチーフにした点描写問題**を自動生成するプログラムの開発を検討。

### 分析した参考教材
- ピグマリオン kantan-6, 7, 9, 10（すたべんドリル）
- 6×7ドットグリッド、物体モチーフ（家・船・封筒等）
- 1ページ3問、お手本＋空グリッド構成

### 検討した生成アプローチ

| アプローチ | 内容 | 評価 |
|---|---|---|
| テンプレート＋バリエーション（反転・回転） | 1モチーフから機械的に派生 | ❌ 品質が微妙。ユーザーに出せるレベルにならない |
| **A案: LLMに座標を直接生成させる** | Claude/ChatGPTにJSON座標データを出力させる | ✅ **本プロトで検証 → 結構いける** |
| **C案: SVGアイコン→グリッドスナップ** | フリーSVG素材の輪郭をグリッド点に変換 | 🔍 未検証。素材探し中 |
| B案: 画像生成→CV→スナップ | ChatGPT画像生成→輪郭抽出→グリッド化 | △ パイプライン複雑、精度不安 |

### 結論
- **A案（LLM直接生成）は実用レベル**で動くことを確認
- まず動物20モチーフをLLMで生成し、SVGプレビューで品質確認済み
- C案（SVGアイコン活用）は別途素材探しの上で検証予定

### 今回のプロトで作ったもの
1. `tenbyo-preview.html` — SVGプレビューア＋動物モチーフ20個
   - グリッド: 6列×7行（座標 [col, row]、左上 [0,0]）
   - お手本（線あり）＋解答欄（空グリッド）の対表示
   - モチーフデータはJSON形式で定義
