# ブランディングコンセプト1行の確定とタグライン第4世代（西澤フレームの導入）

## 何が起きたか（要約）

オーナーが西澤明洋『ブランディングデザイン』を読み、TENZU には「全施策を焦点させる1行」＝ブランディングコンセプトと、クリティカルコアが未定義だと確認したのが発端。2026-07-05 の1日で「考えながら書く力を育てる、点図形（点描写）プリント専門店」をコンセプトとして brand.md §0 に戴冠し、タグラインを第4世代の3段セット——コア「見て、考えて、書く力を、点描写から。」＋サブ＋業態識別句（不変）——へ更新、主戦場を「就学前後（年長〜小1前半・年長中心）」へ絞り込んだ。GPT-5／Gemini／Claude の3-way DR は全会一致。decisions §3.62 として brand.md・voice-tone.md・targeting.md・positioning.md・personas.md・領域 README へ一括反映した。案H''（2026-05-22 の1日3転）以来のブランド大改修だが、web 実装への影響はゼロだった。

## 状況・背景

案H'' でブランドの部品——Promise・Pillars 5本・タグライン——は揃っていた。しかしそれらは「何を約束し、どう語るか」の層であり、「施策の取捨をどこへ焦点させるか」を1行で答える芯が無かった。施策が増えるたび、判断は部品ごとの照合になっていた。オーナーは原案「考えながら書く」を持ち込み、検討の到達点をいったん ideas/ に status: alive で退避してから確定セッションに進んだ。当時のコア第3世代「図形の基礎は、点描写から。」には、図形単独アンカーが年長親のペインとズレるという懸念が既にあり、タグラインはコンセプトとセットで変える意向が固まっていた。

## やり取りの中身

**コンセプト語の選定**。オーナー原案の動詞は「書く」。対抗候補「写す」「描く」「とらえる」を検討した末に棄却し、序列は書く＞とらえる＞写す＞描くとなった。ロジックはこうだ——年長の「かく」は考えないかき（点つなぎ・運筆）が中心で、小1でひらがな・計算・板書と「考えながら書く」行為が一気に要求される。点描写はその予行演習である。学術裏付け（視覚空間処理が書字・算数を予測する）は捨てず、「年長の親の言葉への翻訳」と位置付けた。

**3-way DR とタグラインの収束**。確定は GPT-5／Gemini／Claude の3-way DR にかけ、全会一致で通した。コア「見て、考えて、書く力を、点描写から。」は GPT-5 第一推奨と Claude 案2 が同型に収束したもので、「書く」の漢字表記と点描写単独アンカーは 3-0。GPT-5 追加ラウンドのブレンド案「見て考えて書く、図形の土台を点描写から。」は係り受けの曖昧さと図形回帰を理由に不採用とし、ターゲット幅ラベル「就学前後」だけを採用した。コンセプトの「ながら」（同時性）は §0 側で保持し、タグラインはそのフロント・レンダリングとして行為の三拍で表す、という役割分担も明文化した。

**降格温存と年齢バンド再定義**。旧コア「図形の基礎は、点描写から。」は図形文脈バリアントへ、旧旧コア「点と点がつなげるようになったら、点描写を。」はオンボーディング用途へ降格温存。targeting.md §0 に年齢バンドを新設し、メイン年長＞年中＞小1、従来の3セグメント S-a/b/c は語り分けレイヤーへ降格した。外向けには「点つなぎ・運筆は考えていない」を出さず階段表現にする、「入学までに」型の時間軸煽りに転じない、の2本のガードレールを敷いた。同日後半にはクリティカルコア「設計図ごと、全部公開する」も §0.5 に戴冠している（decisions §4.9）。

## なぜそう判断したか

**フレームを外から借りた理由**。部品が揃っていても、施策判断のたびに Promise や Pillar を照合するのはコストが高い。個人運営では「この施策はコンセプトに寄与するか」と1行に問える方が速い。専門家の完成されたフレームを借りることで、判断構造を自前で発明する遠回りを避けた。

**「図形」から「書く」へ軸足を移した理由**。年長親にとって図形はまだ遠く、目前の関心は文字と入学後の学習である。ただし「図形」は検索でもコピーでも最も効く語なので、捨てずにサブタグラインと図形文脈バリアントへ残した。主語を替え、効く語は配置を替えて温存する二段構えである。

**年齢バンドを昇格しても商品を触らなかった理由**。pack-design §12.7 で Lv.3＝年長標準・5×5 主戦場は既定義で、商品はもともと年長中心に設計されていた。ズレていたのはメッセージ側だけであり、再定義はメッセージ層の書き換えのみで完結した。SEO 上も年齢系キーワードは競合が薄く（年長320・小1 320・年中110）、「運筆 プリント」（5,400 VOL・競合性1）を階段の隣接地として取りに行ける。

**3-way DR を確定条件にした理由**。案H'' のときは1日に3転した（EP-052〜054）。今回は独立した3モデルの推奨が同型に収束したことを確定の条件とし、確定後に SSOT 一括反映まで同日で走り切ることで、再転のスキを構造的に塞いだ。

## 学び（一般化できるノウハウ）

1. **部品が揃っていても「1行の判断軸」は別レイヤーで要る** — Promise・Pillar・タグラインは表現の部品であり、施策の取捨を焦点させるコンセプトとは層が違う。判断軸の1行が無いと、施策判断は毎回の部品照合に退化する。完成済みの外部フレームを借りるのが最短。

2. **旧コピーは削除でなく用途限定で降格する** — 効く語を含む旧コピーは、主役から降ろしても文脈バリアントとして温存すれば資産を捨てずに軸を移せる。降格先（どの文脈でだけ使うか）まで明文化するのが要点で、曖昧に残すと旧コピーが勝手に主役へ戻る。

3. **ターゲット再定義は「商品とメッセージのどちらがズレているか」を先に切り分ける** — 再定義と聞くと商品改修を連想するが、商品側が既に新ターゲット標準で設計されていれば変更はメッセージ層で完結する。この切り分けを先にやると改修範囲が一桁変わる。
