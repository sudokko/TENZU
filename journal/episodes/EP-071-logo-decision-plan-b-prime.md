# D0 ロゴ確定（案B' 幾何ブラッシュアップ採用・navy + cream の 2 色基調）

## 何が起きたか（要約）

D0（ロゴ）フェーズで、案A（手描き温度系）・案B（幾何系）・案C（タイポグラフィ重視）の 3 系統で初稿を出し、案B のブラッシュアップ版（案B'）に確定した。シンボルは正方形枠＋ドットグリッド＋斜線（TZ 風）の組み合わせ、Wordmark はクリーンなセリフ navy、色は navy + cream の 2 色基調。「点描写の専門店」というブランドの核を「点」「直線」「グリッド」の幾何要素そのものでシンボル化し、屋号の TZ を斜線で示唆する読み解きの余地を残した。サイト全体・アプリ・OGP・印刷物までこの幾何トーンを拡張する基礎が固まった。

## 状況・背景

着手プラン（warm-yawning-harbor.md）では「ロゴ → サイト全体 → アプリ」の順で進める方針で、D0 ロゴが最初のデザイン成果物だった。ツールは Claude Design（design.claude.com）でビジュアル → Claude Code で実装のハイブリッド運用。

ブランドブリーフは「専門特化型ミニマルブランド × 個人運営の温度（顔出しなし版）」を掲げており、ベンチマークは「すたペンドリル／ピノトレ系のブランド型知育プリント」の品質ライン。一方、ちびむす・ぷりんときっず系のマスプリント（雑多・カラフル・子供イラスト多用）には絶対に寄せない。「点描写だけを徹底深掘りする、専門特化型ミニマルブランド」というポジショニングが前提だった。

ターゲット層は「4-10 歳の子を持つ親で、3 層を売上換算で均等に狙う」。子ども向けに媚びたデザイン・ゲーミフィケーション過多・キャラクター押しは避け、親が「ちゃんとした専門の人がやっている」と直感できる端正さを優先する方針だった。

## やり取りの中身

3 案の初稿は以下のような立て分けで Claude Design に発注した：

- **案A（手描き温度系）**: 点と線を手描きの揺らぎで結ぶシンボル＋親しみやすい和文書体
- **案B（幾何系）**: ドットグリッド・直線・斜線の組み合わせ＋クリーンなセリフ Wordmark
- **案C（タイポグラフィ重視）**: シンボルなし・Wordmark のみで幾何的字形を作り込む

各案について「子ども向けに見えるか」「専門店として信頼できるか」「マスプリント寄りに見えるか」「ベンチマーク（すたペンドリル／ピノトレ）の品質ラインに乗っているか」の 4 軸で評価した。

案A は手描き温度系で温かさは出るが、「個人の手作り感」が強く出すぎてしまい、「企業並みの端正さ」というブランドブリーフの核から外れた。NG リストにも「個人の手作り感を強調する素朴さ」が含まれており、即不採用。

案C は Wordmark のみで省力的だが、「点描写」というブランドの核となる視覚言語（点・直線・グリッド）を視覚化できず、屋号が立つだけで業態が伝わらない。シンボルの不在は OGP・アプリアイコン・ファビコンで困ることも判明し、不採用。

案B が方向性として確定した後、ブラッシュアップで「シンボルの幾何要素をより端正にする」「TZ の文字構造を斜線で示唆する」「色を navy + cream の 2 色に絞る」の 3 点を反映し、案B' として最終化した。シンボルは正方形枠の中にドットグリッドを置き、斜めの太線で T と Z を読み解ける構造にした。

## なぜそう判断したか

案B' を選んだ最大の理由は、「点・直線・グリッドという幾何要素そのものをブランドの視覚言語にする」というブランドブリーフの方針が、ロゴで一貫していたからだ。サイト全体・アプリ・記事カテゴリ図版まで同じ幾何要素を拡張していく予定で、その起点となるロゴが「他にもありそうな知育ブランド」のテンプレに収まると、後段の拡張全部が薄まる。

navy + cream の 2 色基調を選んだのは、ブランドブリーフの「主役: 鉄紺 #2B3D5A 前後／背景: 生成 #F7F2E7 系」を直接反映したからだ。アクセントの山吹 #D9A237 はロゴには使わず、「達成・注目」用途に限定するルール（マスプリント寄りになるため）を厳守した。ロゴ自体は 2 色に絞ることで、印刷・1 色刷り・ファビコンなどの制約環境でも崩れない。

シンボル＋ Wordmark のロックアップ構造を採用したのは、用途別の使い分け（アプリアイコンはシンボルのみ・サイトヘッダーはロックアップ・名刺は Wordmark のみ等）を見越したためだ。シンボルだけで TENZU と読み解ける必要はなく、「専門店らしい幾何記号」として独立して機能すれば良い。屋号の TZ を斜線で示唆するのは、知っている人だけが気付く読み解きの余地として残した。

## 学び（一般化できるノウハウ）

1. **「他にもありそう」な方向性は採用しない** — テンプレに収まるデザインは安全だが、後段のサイト・アプリ・記事カテゴリ図版まで拡張したとき全部が薄まる。ロゴは後段デザインの基礎になるため、視覚言語の独自性は妥協しない。

2. **アクセント色は用途を限定する** — 山吹色を「達成・注目」用途に限定し、ロゴから外したのは、マスプリント寄りに見えるリスクの予防。アクセント色を多用すると専門ブランドのトーンが崩れる。用途を絞ることが端正さの担保になる。

3. **シンボル＋ Wordmark のロックアップは用途別使い分けを前提に設計する** — シンボルだけでブランド名が読める必要はない。アプリアイコン・ファビコン・1 色刷りなど制約環境での独立機能を見越して、シンボルと Wordmark の関係性を設計する。
