# 「背景の点をとる」白紙模写モード（グリッドなし図形模写の研究を実装へ）

## 何が起きたか（要約）

オーナー発案「小学校受験で頻出のグリッドなし図形模写を TENZU に加えるか」を起点に、隣接ジャンルの調査から実装までを一気に進めた。調査結果を受けて Claude は当初、新タスクとしての新設に慎重論を出したが、オーナーは「既存の点描写問題から背景ドットを消して白紙模写化する設定」という第三の形を選んだ。結果、全10メーカーと商品プリント PDF の両方に「背景の点をとる」トグルを搭載し（コミット dbc918c）、書き込み欄にだけ薄いグレー枠を敷く白紙模写形式を実現した。★●マーカー・欠け補完・立体模写には一律処理から外す個別対応を入れた。調査の副産物として、Amazon に音の近い既存商品「てんずけい」（図形模写教材）を発見し、商標方針の再確認事項として記録した。

## 状況・背景

小学校受験の分野分類では「点図形」と「図形模写」は大分類「図形・模写」内の別小分野として併存し、教材も別建てになっている（こぐま会・理英会とも両者を独立商品にしている）。発達検査の裏付けも厚く、田中ビネー（三角=5歳級・ひし形=6歳級）、BGT、Beery VMI、WAVES「形うつし」、5歳児健診の「まねて四角」と一次資料の候補群が揃う。学習順序の定説は「点図形（ガイドあり）→図形模写（ガイドなし）」で、ガイドなしは始点・方向・長さをすべて自分で決めるため一段難しい。一方、専用教材はこぐま会・理英会に集中し、点描写より層が薄い。この空白を取りに行くか、行くならどの形で取るかが論点だった。

## やり取りの中身

**調査と慎重論**。Web 調査で上記の事実群を確認したうえで、Claude は新タスク新設への慎重論を3点挙げた。業態句「点図形（点描写）プリント専門店」と「点のない問題」の緊張、グリッドなし模写は採点が主観化しブランドの柱 P5（継続）と相性が悪いこと、小受を旗にしないという既往のブランド判断である。賛成材料（発達的な正統性・年齢帯が主戦場と一致・体系化をやる競合ゼロ）も併記したが、結論は新設反対寄りだった。

**「点を取る」方式への転換**。オーナーは新設でも見送りでもなく、「既存の点描写問題から背景ドットを消すトグル」を選んだ。9タスク体系は不変のまま、全問題が白紙模写の素材に転用される。実装は共通コアに寄せた。`page-svg.ts` の `paneSvgString` に `showDots` 引数を追加し、空欄ペイン用の `paneFrameSvgString` を新設、`PaperSVG`・`PreviewPane` にも同じ口を通した。そのうえで全10メーカーの詳細設定に「背景の点」チェックボックスを置き、商品側も `SkuPrintPreview` の8タスク共通プレビューと立体プレビューの両方に「背景の点：つける/とる」を追加した。プレビュー・pdf-lib 生成・解答 PDF の全経路に反映し、枠は出題時の空欄ペインだけに出す（解答 PDF は対象外）。

**一律で消せないタスクの個別対応**。トグルの意味が壊れるタスクを洗い出して例外処理を入れた。回転の★、移動の★●、拡大縮小の★は位置情報として必須のため、通常ドットだけを `showDots` でガードしマーカーは常に残す。欠け補完は書き込み側マスに欠け図の線が既にあるため枠を付けず点だけ消す。立体模写（横長矩形格子の別実装）は `solid-print.ts` 側に同じ口を通し、枠を実線にして「かくれた辺＝点線」と色・線種で区別した。検証は dev サーバの JS 検査で模写・鏡・回転・欠け補完・立体・商品 SKU 2種の7ケースを通し、tsc・build とも緑を確認した。

**市場調査の副産物**。調査中に Amazon で「てんずけい」という商品名の図形模写教材（受験教室監修・126問・正誤確認用透明シート付）を発見した。TENZU と音が近接するため、商標方針の再検討トリガーとして記録した。あわせて「図形模写と点描写の違い」を解説する記事 C3-6 を同日に立て、機能と検索需要の両面から受け皿を作った。

## なぜそう判断したか

**新設ではなくトグルにした理由**。慎重論の3論点は、いずれも「図形模写という新カテゴリを立てる」ことへの懸念であって、「既存問題から点を消す」形なら概ね回避できる。体系は9タスクのまま、採点基準も既存問題の線形状がそのまま正解であり、小受も旗ではなく設定の一つに収まる。むしろ「点は外せる足場」という整理が生まれ、点描写→白紙模写という卒業の階段を専門店の体系内に取り込めた。ブランドの一貫性を弱めるどころか強める話に転じた。

**空欄側にだけ薄枠を敷いた理由**。小受の出題は「お手本＋空欄枠型」と「マス目模写型」の2系統あり、点を消しただけの完全な白紙では書く領域の手がかりが消えて紙面が成立しない。見本側は図だけ、書き込み側は薄いグレー枠だけ、という配分は前者の出題形式に一致し、印刷物としての据わりも保てる。

**発達的正統性が後押しになった理由**。「ガイドあり→ガイドなし」という学習順序の定説を、1トグルで実現できる。エビデンスを明示する店の方針とも合い、発達検査群という一次資料の裏付けもある。機能としては小さいが、商品の射程を「点図形の店」から「点図形とその卒業までの店」へ広げる意味を持った。

## 学び（一般化できるノウハウ）

1. **隣接ジャンルへの進出は「新カテゴリ新設」より先に「既存資産のパラメータ化」を検討する** — 新設は体系・ブランド・採点基準のすべてに緊張を走らせるが、既存問題の1属性（背景ドットの有無）をトグル化すれば、資産全部がそのまま隣接ジャンルへ転用され、体系は不変のまま射程だけが広がる。反対論の大半は「新設」への反対であり、形を変えれば消えることがある。

2. **一律トグルは「意味を持つ例外」を洗い出してから展開する** — 同じ「背景の点」でも、位置マーカー・書き込み済みの線・立体の隠れ線表現ではドットの役割が違う。全対象に同じ処理を流す前にタスクごとの意味を点検し、例外（マーカー保持・枠なし・線種の区別）を仕様として先に決めたことで、後追いの手戻りがなかった。

3. **機能調査は市場調査を兼ねる** — 隣接ジャンルの教材事情を調べる過程で、音の近い既存商品という商標上の発見があった。機能の是非を判断するための調査が、そのまま競合・リスクの早期検知になる。調査結果は機能の結論だけでなく、副産物ごと記録しておく価値がある。
