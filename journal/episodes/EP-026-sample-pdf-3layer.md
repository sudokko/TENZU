# 無料サンプルPDF廃止——「試してから買う」体験を3層で再設計

## 何が起きたか（要約）

各商品（各タスク・各 Lv・各 Vol.）に対して「無料サンプル PDF」を個別ファイルで配布する設計を廃止した。理由は「作成・管理コストの高さ」と「代替手段で同等の体験が担保できる」の2点だ。代替として「①アプリで無料体験（問題を自分で作れる）・②商品ページの Web プレビュー画像・③記事内のサンプル問題埋込」の3層で「試してから買う」体験を設計した。

## 状況・背景

2026-04-19 のセッション、立体模写プロト開発（EP-025）の流れの中で「立体模写のサンプル PDF をどう用意するか」が論点になった。そこで「そもそも独立サンプル PDF という形式が最善か」という根本的な問いが浮上した。

TENZU の商品は PDF パック（¥200 一律）だ。購入前に「内容が分かる」ことが差別化の核（「中身が見える専門店」）である以上、何らかの形で「試せる・確認できる」体験は必要だった。しかし「各 Vol. に独立したサンプル PDF を作って配布する」設計には問題があった：

- 総 SKU 数は 140 本以上。各 SKU にサンプル PDF を作ると 140 ファイル以上の管理が必要
- サンプル PDF は「無料で配布」するものだから、有料パックとの品質差の管理も要る
- 立体模写のような特殊格子の問題は、サンプル PDF 単体では「問題の実際の使い方」が伝わりにくい

## やり取りの中身

「独立サンプル PDF は廃止して、代替の3層でカバーする」という方向は Claude が提案した：

> 「140冊分のサンプル PDF を作って管理するのは、個人開発者には現実的じゃない。しかも保護者が本当に知りたいのは『この問題がうちの子に合うか』なのに、サンプル PDF だと『この問題の数枚』しか見せられない。むしろアプリで実際に試せた方が、保護者の体験としていいんじゃない？」

この提案を受けて3層設計に移行した：

**層1: アプリ無料体験**
- TENZU 作成アプリ（点描写問題ジェネレーター）は無料で提供
- 保護者・子どもが実際に問題を生成してみることで「こういう問題だ」が分かる
- 購入前に「難易度感・問題の見た目・印刷後の使い方」を体験できる
- 特に立体模写は「アプリで三角ドット格子の問題を見る」ことで、PDF の見え方が確認できる

**層2: 商品ページの Web プレビュー画像**
- 各商品ページに「問題のサンプル画像（数問分）」を掲載
- 「この Vol. はこういう問題が入っている」を商品ページで確認できる
- PDF を配布せず画像として見せることで、管理コストと不正コピーリスクの両方を下げる

**層3: 記事内サンプル問題埋込**
- 各タスクの紹介記事（B-2 コンテンツ設計）に、サンプル問題を画像で埋め込む
- 「記事を読んで理解する→サンプル問題で確認する→商品ページで購入する」という導線を作る
- 記事が SEO 流入の入口になりながら、同時に「試せる体験」を提供する

これにより「独立サンプル PDF 配布なし」が確定した。`docs/service-blueprint.md §2（検討/体験フェーズ）`に「無料サンプルは3層のみ（独立サンプル PDF は廃止）」として記録された。

## なぜそう判断したか

廃止の根本的な理由は「管理コストと体験品質のトレードオフ」だ。

独立サンプル PDF を全 SKU で用意すると、コンテンツ管理の負荷が倍増する。140冊の有料版を作った上に、さらに140本のサンプル版を作る。どちらかの品質が下がった時に更新しなければならない2系統のコンテンツ管理は、個人開発者には重すぎる。

一方、3層代替の体験品質は独立サンプル PDF より優れている側面がある。「アプリで問題を実際に生成して印刷してみる」体験は、「PDF の数ページをプレビューする」より保護者の判断精度が高い。特に「子どもに実際に解かせてから判断したい」という保護者には、アプリ体験の方が有益だ。

また「Web プレビュー画像 + 記事埋込」は SEO との相乗効果がある。記事にサンプル問題が画像として載っていることで、記事の専門性・独自コンテンツとしての評価が上がる。独立 PDF ではこの効果が生まれない。

## 学び（一般化できるノウハウ）

1. **「本来の目的」で代替手段を評価する** — 「サンプル PDF が必要」ではなく「試してから買える体験が必要」という目的に立ち戻ると、代替手段の評価軸が変わる。目的から逆算すると、より良い代替案が見つかることがある。

2. **コンテンツの二系統管理は個人開発では危険** — 有料版と無料版を別ファイルで管理することは、更新の都度2回作業を要求する。「一つの素材が複数の目的を兼ねる」設計の方が持続可能だ。

3. **無料体験はアプリや記事で担保できる** — SaaS 的な「フリーミアム」体験は PDF 配布より豊かな場合がある。特に生成型ツール（アプリ）は「自分で作った」体験が購入動機に直結しやすい。
