# 案H→案H' オーナー突合：AI のフレームを一次情報で解体する

## 何が起きたか（要約）

AI が午前中に組み上げた案H で「公文家庭＝旗艦ターゲット」と置いた構造に対し、オーナーが「実購入意向のデータはない、見えているのは『公文に図形がない』事実のみ」と突き返した。これを起点に 4 点の修正を行い、案H' として確定した。①公文家庭は「旗艦」→「TENZU の理想顧客像に最も近い親層の例示」へ降格、中核は「公文に通わせるような知育意識のある親」全般／②対象年齢は年中〜（公文より高めに設定）／③Article は Core から降格し Product のみ Core（個人運営でのスケール問題）／④App は「採点支援・進捗記録」から「自作点描写ジェネレータ → PDF 印刷」へ転換し Phase 0 で復活。タグラインも「点つなぎの次に、点描写を。」→「点と点がつなげるようになったら、点描写を。」へ書き換え、競合観も再設定。Brand Pillars 4 本（P1 体系／P2 言語化／P3 発見／P4 解像度）で固めた。

## 状況・背景

午前の案G→案H 軸足移動セッション（EP-052）で、AI 側は「啓蒙ブランドの旗艦ターゲットは公文家庭」と置いた。公文式に通わせる家庭は「点つなぎが終わり、図形は公文式カリキュラムに含まれない」というユーザージャーニーの隙間が明確に見えるため、AI のロジックとしては自然な置き方だった。

しかしオーナー側には別の感覚があった。公文家庭が「点つなぎの次」を欲して TENZU を実購入するという仮説は、定量データが取れていない。見えているのは「公文式カリキュラムに図形がない」という事実だけで、そこから「公文家庭が実購入する」へ飛ぶには論理に穴がある。AI のフレームは、一次情報の裏取りなしで構造を組み立ててしまった疑いがあった。

## やり取りの中身

オーナーの最初の指摘は「公文家庭を旗艦に置いた根拠は何か」だった。AI 側は「市場規模、ユーザージャーニーの隙間、知育意識の高さ」の 3 点を挙げたが、いずれも実購入意向の裏取りデータではなく、構造的な推論だった。

オーナーはここで「実購入意向が確認できていない層を旗艦に置くと、後で全部組み替えになる」と切り出し、「公文家庭は『TENZU の理想顧客像に最も近い親層の例示』として §5 のセグメント定義の代表例位置に置く。中核は『公文に通わせるような知育意識のある親』全般」と再定義を要求した。

連動して 3 点の波及修正が必要になった。第 1 に対象年齢。公文家庭を例示位置に下げると、対象年齢を公文より高めの「年中〜」に上げて知育意識の高い親層全体を拾う設計に変える必要があった。第 2 に Article の位置付け。「個人運営でブログ記事 30 本基幹コンテンツ化」は、現実的なオペレーション負荷で組めない、と判明し、Article を Core から降格、Product のみ Core という構造に整理した。第 3 に App。元の案H では「採点支援・進捗記録」を担うものとして App を構想していたが、それでは PDF 商品との関係が薄い。「自作点描写ジェネレータ → PDF 印刷」という、PDF 商品の購買前体験として位置付け直し、Phase 0 で App を復活させた。

タグラインの書き換えも本セッションで起きた。「点つなぎの次に、点描写を。」は完走待ちの含意があったが、年中〜に対象が広がると「点つなぎの完走を待たずに、点と点がつながるようになった段階で点描写へ移れる」という能力獲得タイミング軸の方が拾える範囲が広い。「点と点がつなげるようになったら、点描写を。」で確定した。

競合観も再設定した。タブレット教材を「対立軸（紙 vs 画面）」から「使い分け軸」へ降格。天才ドリル・ピグマリオン・コグトレ書籍は「競合」から「同志（引用先）」へ位置付け直した。啓蒙ブランドである以上、書籍系の同志は引用協力先として扱う方が筋が通る。

Brand Pillars は午前の 3 本（点つなぎ次／紙で続く／中身が見える）から、4 本構成（P1 体系／P2 言語化／P3 発見／P4 解像度）へ再編。旧 Pillar 3 本は archive/retired-designs へ退避し、方針転換の証跡として残した。

## なぜそう判断したか

判断軸の中心は「AI のフレーム < オーナーの一次情報」という優先順位。AI が組んだ構造的推論（市場規模＋ジャーニー隙間＋知育意識）は、実購入意向のデータが不在のまま組まれていた。仮説段階の論点を「旗艦」として確定すると、Phase 1 以降で実購入データが取れた時点で構造全体の組み直しが発生する。それを避けるため、データのない仮説は格下げし、定義可能な事実（「公文に図形がない」「公文に通わせる親層は知育意識が高い」）のみで構造を組み直した。

App の Phase 0 復活も同じ論理。Phase 0 で「無料体験」を担う物は必要だが、PDF 商品との接続が薄い App では Phase 1 以降に廃止圧力がかかる。PDF 印刷を最終出力とする「自作点描写ジェネレータ」なら、Phase 0 体験 → PDF 商品購買への動線がそのまま繋がる。

## 学び（一般化できるノウハウ）

第 1 に、AI が組んだフレームをオーナーが解体する作法。AI は手元の情報から構造的推論で「旗艦」を置きにくるが、一次情報（実購入意向データ）が不在の仮説は仮説のままで、確定構造にしてはいけない。「定義可能な事実」と「推論」を区別し、定義可能な事実のみで構造を組み立てる規律が要る。

第 2 に、タグラインを「完走待ち」から「能力獲得タイミング」へ移すと、対象年齢の広がりを構造的に吸収できる。タグラインの動詞・条件節を 1 単語変えるだけで、ターゲット定義の幅が大きく動く。

第 3 に、既存の Pillar 構造を破棄するときは archive/retired-designs に退避して証跡化する。後日の意思決定で「なぜそこを変えたか」を遡れるようにすると、似たフレームに戻りそうになったときの歯止めになる。
